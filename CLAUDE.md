## 三、水平技能（跨垂直通用能力）

1. **编程语言**  
   - Java / Python / JavaScript / TypeScript / C / C++ / Go / Kotlin / Swift / Dart / Rust
2. **前端技能**  
   - HTML / CSS / JS / TS / React / Vue / Angular / Svelte  
   - 状态管理（Redux / Zustand / Pinia）  
   - 前端工程化（Webpack / Vite / Rollup）  
   - UI框架：Tailwind / Ant Design / ShadCN  
   - 性能优化 / 前端安全
3. **后端技能**  
   - REST / GraphQL / RPC / 微服务 / 异步 / 高并发  
   - 框架：Spring Boot / Spring Cloud / Django / Flask / FastAPI / Node.js / Nest.js / Laravel  
   - 缓存 / 消息队列 / 异步任务
4. **数据库 & 数据处理**  
   - MySQL / PostgreSQL / Oracle / MongoDB / Redis / Cassandra / ClickHouse / Doris  
   - SQL优化 / 数据建模 / ETL / 数据仓库
5. **人工智能 / 数据科学**  
   - NumPy / Pandas / Matplotlib / Scikit-learn / TensorFlow / PyTorch / Keras / OpenCV / NLTK / HuggingFace  
   - 数据可视化 / 特征工程 / 模型训练 / 部署 / MLOps
6. **大数据 / 流处理**  
   - Hadoop / Spark / Flink / Kafka / Airflow / Hive / Presto  
   - 数据仓库 / 实时流处理 / ETL
7. **网络与安全**  
   - TCP/IP / HTTP / HTTPS / DNS  
   - Web安全（XSS / CSRF / SQL注入）  
   - 渗透测试 / 漏洞分析 / 密码学 / 安全运维
8. **移动开发**  
   - 安卓（Java/Kotlin） / iOS（Swift） / Flutter / React Native  
   - UI/UX优化 / 跨平台开发 / 性能调优 / 本地存储
9. **DevOps / 云 /运维**  
   - Git / CI/CD / Docker / Kubernetes / Terraform / Ansible / Jenkins / GitLab CI  
   - 云平台：AWS / Azure / GCP / 阿里云  
   - 监控 / 日志 / 告警 / 自动化部署
10. **测试 / QA / 软件质量**  
    - 单元测试 / 集成测试 / 自动化测试 / 性能测试  
    - 工具：Selenium / Appium / JMeter / Postman / Pytest / JUnit  
    - 测试流程 / TDD / BDD
11. **GIS / WebGIS / 三维地图**  
    - Leaflet / OpenLayers / Cesium / ArcGIS API / PostGIS / GeoServer  
    - 空间数据分析 / 三维可视化 / 项目实战
12. **嵌入式 / IoT**  
    - STM32 / Arduino / Raspberry Pi / Zephyr / FreeRTOS  
    - 硬件驱动 / 边缘计算 / IoT协议 / 数据采集
13. **区块链 / Web3**  
    - Solidity / Rust / Go / JS  
    - 智能合约 / DApp / NFT / DeFi / 区块链架构
