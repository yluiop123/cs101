> 全面的技术学习路径汇总 —— 从入门到进阶，覆盖主流技术栈、应用领域与通用技能。

## 🚀 快速开始

```bash
pnpm install   # 安装依赖
pnpm dev       # 启动开发服务器
pnpm build     # 构建静态站点
pnpm preview   # 预览构建结果
```

## 📖 项目简介

基于 [VitePress](https://vitepress.dev/) 构建的技术学习路线网站，帮助学习者系统规划学习路径。内容分为三大板块：

### 一、技术栈路线

围绕核心技术展开，拓展应用场景：

| 核心技术 | 可扩展应用场景 |
| -------- | -------------- |
| **Java** | Web开发 / 企业系统 / 移动开发 / 大数据 / AI后端 |
| **Python** | Web开发 / 数据科学 / AI / 自动化运维 |
| **JavaScript / TypeScript** | 前端开发 / 全栈开发 / WebGIS |
| **C / C++** | 系统编程 / 嵌入式 / 高性能计算 |
| **Go** | 后端高并发 / 微服务 / 云原生 |
| **Kotlin / Swift / Dart** | 移动开发 / 跨平台应用 |
| **SQL / 数据库** | 数据管理 / 数据建模 |

### 二、应用领域路线

围绕业务场景选择技术栈：

Web开发 · 企业系统 · 大数据 · AI/ML · 网络安全 · 移动开发 · DevOps · GIS · 游戏开发 · 嵌入式/IoT · 区块链 · 软件测试 · 金融科技

### 三、水平技能

跨行业通用能力：编程语言 / 前后端 / 数据库 / AI / 运维 / 测试 / 安全 / 移动开发

## 🗂️ 站点结构
