# CSS 教程

> 状态：可学习 · 共 12 章 · 预计 8 小时

CSS（层叠样式表）负责网页的"颜值"——颜色、布局、动画都由它控制。如果说 HTML 是骨架，CSS 就是皮肤与肌肉。本教程系统讲解选择器、盒子模型、定位、Flex/Grid 布局与响应式设计，最终能独立还原设计稿。
