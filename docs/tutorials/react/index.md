# React 教程

> 状态：可学习 · 共 12 章 · 预计 10 小时

React 是 Meta（Facebook）开源的声明式 UI 库，全球使用率第一的前端框架。它的核心理念是"用函数描述 UI"，配合 Hooks 机制可以优雅地管理状态与副作用。本教程从 JSX 讲到路由、状态管理与完整项目实战。
