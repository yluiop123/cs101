# VS Code 教程

> 状态：可学习 · 共 5 章 · 预计 1.5 小时

Visual Studio Code（简称 VS Code）是微软推出的免费开源代码编辑器，凭借轻量、插件生态丰富、跨平台等优势，已成为目前最流行的开发工具。无论你将来学习前端、后端还是数据科学，它都能胜任。

本教程从零开始：安装与界面认识 → 基础配置 → 必备插件 → 核心功能 → 效率进阶，学完即可流畅地使用 VS Code 进行日常开发。

## 前置教程

无需编程基础，零门槛入门。建议准备一台 Windows / macOS / Linux 电脑即可。

- 安装 VS Code 并完成中文界面、常用基础配置
- 装好一套覆盖日常开发 90% 场景的插件组合
