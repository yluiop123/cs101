# 第 4 章 · 核心功能详解

**本章目标：**

- 熟练使用文件管理与全局搜索
- 掌握集成终端的日常用法
- 学会用内置调试器打断点、看变量
- 了解 Emmet 与代码片段带来的效率提升

## 4.1 文件与工作区管理

### 打开项目的方式

推荐用"打开文件夹"（`Ctrl+K Ctrl+O`）把整个项目目录作为工作区打开，而不是单开文件——这样资源管理器、全局搜索、Git 功能都以项目为根。

### 常用文件操作快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+P` | 按文件名快速打开文件（最高频！） |
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+B` | 显示/隐藏侧边栏 |
| `Ctrl+\` | 分屏（左右分出第二编辑区） |
| `Ctrl+W` | 关闭当前标签页 |
| `Ctrl+Tab` | 切换标签页 |

::: tip Ctrl+P 小技巧
输入文件名时支持模糊匹配，比如输入 `sct` 就能匹配到 `screen-config.ts`。文件名记不全也能秒开。
:::

## 4.2 全局搜索与替换

`Ctrl+Shift+F` 打开全局搜索，在**整个项目**里搜索文本：

- `Ctrl+Shift+H`：全局替换（可预览每处改动）
- 搜索框右侧三个开关：**区分大小写**（`Ab`）、**全字匹配**（`ab`）、**正则模式**（`.*`）
- 可用 `files to include` 指定搜索范围，如 `src/**/*.ts` 只搜 src 下的 ts 文件

正则示例：搜索 `console\.log\(.*\)` 可一键找出项目里所有调试输出语句，配合全局替换批量清理。

## 4.3 集成终端

``Ctrl+` ``（反引号，Tab 键上方）打开集成终端：

- 终端就在编辑器下方，无需切换窗口
- 点击面板右上角 `+` 可新建多个终端（如一个跑开发服务器，一个执行 git）
- 支持多开与分屏，可分别选择 PowerShell / CMD / Git Bash 等默认 shell

::: tip 改默认终端（Windows）
命令面板输入 `Terminal: Select Default Profile`，选择你喜欢的 shell。前端开发推荐 Git Bash 或 PowerShell 7。
:::

## 4.4 断点调试

以调试 JavaScript 为例，体验内置调试器：

1. 在某行代码**行号左侧单击**，出现红点即**断点（breakpoint）**
2. 按 `F5` 启动调试（首次会提示选择环境，如 Node.js / Chrome）
3. 程序运行到断点处暂停，此时可以：

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 单步跳过 | `F10` | 执行当前行，不进入函数内部 |
| 单步进入 | `F11` | 进入当前调用的函数内部 |
| 单步跳出 | `Shift+F11` | 执行完当前函数并跳出 |
| 继续 | `F5` | 运行到下一个断点 |

4. 左侧面板实时查看：**局部变量**、**监视表达式**、**调用堆栈**

调试比"到处加 console.log 打印"高效得多——这是从新手进阶到熟练开发者的重要一步。

## 4.5 内置 Emmet：HTML/CSS 加速器

VS Code 内置了 Emmet 缩写展开，输入缩写按 `Tab` 即可生成代码：

```html
<!-- 输入 ul>li.item*3 然后按 Tab -->
<ul>
  <li class="item"></li>
  <li class="item"></li>
  <li class="item"></li>
</ul>
```

```html
<!-- 输入 div#header.main 然后按 Tab -->
<div id="header" class="main"></div>
```

CSS 中也有对应缩写，如输入 `m10` 展开为 `margin: 10px;`，`p20` 展开为 `padding: 20px;`。学会几个高频缩写，写模板的速度翻倍。

## 4.6 代码片段（Snippets）

输入 `log` 按 Tab 自动展开为 `console.log()`——这就是代码片段。

查看/自定义片段：命令面板输入 `Configure User Snippets`，选择语言后编辑 JSON：

```json
{
  "Print to console": {
    "prefix": "log",
    "body": ["console.log('$1');", "$2"],
    "description": "输出日志"
  }
}
```

- `prefix`：触发的缩写词
- `body`：展开的内容，`$1`、`$2` 是按 Tab 跳转的占位符

## 本章小结

- `Ctrl+P` 秒开文件（模糊匹配）；整个目录作为工作区打开
- 全局搜索支持正则与范围限定；集成终端免切换窗口
- 调试四步：打断点 → F5 → F10/F11 步进 → 看变量面板
- Emmet 缩写 + 自定义 Snippets 是书写提速利器
