# 第 1 章 · 初识 VS Code

**本章目标：**

- 了解 VS Code 是什么、为什么它如此流行
- 认识编辑器界面的主要组成部分
- 理解 VS Code 与"IDE"的区别

## 1.1 什么是 VS Code

Visual Studio Code 是微软在 2015 年发布的**免费、开源、跨平台**代码编辑器。注意它和"Visual Studio"是两个不同的产品——VS Code 是轻量编辑器，Visual Studio 是重型集成开发环境（IDE）。

它之所以能成为最受欢迎的开发工具之一，靠的是四个特点：

| 特点 | 说明 |
| --- | --- |
| 免费 | 个人和商业使用均完全免费 |
| 轻量 | 安装包不到 100MB，启动秒开 |
| 跨平台 | Windows / macOS / Linux 全支持 |
| 插件生态 | 数万款扩展，几乎覆盖所有语言与工作流 |

::: tip 提示
VS Code 本体只是一个"壳"，真正强大的地方在于**插件生态**——这也是本教程第 3 章的主题。
:::

## 1.2 它能用来做什么

VS Code 几乎可以覆盖所有的开发场景：

- **前端开发**：HTML / CSS / JavaScript，配合插件还有语法检查与自动补全
- **后端开发**：Java、Python、Go、C# 等语言插件一应俱全
- **数据与脚本**：Python、Jupyter Notebook、Shell 脚本
- **写作**：Markdown 编辑（本站的教程就是用 VS Code 编写的）

## 1.3 界面速览

安装完成后（下一章详解安装），你会看到这样的界面布局：

```text
┌─────────────────────────────────────────────┐
│  菜单栏（文件 / 编辑 / 查看 / 终端…）        │
├──────┬──────────────────────────┬───────────┤
│      │                          │           │
│ 活动栏│        编辑区            │  侧边面板  │
│      │   （写代码的地方）        │ (资源管理器│
│ 5个  │                          │  搜索、Git │
│ 图标 │                          │  调试…)    │
│      ├──────────────────────────┤           │
│      │        面板区             │           │
│      │  (终端 / 输出 / 错误)     │           │
├──────┴──────────────────────────┴───────────┤
│  状态栏（分支、错误数、行列号、编码…）        │
└─────────────────────────────────────────────┘
```

各区域职责：

- **活动栏**：最左侧一列图标，切换资源管理器、全局搜索、源代码管理、调试、扩展五大面板
- **编辑区**：核心工作区，支持多标签页、分屏
- **面板区**：终端、输出、问题列表都在这里
- **状态栏**：显示当前分支、行列位置、文件编码等实时信息

## 1.4 VS Code 与 IDE 的区别

很多初学者会问："VS Code 算 IDE 吗？"严格来说它只是**编辑器**，但通过插件它可以无限接近 IDE：

```text
编辑器（VS Code 本体） + 插件（语言支持/调试/格式化） ≈ IDE
```

这种"按需组装"的模式正是它的魅力：写 Python 就装 Python 插件，写 Vue 就装 Vue 插件，永远只加载你需要的功能。

::: warning 常见误区
不要一开始就装几十个插件。插件越多，启动越慢、冲突越多。本教程第 3 章会给你一份精简的必备清单。
:::

## 本章小结

- VS Code：免费、轻量、跨平台、插件生态强大
- 五大区域：菜单栏、活动栏、编辑区、面板区、状态栏
- 本体只是编辑器，配合语言扩展可无限接近 IDE
- 插件贵精不贵多，遇到痛点再装
