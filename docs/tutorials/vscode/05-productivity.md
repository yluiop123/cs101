# 第 5 章 · 效率进阶

**本章目标：**

- 记住最值得背下来的 10 个快捷键
- 掌握多光标编辑这一"杀手级"技巧
- 学会重构重命名、快速跳转等编辑器级能力

## 5.1 十个最值得记住的快捷键

以下快捷键值得形成肌肉记忆（macOS 将 `Ctrl` 换成 `Cmd`）：

| 快捷键 | 功能 | 使用频率 |
| --- | --- | --- |
| `Ctrl+P` | 快速打开文件 | ⭐⭐⭐⭐⭐ |
| `Ctrl+Shift+P` | 命令面板 | ⭐⭐⭐⭐⭐ |
| `` Ctrl+` `` | 开关终端 | ⭐⭐⭐⭐⭐ |
| `Ctrl+D` | 选中下一个相同词（配合多光标） | ⭐⭐⭐⭐ |
| `Ctrl+Shift+F` | 全局搜索 | ⭐⭐⭐⭐ |
| `Ctrl+/` | 注释/取消注释当前行 | ⭐⭐⭐⭐ |
| `Alt+↑/↓` | 上下移动当前行 | ⭐⭐⭐⭐ |
| `Shift+Alt+↑/↓` | 向上/下复制当前行 | ⭐⭐⭐⭐ |
| `Ctrl+Home/End` | 跳到文件开头/结尾 | ⭐⭐⭐ |
| `Ctrl+G` | 跳转到指定行号 | ⭐⭐⭐ |

::: tip 循序渐进
不要试图一天背完。每周刻意练习 3 个，一个月后这些操作会变成条件反射。
:::

## 5.2 多光标编辑

这是 VS Code 最强大的编辑能力，一个光标变多个（Multi-cursor），同时编辑多处：

- `Alt+点击`：在点击处新增一个光标
- `Ctrl+D`：选中当前词后，每按一次选中下一个相同词（所有选中处同时出现光标）
- `Ctrl+Alt+↑/↓`：在上下相邻行同列位置加光标（适合批量对齐编辑）
- `Esc`：退出多光标模式

典型场景：把一个对象里 10 个字段名统一加上前缀——用 `Ctrl+D` 逐个选中再加前缀，3 秒完成，比手改 10 次快得多。

## 5.3 重构利器：重命名符号

把光标放在变量/函数名上，按 `F2`（或右键 → 重命名符号）：

- 所有**引用了该符号**的位置同步改名
- 与"全局查找替换"的区别：F2 理解代码语义，不会误改注释或字符串里的同名词

前提：安装了对应语言的扩展（JS/TS 内置支持，Python 需要 Python 插件）。

## 5.4 快速跳转

| 操作 | 快捷键 |
| --- | --- |
| 跳转到定义 | `F12`（或 Ctrl+点击） |
| 查看引用（谁用到了它） | `Shift+F12` |
| 跳回上一个位置 | `Alt+←` |
| 符号间跳转（当前文件） | `Ctrl+Shift+O` |

`Alt+←/→` 相当于浏览器的"后退/前进"，在代码里跳来跳去时非常常用。

## 5.5 拖拽与列选择

- **按住 Alt 拖动鼠标**：矩形列选择，可对一列文本同时编辑
- **按住 Ctrl 拖动标签页**：复制文件
- **拖动文件到编辑器**：按住 `Shift` 拖入是插入文件路径（而非打开文件）

## 5.6 保持更新的习惯

VS Code 每月发布一个版本，`帮助 → 检查更新` 或直接在欢迎页查看 **Release Notes**。每次更新的亮点都会演示动图，花 5 分钟浏览一遍，经常能发现新效率功能。

## 本章小结

- 十大快捷键每周练三个，先背 `Ctrl+P` / 命令面板 / 终端
- `Ctrl+D` 多光标是批量编辑之王
- `F2` 语义重命名、`F12` 跳转定义、`Alt+←/→` 导航历史
- 关注月度 Release Notes，持续吸收新功能
