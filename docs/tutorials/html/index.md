# HTML 教程

> 状态：可学习 · 共 10 章 · 预计 6 小时

HTML（超文本标记语言）是网页的骨架——你看到的每一个网页，本质上都是一份 HTML 文档。本教程从零基础开始，系统学习标签、表单、语义化与 HTML5 进阶，最终能独立手写一个结构规范的完整页面。

## 前置教程

- 无需编程基础，零门槛入门
- 建议先完成 [VS Code 教程](/tutorials/vscode/)，并安装 Live Server 插件（第 3 章有介绍）

## 你将学到

- 理解网页从 URL 到渲染的完整过程
- 熟练使用文本、列表、表格、链接、图片、多媒体等标签
- 掌握表单的完整体系：控件、校验与提交原理
- 用语义化标签构建规范页面结构，理解 SEO 与无障碍的意义
- 综合实战：从零完成一个个人主页
