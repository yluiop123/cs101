# 第 3 章 · 文本标签

**本章目标：**

- 熟练使用标题与段落，理解文档大纲
- 掌握常用行内语义标签的正确选择
- 会用引用与代码相关的标签

文本标签是使用频率最高的一组标签，覆盖网页 90% 的文字内容。

## 3.1 标题：h1 ~ h6

六个层级的标题，重要性递减：

```html
<h1>文章主标题</h1>
<h2>章节标题</h2>
<h3>小节标题</h3>
```

::: danger h1 唯一原则
- 每个页面**只用一个** `<h1>`（页面主题）
- **不要跳级**：h2 下面直接用 h4
- **不要为了字号选标签**：调整大小是 CSS 的事，标题的选择只看**语义层级**

标题层级会构成"文档大纲"，屏幕阅读器（screen reader）靠它导航，搜索引擎靠它理解页面结构。
:::

## 3.2 段落与换行

```html
<p>这是一个段落。浏览器会在段落之间自动添加间距。</p>

<p>第一行<br />强制换行的第二行</p>

<hr />
```

- `<p>`：段落（paragraph），成段的内容必须用它，**不要用 `<br>` 凑段落**
- `<br>`：强制换行（break），仅用于诗歌、地址等"逻辑上必须断行"的场景
- `<hr>`：主题分隔（thematic break），表示话题转换，不是装饰线

## 3.3 行内语义标签

同一件事有多种写法，选标签的依据是**语义**：

| 标签 | 语义 | 效果 |
| --- | --- | --- |
| `<strong>` | 重要内容（强烈强调） | 加粗 |
| `<em>` | 强调语气（emphasized） | 斜体 |
| `<del>` | 已删除内容 | 删除线 |
| `<ins>` | 新插入内容 | 下划线 |
| `<mark>` | 高亮标记 | 黄色背景 |
| `<small>` | 备注、小字 | 缩小 |
| `<sub>` / `<sup>` | 下标 / 上标 | H₂O、x² |

实际对比：

```html
<p>
  <strong>警告</strong>：该项目已<del>开源</del><ins>转为闭源</ins>，
  请重点阅读 <mark>许可协议</mark> 部分。
</p>
<p>水的化学式是 H<sub>2</sub>O，2<sup>10</sup> = 1024。</p>
```

::: warning 别用 b 和 i
`<b>`（bold）与 `<i>`（italic）也能加粗斜体，但**不带语义**。现代规范推荐一律用 `<strong>`/`<em>`——当内容确实"只是视觉上粗一点"再考虑 b/i。
:::

## 3.4 引用类标签

```html
<!-- 块级引用：一整段引用 -->
<blockquote cite="https://example.com/source">
  天下大事，必作于细。——《道德经》
</blockquote>

<!-- 行内短引用 -->
<p><q>学而不思则罔</q>是孔子的名言。</p>

<!-- 作品名称 -->
<p>我最喜欢的书是<cite>三体</cite>。</p>
```

- `<blockquote>`：长引用块（通常带缩进样式）
- `<q>`：行内短引用（浏览器自动加引号）
- `<cite>`：作品标题（书名、文章名）

## 3.5 代码相关标签

```html
<!-- 行内代码 -->
<p>用 <code>npm install</code> 安装依赖。</p>

<!-- 代码块：pre 保留空格与换行 -->
<pre><code>function greet() {
  console.log('hi');
}</code></pre>

<!-- 键盘按键 -->
<p>按 <kbd>Ctrl</kbd> + <kbd>S</kbd> 保存。</p>

<!-- 程序输出示例 -->
<p>输出：<samp>Hello</samp></p>

<!-- 变量名 -->
<p>变量 <var>x</var> 表示横坐标。</p>
```

::: tip 记住两个就够
日常最常用 `<code>`（行内）与 `<pre><code>`（代码块）组合；`kbd`/`samp`/`var` 按需取用。
:::

## 3.6 内容分组小结

| 场景 | 用什么 |
| --- | --- |
| 一段完整的话 | `<p>` |
| 独立的次要提示 | `<small>` 配合 `<p>` |
| 引用别人的话（长） | `<blockquote>` |
| 引用别人的话（短） | `<q>` |
| 代码 | `<code>` / `<pre>` |
| 强制断行 | `<br>`（慎用） |

## 本章小结

- h1 唯一、不跳级、不为字号选标签
- 段落用 p，br 只给"必须断行"的场景
- strong/em 带语义优于 b/i；del/ins 记录修订
- 引用三兄弟 blockquote/q/cite；代码用 code 与 pre+code
