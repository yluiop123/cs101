# Tailwind CSS 教程

> 状态：编写中 · 共 8 章 · 预计 4 小时

Tailwind CSS 是"原子化/工具类优先"的 CSS 框架：不写传统样式表，而是把成千上万个预定义的小工具类直接组合在 HTML 上，配合响应式与状态变体，快速搭建 appearance 一致的界面。它已成为现代前端（Vue/React 项目）最流行的样式方案之一。
