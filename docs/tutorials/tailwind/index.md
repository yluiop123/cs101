# Tailwind CSS 教程

> 状态：可学习 · 共 8 章 · 预计 4 小时

Tailwind CSS 是"工具类优先"的 CSS 框架：不写传统样式表，而是把预定义的小工具类直接组合在 HTML 上，配合响应式前缀与状态变体，快速搭建视觉一致的界面。本教程基于 v4（CSS-first 配置），工具类与 v3 基本通用。

## 前置教程

- [CSS 教程](/tutorials/css/)：需要理解盒子模型与 Flex/Grid 布局（工具类就是这些概念的封装）
- [Node.js 与包管理教程](/tutorials/nodejs/)：npm 安装依赖

## 你将学到

- 工具类优先的开发思维，与传统 CSS 的关系
- 盒模型、排版、颜色、阴影等核心工具类体系
- 响应式前缀（sm:/md:/lg:）与 hover:/focus: 状态变体
