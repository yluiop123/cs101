# 第 10 章 · DOM（上）：查找与操作

**本章目标：**

- 理解 DOM 树与浏览器的渲染关系
- 熟练掌握元素查询的现代 API
- 掌握增删改元素与样式类操作

## 10.1 DOM：页面的编程接口

浏览器把 HTML 解析成一棵**树**，每个标签/文本都是节点（node），JS 通过 DOM（Document Object Model，文档对象模型）API 读写这棵树：

```html
<body>                      ← document.body
  <div id="app">            ← 元素节点
    <h1>标题</h1>           ← 元素节点 + 文本子节点
    <ul>
      <li>一</li>           ← 列表项节点
    </ul>
  </div>
</body>
```

改 DOM = 改页面：增删节点、改文字、改样式，浏览器实时重新渲染。

## 10.2 查找元素

```js
// 现代首选：querySelector 系列（CSS 选择器语法）
const box = document.querySelector('.box');        // 第一个匹配
const items = document.querySelectorAll('.item');  // 全部匹配（NodeList）

// 老牌专用 API（更快，写法死板）
document.getElementById('app');      // 按 id
document.getElementsByClassName('item');  // 按 class（HTMLCollection）
document.getElementsByTagName('li');

// 在某个元素内部继续找（缩小范围）
box.querySelector('span');
box.closest('.card');      // 向上找最近的匹配祖先
```

::: tip querySelectorAll 是"静态快照"
返回的 NodeList 不随 DOM 变化自动更新；遍历用 `for...of` 或 `forEach`。
:::

## 10.3 读写内容

```js
const el = document.querySelector('h1');

el.textContent = '新标题';    // 纯文本（推荐，自动转义，安全）
el.innerHTML = '<b>加粗</b>'; // 解析 HTML（有 XSS 风险，见下方警告）
el.innerText;                 // 渲染后的可见文本（读常用）

// 表单控件的值用 value
const input = document.querySelector('input');
input.value;   // 读取用户输入
```

::: danger innerHTML 与 XSS
`innerHTML` 会把字符串当 HTML 执行。若内容来自用户输入（如评论），攻击者可注入 `<script>` 窃取信息——这是 **XSS（跨站脚本攻击）**。原则：用户内容一律 `textContent`；必须用 innerHTML 时先做转义。
:::

## 10.4 操作属性与 data-*

```js
const img = document.querySelector('img');

// 标准属性直接读写
img.src = './new.png';
img.alt = '新图片';
input.disabled = true;

// 任意属性：setAttribute / getAttribute
el.setAttribute('data-id', '1024');
el.getAttribute('data-id');

// data-* 的便捷读写（HTML 第 10 章呼应）
el.dataset.id;      // '1024'
el.dataset.userId;  // 对应 data-user-id
```

## 10.5 class 与样式操作

```js
const box = document.querySelector('.box');

// classList：class 的增删改查（首选）
box.classList.add('active');
box.classList.remove('active');
box.classList.toggle('active');   // 有则删无则加（开关）
box.classList.contains('active'); // 是否包含

// 行内样式：属性名用驼峰
box.style.backgroundColor = '#2563eb';
box.style.display = 'none';

// 批量样式：改 class 永远优于逐条改 style
box.style.cssText = 'color: red; font-size: 14px;';  // 少用
```

::: danger 样式写在 CSS，JS 只切换类
`el.style.xxx` 逐条硬编码难以维护。正确姿势：CSS 里写好 `.active { ... }`，JS 只负责 `classList.toggle('active')`——"结构样式分离"在动态行为上的延续。
:::

## 10.6 创建、插入与删除节点

```js
const list = document.querySelector('ul');

// 1. 创建
const li = document.createElement('li');
li.textContent = '新列表项';
li.classList.add('item');

// 2. 插入
list.appendChild(li);                 // 追加到最后
list.prepend(li);                     // 插到最前
list.before(li);                      // 插到 list 前面
list.after(li);                       // 插到 list 后面
list.replaceWith(newEl);              // 替换

// 3. 删除
li.remove();                          // 自我删除（现代 API）
list.removeChild(list.firstChild);    // 老写法

// 克隆
const copy = li.cloneNode(true);      // true = 连子节点一起复制
```

## 10.7 综合示例：动态渲染列表

```html
<ul id="todo-list"></ul>

<script>
  const todos = [
    { id: 1, text: '学 HTML', done: true },
    { id: 2, text: '学 CSS', done: false },
  ];

  const ul = document.querySelector('#todo-list');

  // 模板字符串 + innerHTML 批量渲染（数据是本地常量，安全）
  ul.innerHTML = todos
    .map((t) => `<li class="${t.done ? 'done' : ''}">${t.text}</li>`)
    .join('');

  // 动态创建 + 事件绑定的方式（第 11 章深化）
  const newLi = document.createElement('li');
  newLi.textContent = '学 JS';
  ul.appendChild(newLi);
</script>
```

"数据 → 渲染函数 → DOM"的模式是所有前端框架（Vue/React）的心智雏形。

## 本章小结

- DOM 是 HTML 的树形编程接口，改 DOM 即改页面
- 查询用 `querySelector / querySelectorAll`，范围缩小用 `closest`
- 用户内容用 `textContent` 防 XSS；样式切换用 `classList.toggle`
- 增删用 `createElement + appendChild + remove`，批量渲染用模板字符串
