# 第 11 章 · DOM（下）：事件处理

**本章目标：**

- 掌握 addEventListener 与事件对象
- 理解冒泡、捕获与事件委托
- 完成常见交互场景实战

## 11.1 监听事件：addEventListener

```js
const btn = document.querySelector('#btn');

btn.addEventListener('click', (event) => {
  console.log('按钮被点击了');
});

// 常用事件类型
// 鼠标：click / dblclick / mouseenter / mouseleave / contextmenu
// 键盘：keydown / keyup
// 表单：input / change / submit / focus / blur
// 页面：DOMContentLoaded / scroll / resize
```

::: tip 同一事件可挂多个监听器
`onclick = fn` 的老写法会被覆盖；`addEventListener` 可以叠加多个监听器，且便于移除（保存函数引用后 `removeEventListener`）。
:::

## 11.2 事件对象：event

回调收到的 event 对象携带事件的全部信息：

```js
input.addEventListener('keydown', (e) => {
  e.key;          // 按下的键：'Enter' / 'Escape' / 'a'
  if (e.key === 'Enter') submit();
});

form.addEventListener('submit', (e) => {
  e.preventDefault();   // 阻止默认行为：表单不再刷新页面！
  // 在这里用 fetch 提交数据（第 13 章）
});

a.addEventListener('click', (e) => {
  e.preventDefault();   // 阻止链接跳转
});
```

最高频的两个操作：`preventDefault()` 阻止默认行为、读 `e.target`（事件发生的目标元素）。

## 11.3 事件流：捕获与冒泡

点击一个元素时，事件经历三个阶段：

```text
捕获阶段：window → document → ... → 父元素 → 目标（自上而下）
目标阶段：事件到达目标元素
冒泡阶段：目标 → 父元素 → ... → document（自下而上，默认监听的是这个阶段）
```

```js
// 第三个参数 true = 在捕获阶段监听（极少用）
el.addEventListener('click', fn, true);
```

冒泡意味着：**点子元素，父元素的监听器也会触发**——这既是"意外触发"的来源，也是事件委托的基础。

## 11.4 事件委托：一个监听器管一片

给**父元素**挂一个监听器，利用冒泡统一处理所有子元素的事件：

```js
// 需求：列表项可能随时增删，给每个 li 单独绑定太浪费
const ul = document.querySelector('ul');

ul.addEventListener('click', (e) => {
  const li = e.target.closest('li');   // 从点击处向上找 li
  if (!li) return;                     // 点在空白处，忽略
  console.log('点击了：', li.textContent);
  li.classList.toggle('done');
});
```

好处：动态新增的子元素**无需重新绑定**；1000 个 li 只花 1 个监听器的内存。

```html

  .delegate-demo ul { list-style: none; padding: 0; margin: 8px 0; }
  .delegate-demo li { padding: 8px 12px; border: 1px solid #e2e8f0; border-radius: 6px; margin-bottom: 6px; cursor: pointer; font-size: 13px; }
  .delegate-demo li.done { background: #dcfce7; text-decoration: line-through; color: #16a34a; }
  .delegate-demo .add-btn { border: 1px dashed #2563eb; color: #2563eb; background: #fff; border-radius: 6px; padding: 6px 12px; cursor: pointer; font-size: 13px; }
</style>

<div class="delegate-demo">
  <ul id="task-list">
    <li>任务一：点我试试（事件委托）</li>
    <li>任务二：再点一个</li>
  </ul>
  <button class="add-btn" onclick="document.getElementById('task-list').insertAdjacentHTML('beforeend', '<li>新任务（无需重新绑定，点了就有效）</li>')">+ 添加任务</button>
</div>

<script>
  document.getElementById('task-list').addEventListener('click', (e) => {
    const li = e.target.closest('li');
    if (li) li.classList.toggle('done');
  });
</script>
```

::: info 体验委托
把这段代码保存为本地 HTML 文件（VS Code + Live Server，见 [HTML 教程](/tutorials/html/)第 1 章）运行：点击任意任务切换完成状态；点"+ 添加任务"新增一项后**直接点击新任务**——它也能响应，因为监听器绑在父元素 ul 上，而非每个 li 各自绑定。
:::

## 11.5 常见交互模式速查

```js
// 1. 输入实时响应（input 事件，每次键入触发）
searchInput.addEventListener('input', (e) => {
  const keyword = e.target.value.trim();
  renderList(filterList(keyword));
});

// 2. 表单提交接管
form.addEventListener('submit', (e) => {
  e.preventDefault();
  const data = Object.fromEntries(new FormData(form));
  console.log(data);   // { name: '...', email: '...' }
});

// 3. 按键快捷键
document.addEventListener('keydown', (e) => {
  if (e.key === 'Escape') closeModal();
  if ((e.ctrlKey || e.metaKey) && e.key === 's') {
    e.preventDefault();
    save();
  }
});

// 4. 防抖：输入停止 300ms 后才搜索
let timer;
searchInput.addEventListener('input', (e) => {
  clearTimeout(timer);
  timer = setTimeout(() => doSearch(e.target.value), 300);
});
```

## 11.6 综合示例：受控的 todo 交互层

```js
const form = document.querySelector('#todo-form');
const list = document.querySelector('#todo-list');
let todos = [];   // 数据层（第 6 章）

function render() {
  list.innerHTML = todos
    .map((t) => `<li data-id="${t.id}" class="${t.done ? 'done' : ''}">${t.text}</li>`)
    .join('');
}

form.addEventListener('submit', (e) => {
  e.preventDefault();
  const text = form.querySelector('input').value.trim();
  if (!text) return;
  todos = [...todos, { id: Date.now(), text, done: false }];
  form.reset();
  render();
});

list.addEventListener('click', (e) => {
  const li = e.target.closest('li');
  if (!li) return;
  const id = Number(li.dataset.id);
  todos = todos.map((t) => (t.id === id ? { ...t, done: !t.done } : t));
  render();
});

render();
```

"数据层（todos 数组）→ render() 全量重绘 → 事件修改数据再重绘"——这个循环就是待办清单实战（第 14 章）的骨架。

## 本章小结

- 一律 `addEventListener`；表单提交先 `preventDefault()`
- 事件流 = 捕获（下）→ 目标 → 冒泡（上），默认监听冒泡
- 事件委托：父元素监听 + `e.target.closest()` 匹配，动态子元素零成本
- 高频模式：input 实时响应、keydown 快捷键、防抖
