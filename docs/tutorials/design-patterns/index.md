# 设计模式教程

> 状态：可学习 · 共 8 章 · 预计 8 小时

设计模式不是要背下来的 23 个类图，而是给"反复出现的问题—解法配对"起的名字。本教程以面向对象五大原则为主线，按创建型、结构型、行为型三类逐个拆解：每种模式都回答"不用它会长什么样、用了之后改善什么、要付出什么代价"，示例代码以 Python 3 为主，必要处给出 Java 对照。

## 前置教程

- [Java 教程](/tutorials/java/)：类、接口、继承与泛型语法——模式讨论的最小语言载体
- [设计相关的数据结构与算法教程](/tutorials/dsa/)：树、图与查找结构——组合树和享元池的分析基础

## 你将学到

- SOLID 五条原则各自治什么病，如何对着一段代码找违反点
- 单例的三种写法、线程安全初始化与全局状态的测试代价
- 用工厂族与建造者隔离创建决定，用适配器/装饰器/代理/外观重组连接
- 桥接拆双维度继承、组合统一树处理、享元切内外蕴状态、依赖注入的装配取舍
- 每种模式的"不用 → 用了 → 代价"三段评估与选型表
- 何时不用模式：语言原生能力（一等函数、生成器）已覆盖大半场景
