# Node.js 与包管理教程

> 状态：可学习 · 共 12 章 · 预计 6 小时

Node.js 让 JavaScript 跑在浏览器之外（服务器、命令行工具），npm / pnpm 则是围绕它建立的包管理体系——现代前端开发的一切工具（Vite、Vue、React）都依赖这套环境。本教程把它们作为一个整体系统学习。
