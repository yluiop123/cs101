# 第 2 章 · 元字符与字符类

**本章目标：**

- 掌握最核心的元字符：`.`、`\`、`^`、`$`
- 熟练使用字符类 `[...]` 与反义
- 学会预定义字符类 `\d` `\w` `\s`

## 2.1 点号：`.`

`.` 匹配**除换行符外**的任意单个字符：

```js
/h.t/.test('hat')  // true —— h任意字符t
/h.t/.test('ht')   // false —— 中间必须有且只有一个字符
```

`h.t` 能匹配 hat、hot、h2t、h t……"通配一位"是它最常用的用途。

## 2.2 转义：`\`

想匹配元字符本身，在前面加反斜杠：

```js
/3\.14/.test('π≈3.14')   // true —— 匹配字面上的点
/3.14/.test('3x14')      // true —— 注意！这也匹配了，因为 . 是通配
```

::: warning 经典陷阱
URL 中的 `.` 不转义会意外匹配：`/www.baidu.com/` 能匹配 `www.baiduXcom`。匹配字面文本时，元字符一律转义。
:::

## 2.3 字符类：`[...]`

方括号匹配"**括号内任意一个**字符"：

```js
/[aeiou]/.test('hello')   // true —— 含有任一元音
/gr[ae]y/.test('gray')    // true
/gr[ae]y/.test('grey')    // true —— 两种拼写都支持
/[Pp]ython/               // Python 或 python
```

### 范围：`-`

```js
/[a-z]/     // 一位小写字母
/[A-Za-z]/  // 一位字母（不分大小写）
/[0-9]/     // 一位数字
/[a-zA-Z0-9]/  // 一位字母或数字
```

::: warning 范围按字符编码
`[a-Z]` 不是"所有字母"——小写 a 的编码大于大写 Z，此写法非法或反直觉。老老实实写 `[a-zA-Z]`。
:::

### 反义：`^` 放在开头

`^` 放在字符类**内部第一个位置**，表示"除这些之外"：

```js
/[^0-9]/.test('abc')  // true —— 存在非数字字符
```

注意与"锚点 `^`"（行首，下一节）区分：**在字符类内的 `^` 是取反，在外的 `^` 是行首**。

## 2.4 锚点：`^` 与 `$`

锚点不匹配任何字符，只匹配"位置"：

```js
/^cat/    // 以 cat 开头
/cat$/    // 以 cat 结尾
/^cat$/   // 整个字符串恰好是 cat
```

```js
/^1[3-9]\d{9}$/  // 手机号校验的标准姿势：^ 和 $ 锁定整串
```

::: danger 校验必须加锚点
做"格式校验"（手机号、邮箱、密码规则）时，**不加 `^...$` 等于没校验**——`/^1\d{10}/` 能通过 `19999999999999999` 这种垃圾输入。
:::

## 2.5 预定义字符类

常用缩写，务必背熟（它们是正则的"基本词汇"）：

| 写法 | 含义 | 等价于 |
| --- | --- | --- |
| `\d` | 数字 | `[0-9]` |
| `\D` | 非数字 | `[^0-9]` |
| `\w` | 字母/数字/下划线 | `[A-Za-z0-9_]` |
| `\W` | 非单词字符 | `[^A-Za-z0-9_]` |
| `\s` | 空白（空格/Tab/换行） | |
| `\S` | 非空白 | |
| `\b` | 单词边界（位置） | |

实践示例：

```js
/\d/.test('abc123')    // true —— 含数字
/\s/.test('hello world')  // true —— 含空白
/\bcat\b/              // 匹配独立的 cat，不匹配 category
```

## 2.6 综合练习：座位号模式

回顾第 1 章的三步法，把"座位号（一个大写字母 + 1~2 位数字，如 A12、B5）"翻译成正则：

```text
第一步结构：字母段 + 数字段
第二步类型：字母段 = [A-Z]；数字段 = \d
第三步次数：数字段 1~2 次 → {1,2}
锁整串：^...$
```

```js
/^[A-Z]\d{1,2}$/.test('A12')  // true
/^[A-Z]\d{1,2}$/.test('b5')   // false —— 小写被排除
```

## 本章小结

- `.` 通配单字符；`\` 转义元字符
- 字符类 `[...]` 选一个，`^` 开头取反，`-` 表范围
- `^`/`$` 锚定位置，校验必须锁整串
- 背熟 `\d` `\w` `\s` 三兄弟与反向大写
