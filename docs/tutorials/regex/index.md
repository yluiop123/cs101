# 正则表达式教程

> 状态：可学习 · 共 5 章 · 预计 2 小时

正则表达式（Regular Expression，简称 regex）是用一个字符串描述"文本匹配规则"的语言。校验手机号、提取网页内容、批量替换文本——凡是处理文本的场景，正则都是效率利器。

本教程从匹配思维讲起，逐层掌握元字符、量词、分组与引用，并通过高频实战案例（邮箱/手机号校验、日志提取、批量替换）巩固，最后对比各主流语言中的正则用法差异。
