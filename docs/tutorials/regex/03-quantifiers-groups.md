# 第 3 章 · 量词、分组与引用

**本章目标：**

- 熟练使用五种量词，理解贪婪与懒惰
- 掌握分组 `(...)` 与或 `|`
- 学会引用分组与正向断言

## 3.1 量词：出现几次

量词（quantifier）控制前面元素的出现次数：

| 量词 | 含义 | 示例 |
| --- | --- | --- |
| `*` | 0 次或多次 | `\d*`：空串、5、123 都匹配 |
| `+` | 1 次或多次 | `\d+`：一个及以上数字 |
| `?` | 0 次或 1 次 | `colou?r`：color / colour |
| `{n}` | 恰好 n 次 | `\d{4}`：恰好 4 位数字 |
| `{n,}` | 至少 n 次 | `\d{3,}`：3 位及以上 |
| `{n,m}` | n 到 m 次 | `\d{2,8}`：2~8 位数字 |

```js
/^\d{4}-\d{2}-\d{2}$/   // 日期格式 2024-01-15
/^1[3-9]\d{9}$/         // 手机号：13~19 开头共 11 位
```

::: tip 记忆技巧
`?` 读作"可有可无"；`+` 读作"至少一个"；`*` 读作"有没有都行"。三者覆盖 90% 场景，`{n,m}` 精确控制。
:::

## 3.2 贪婪与懒惰

量词默认**贪婪（greedy）**：尽可能多吃字符。加 `?` 变成**懒惰（lazy）**：能少就少。

```js
'aaa'.match(/a+/)      // 'aaa'  —— 贪婪，全吃
'aaa'.match(/a+?/)     // 'a'    —— 懒惰，吃一个就停

// 经典场景：提取 HTML 标签内容
'<b>hi</b><b>ok</b>'.match(/<b>(.*)<\/b>/)   // 贪婪：捕获 "hi</b><b>ok"（跨标签！）
'<b>hi</b><b>ok</b>'.match(/<b>(.*?)<\/b>/)  // 懒惰：捕获 "hi" ✓
```

::: danger 贪婪陷阱
跨标签、跨引号的"吞并"几乎都源于贪婪匹配。处理成对结构（标签、引号）时，优先考虑 `.*?` 懒惰模式。
:::

## 3.3 分组：`(...)`

圆括号把多个元素打包成一个整体，量词可以直接作用于组：

```js
/(ab)+/     // ab ab ab...
/(\d{1,3}\.){3}\d{1,3}/   // 简化版 IP 格式：如 192.168.1.1
/^(ab|cd)+$/              // abcd、cdab 都能匹配
```

没有分组时，量词只管**紧邻的那一个元素**：`ab+` 是"a 加一个及以上 b"，完全不同于 `(ab)+`。

## 3.4 或：`|`

竖线表示"左右任选其一"，**优先级最低**，通常与分组连用：

```js
/cat|dog/         // cat 或 dog
/(cat|dog)s?/     // cat、cats、dog、dogs
/^(java|python|go)$/   // 整串必须是三者之一
```

::: warning 括号决定作用域
`/^cat|dog$/` 的意思是"以 cat 开头"**或**"以 dog 结尾"——不是"整串是 cat 或 dog"。校验类需求永远把 `|` 包进分组再加锚点。
:::

## 3.5 引用分组：`$1` 与 `\1`

分组同时会"捕获"内容，可在替换或模式内引用：

### 替换中引用

```js
// 交换年与日的位置：2024-01-15 → 15/01/2024
'2024-01-15'.replace(/(\d{4})-(\d{2})-(\d{2})/, '$3/$2/$1')
```

`$1`、`$2`、`$3` 按分组出现的顺序对应捕获内容。

### 模式内反向引用

```js
/(\w+) \1/.test('hello hello')  // true —— \1 要求与第一个分组内容相同
```

### 非捕获分组：`(?:...)`

只想"分组"不想要"捕获"（避免占用 `$1` 编号、提升可读性）：

```js
/(?:ab)+(\d+)/   // (?:) 只打包不捕获，$1 永远是数字部分
```

## 3.6 断言（进阶预告）

断言（assertion）"只看位置不加内容"：

```js
/\d+(?=元)/    // 正向先行：后面是"元"的数字（不包含"元"）
'苹果5元，香蕉3斤'.match(/\d+(?=元)/)[0]   // '5'
```

| 写法 | 名称 | 含义 |
| --- | --- | --- |
| `(?=x)` | 正向先行 | 后面紧跟 x |
| `(?!x)` | 否定先行 | 后面不能是 x |
| `(?<=y)` | 正向后行 | 前面是 y（较新语法） |
| `(?<!y)` | 否定后行 | 前面不能是 y |

## 本章小结

- 量词五式：`*` `+` `?` `{n}` `{n,m}`；默认贪婪，加 `?` 变懒惰
- 分组 `(...)` 让量词作用于整体；`|` 优先级低，校验必须包进分组
- `$1` 引用捕获做替换；`(?:...)` 只分组不捕获
- 断言 `(?=)` `(?!)` "只看不用"，叠加条件不消耗字符
