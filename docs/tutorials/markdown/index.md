# Markdown 教程

> 状态：可学习 · 共 4 章 · 预计 1 小时

Markdown 是一种轻量级标记语言，用简单的符号描述标题、列表、链接等格式，让作者专注于内容本身。它是技术写作的事实标准：GitHub 的 README、掘金/CSDN 的文章、各类文档站都基于 Markdown。

本教程覆盖基础语法、表格与代码块、GFM 扩展语法，以及完整的写作工具链。

- 无需编程基础，会打字即可
