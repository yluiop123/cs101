# Angular 教程

> 状态：编写中 · 共 12 章 · 预计 10 小时

Angular 是 Google 开发的企业级前端框架，"大而全"是其特点：路由、HTTP、表单、依赖注入、测试全部内置，配合 TypeScript 形成强约束的工程体系。它广泛存在于大型企业系统与外企项目中。本教程定位为入门，RxJS 等深水区点到为止。
