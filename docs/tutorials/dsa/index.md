# 数据结构与算法教程

> 状态：可学习 · 共 12 章 · 预计 12 小时

数据结构与算法不是"背 20 种结构 + 10 种排序"，而是一门关于**取舍**的学问：同一份数据放进不同结构里，随机访问、插入删除、有序性、内存开销会此消彼长；同一个问题换一种思路，耗时能从几小时降到几毫秒。本教程从复杂度分析讲起，沿着数组、链表、栈队列、哈希表、树、堆、图的主线把结构讲透，再用排序、查找、递归、动态规划、贪心回溯把算法串起来。全部示例代码使用 Python 3，每章结尾都有可直接运行的完整脚本。

## 你将学到

- 用大 O 表示法估算循环、递归与空间开销，并区分最坏、平均、摊还三种口径
- 数组、链表、栈、队列、哈希表、树、堆各自的内部机制与真实代价
- 双指针、单调栈、滑动窗口、迭代式遍历这些高频解题技巧的模板与错例
- 动态数组扩容、哈希表再哈希、BST 平衡这些"看不见但会要命"的机制
- Top-K、合并 K 路、表达式求值、LRU 缓存等经典问题的完整实现
- 面对一个新需求，能按操作画像快速选出最合适的数据结构
