# Java 教程

> 状态：可学习 · 共 15 章 · 预计 12 小时

Java 是企业级后端的常青树：强类型、面向对象、跨平台（一次编写，到处运行），国内大厂后端、Android、大数据生态（Hadoop/Flink）都以它为基石。本教程基于 JDK 21（LTS），从基础语法讲到集合、多线程与反射，为 Spring Boot 打底。
