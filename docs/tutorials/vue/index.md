# Vue 3 教程

> 状态：可学习 · 共 12 章 · 预计 10 小时

Vue 是一款渐进式 JavaScript 框架，以平缓的学习曲线和优秀的中文文档著称，在国内使用率极高。Vue 3 的组合式 API（Composition API）让逻辑复用与大型项目组织能力大幅提升。本教程从模板语法讲到路由、状态管理与完整项目实战。
