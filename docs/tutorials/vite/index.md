# Vite 教程

> 状态：可学习 · 共 6 章 · 预计 3 小时

Vite（法语"快"）是基于原生 ES Module 的下一代前端构建工具，由 Vue 作者尤雨溪开发，如今已是 Vue、React 等主流框架官方脚手架的底层。冷启动快、热更新快、开箱即用——它重新定义了前端开发体验。
