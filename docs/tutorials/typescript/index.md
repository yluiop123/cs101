# TypeScript 教程

> 状态：编写中 · 共 10 章 · 预计 7 小时

TypeScript 是 JavaScript 的超集，在 JS 之上增加了**静态类型系统**。它能在写代码时（而非上线后）就发现类型错误，已成为中大型前端项目的标配，Angular 甚至强制使用。本教程从基础类型讲到泛型与工程化配置。

- [Node.js 与包管理教程](/tutorials/nodejs/)：npm 安装依赖与 scripts 的使用
