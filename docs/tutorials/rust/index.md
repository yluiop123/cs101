# Rust 教程

> 状态：编写中 · 共 14 章 · 预计 12 小时

Rust 是系统级语言的现代答案：**没有 GC 却内存安全**（所有权机制在编译期消灭空指针与数据竞争）、性能对标 C/C++、工具链体验对标现代语言。它连续多年霸榜"最受喜爱语言"，正快速进入后端、CLI 与基础设施领域。本教程从所有权讲到并发，尾部以 Axum 完成 Web 服务初见。
