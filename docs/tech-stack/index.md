# 技术栈路线

从核心技术出发，横向拓展到不同的应用场景。适合以某一门语言或技术为核心，逐步扩大技术广度的学习者。

## 编程语言

| 核心技术 | 可扩展方向 |
|---------|-----------|
| [Java](./java) | Web开发、企业系统、移动开发、大数据、AI后端 |
| [Python](./python) | Web开发、数据科学/AI、自动化运维、金融科技 |
| [JavaScript / TypeScript](./javascript-typescript) | 前端开发、全栈开发、WebGIS |
| [Go](./go) | 后端高并发、微服务、云原生 |
| [C / C++](./c-cpp) | 系统/嵌入式、高性能计算、驱动开发 |
| [Rust](./rust) | 系统编程、WebAssembly、区块链开发 |
| [C#](./c-sharp) | 游戏开发（Unity）、企业应用（.NET） |
| [Kotlin / Swift / Dart](./kotlin-swift-dart) | Android、iOS、Flutter 跨平台开发 |

## 数据库

| 技术 | 说明 |

| [PostgreSQL](./postgresql) | 功能强大的开源关系型数据库 |
