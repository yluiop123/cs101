# 计算机科学

计算机科学是技术领域的根基，涵盖从底层硬件到上层应用的完整知识体系。掌握计算机科学基础，有助于更深入地理解编程语言、框架和系统设计背后的原理。

## 核心领域

| 领域 | 说明 |
|------|------|
| [数据结构与算法](./data-structures-algorithms) | 数组、链表、树、图、排序、搜索、动态规划等 |
| [计算机网络](./computer-networks) | TCP/IP、HTTP/HTTPS、DNS、网络安全协议等 |
| [操作系统](./operating-systems) | 进程管理、内存管理、文件系统、并发与同步等 |
| [数据库系统原理](./database-systems) | 关系模型、SQL、索引、事务、ACID、范式设计等 |
| [计算机组成原理](./computer-organization) | CPU 架构、存储器层次、指令流水线、I/O 系统等 |
| [编译原理](./compilers) | 词法分析、语法分析、语义分析、中间代码生成、优化等 |
| [离散数学](./discrete-mathematics) | 数理逻辑、集合论、图论、代数结构、组合数学等 |
| [软件工程](./software-engineering) | 软件过程、需求分析、设计模式、测试、项目管理等 |
| [人工智能导论](./artificial-intelligence) | 搜索、知识表示、机器学习、深度学习、强化学习等 |
| [计算机图形学](./computer-graphics) | 渲染管线、光照模型、纹理映射、光线追踪等 |
| [密码学](./cryptography) | 对称/公钥密码、哈希函数、数字签名、安全协议等 |

## 学习建议

- **打好基础**：建议先学习数据结构与算法和计算机组成原理，建立底层思维
- **理论与实践结合**：每学一个知识点，尝试用代码实现或搭建实验环境验证
- **体系化学习**：计算机科学各领域相互关联，建议按体系逐步深入
