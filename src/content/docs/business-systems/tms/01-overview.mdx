## 一句话定义

管运输订单、调度、承运商、运费和轨迹，让货物按时到、成本可算。

## 业务背景

运输靠电话和 Excel 调度，运费对账难，在途状态不透明，客户催货只能问司机。TMS 把订单、调度、承运商、运费和轨迹串起来。

它既降低运输成本，也让客服和客户能看到货物到哪了。

## 系统边界

TMS 管运输计划与执行，不管仓库作业（WMS）、不管财务总账（FMS）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 调度员 | 配载、派车、承运商选择 | 运输订单、调度、派车 |
| 物流专员 | 发货计划、在途跟踪 | 运单、轨迹 |
| 承运商/司机 | 接单、装货、签收 | 司机端、回单 |
| 财务 | 运费计算、对账、结算 | 运费、对账单 |
| 客服 | 查件、异常处理 | 轨迹、异常 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| WMS | 出库交接与装车 |
| OMS/ERP | 运输需求与订单 |
| FMS | 运费结算与付款 |
| 地图/定位平台 | 轨迹与路径规划 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 运单 | Waybill | 一次运输任务的凭证 |
| 配载 | Load Planning | 把多票货物分配到车辆 |
| 回单 | Proof of Delivery | 收货方签收的凭证 |
| 运费 | Freight | 按重量、体积、里程或协议计算的运输费用 |
| 在途 | In Transit | 货物已发出但尚未签收 |
