## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 运输订单 | 接单、拆合、优先级 | 物流专员 |
| 调度配载 | 车辆、线路、装载 | 调度 |
| 承运商 | 准入、报价、考核 | 采购、物流 |
| 运费 | 计费规则、对账、结算 | 财务 |
| 轨迹 | GPS、节点、异常 | 客服、调度 |
| 回单 | 签收、上传、核销 | 司机、财务 |

## 核心功能

### 智能配载

按体积、重量、线路和时效把货物分配到车辆。

### 承运商管理

维护承运商资质、线路报价和考核评分。

### 运费计算

按重量、体积、里程、区域和协议价自动算费。

### 在途跟踪

对接 GPS 或司机端上报节点，展示实时位置和预计到达。

### 回单核销

签收后上传回单，作为运费结算依据。

## 核心业务流程

### 运输下单到调度

- **触发条件**：销售发货或采购到货需要运输
- **参与角色**：物流专员、调度、承运商
- **流程步骤**：
  1. 创建运输订单
  2. 选择线路与时效
  3. 配载
  4. 指派承运商/车辆
  5. 司机接单
  6. 装车发运
- **输入 / 输出**：输入货物与收货信息，输出运单、派车单
- **异常与分支**：运力不足转外协；超载拆单；临时改址重算运费

### 在途跟踪

- **触发条件**：车辆发运
- **参与角色**：调度、客服、客户
- **流程步骤**：
  1. 采集定位/节点
  2. 更新在途状态
  3. 异常预警
  4. 处理
  5. 到达签收
- **输入 / 输出**：输入轨迹与节点，输出在途看板与预计到达
- **异常与分支**：偏航、滞留、温控异常触发告警；丢损走理赔

### 运费结算

- **触发条件**：回单签收
- **参与角色**：财务、物流、承运商
- **流程步骤**：
  1. 汇总运单
  2. 计算运费
  3. 承运商对账
  4. 差异处理
  5. 开票
  6. 付款
- **输入 / 输出**：输入运单与报价，输出对账单、发票、付款单
- **异常与分支**：回单缺失暂挂；重量体积争议复测；价格不符查协议

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 运输订单 | 待调度/已调度/运输中/已签收/已取消 | 调度、发运 | 运单 |
| 运单 | 已派车/已装车/在途/已签收/异常 | 发运、签收 | 回单 |
| 对账单 | 待对账/有差异/已确认/已结算 | 对账 | 付款 |
| 异常单 | 待处理/处理中/已关闭 | 处理 | 理赔/补发 |

## 业务规则

- 运单必须关联运输订单和承运商
- 超载、超限车辆不能派单
- 运费按协议价计算，手工改价需审批
- 回单未签收不能结算
- 异常必须登记处理结果
