**一句话定位**：管运输订单、调度、承运商、运费和轨迹，让货物按时到、成本可算。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 制造与供应链系统 |
| 典型用户 | 调度员、物流专员、承运商/司机、财务、客服 |
| 核心模块 | 运输订单、调度配载、承运商、运费、轨迹、回单 |
| 常见产品 | SAP Transportation Management、Oracle Transportation Management、唯智 TMS、蓝桥 TMS |
| 开源项目 | Odoo Fleet、ERPNext、OpenBoxes、Apache OFBiz |

## 这个系统解决什么问题

运输靠电话和 Excel 调度，运费对账难，在途状态不透明，客户催货只能问司机。TMS 把订单、调度、承运商、运费和轨迹串起来。

它既降低运输成本，也让客服和客户能看到货物到哪了。
