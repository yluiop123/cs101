## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 订单接入 | 多渠道订单统一接入 | 订单运营 |
| 订单校验 | 库存、价格、地址、风控 | 系统 |
| 拆合单 | 按规则拆分合并 | 订单运营 |
| 路由 | 仓店分配与优先级 | 订单运营 |
| 履约 | 发货、物流、签收 | 仓库、客服 |
| 售后 | 退货、换货、退款 | 客服 |
| 订单查询 | 全链路状态 | 客服、运营 |

## 核心功能

### 多渠道接单

对接电商平台、小程序、门店、电话等渠道，统一订单模型。

### 自动拆合

按仓库、商品、时效、赠品规则自动拆单或合单。

### 智能路由

按库存、距离、成本、时效选择履约仓或门店。

### 全链路状态

订单、支付、发货、物流、签收、售后状态一屏可查。

### 售后闭环

退货入库、退款、换货补发按流程流转。

## 核心业务流程

### 下单到发货

- **触发条件**：渠道产生新订单
- **参与角色**：订单运营、仓库、客服
- **流程步骤**：
  1. 接单
  2. 校验
  3. 锁库存
  4. 拆合单
  5. 路由
  6. 生成发货单
  7. 仓库发货
  8. 物流签收
- **输入 / 输出**：输入渠道订单，输出发货单、物流单、订单状态
- **异常与分支**：库存不足挂起或拆单；地址异常转客服；支付超时取消

### 拆单合单

- **触发条件**：订单包含多仓商品或满足合单规则
- **参与角色**：订单运营
- **流程步骤**：
  1. 识别规则
  2. 拆分/合并
  3. 重新锁库存
  4. 生成子单
  5. 通知仓库
- **输入 / 输出**：输入原订单与规则，输出子订单与发货任务
- **异常与分支**：拆单后运费变化需重算；合单失败回退原单

### 退款售后

- **触发条件**：客户申请退货退款
- **参与角色**：客服、仓库、财务
- **流程步骤**：
  1. 创建售后单
  2. 审核
  3. 退货入库
  4. 质检
  5. 退款
  6. 关闭
- **输入 / 输出**：输入售后申请，输出退货单、退款单
- **异常与分支**：超时未退货关闭；质检不合格拒退；部分退款按商品拆分

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 订单 | 待支付/待审核/待发货/已发货/已完成/已取消 | 审核、发货 | 发货单 |
| 发货单 | 待拣货/已发货/已签收 | 发货 | 物流单 |
| 售后单 | 待审核/待退货/待退款/已完成/已拒绝 | 审核、退款 | 退款单 |
| 退款单 | 待退款/已退款/已失败 | 退款 | 财务 |

## 业务规则

- 订单支付成功后才进入履约
- 库存锁定失败不能发货
- 拆单后子单金额之和必须等于原单
- 改址、取消在发货前才允许
- 退款金额不能超过实付金额
