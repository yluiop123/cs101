**一句话定位**：统一接单、拆单、路由、发货和售后，让多渠道订单有序流转。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 交易与零售系统 |
| 典型用户 | 订单运营、客服、仓库、财务 |
| 核心模块 | 订单接入、订单校验、拆合单、路由、履约、售后、订单查询 |
| 常见产品 | 京东订单中心、阿里交易中台、旺店通、聚水潭 |
| 开源项目 | Apache OFBiz、Odoo Sales、ERPNext Selling、Saleor |

## 这个系统解决什么问题

电商、门店、小程序、电话订单格式不同，库存不同步，拆单合单靠人工，售后状态乱。OMS 统一订单入口，做校验、拆合、路由、履约和售后。

它让订单从「进来」到「出去」的每一步都有状态，客服能查、仓库能拣、财务能对。
