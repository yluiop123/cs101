## 一句话定义

统一接单、拆单、路由、发货和售后，让多渠道订单有序流转。

## 业务背景

电商、门店、小程序、电话订单格式不同，库存不同步，拆单合单靠人工，售后状态乱。OMS 统一订单入口，做校验、拆合、路由、履约和售后。

它让订单从「进来」到「出去」的每一步都有状态，客服能查、仓库能拣、财务能对。

## 系统边界

OMS 管订单生命周期，不管商品主数据（PIM）、不管仓储作业（WMS）、不管支付账务（支付系统）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 订单运营 | 接单、审核、拆合、路由 | 订单列表、规则配置 |
| 客服 | 查单、改址、取消、售后 | 订单查询、售后单 |
| 仓库 | 接收发货任务、回传发货 | 发货单 |
| 财务 | 对账、退款 | 订单金额、退款 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| PIM | 商品与价格 |
| WMS | 发货与库存 |
| 支付/退款 | 支付状态与退款 |
| CRM/会员 | 客户与权益 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 拆单 | Order Splitting | 按仓库、商品类型或时效把一单拆成多单 |
| 合单 | Order Merging | 把同一收货人的多单合并发货 |
| 路由 | Order Routing | 决定订单由哪个仓库或门店履约 |
| 履约 | Fulfillment | 从接单到发货签收的全过程 |
| 售后单 | After-sales Order | 退货、换货、退款等售后请求 |
