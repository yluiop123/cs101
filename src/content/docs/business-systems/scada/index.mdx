**一句话定位**：采集设备与产线数据，做实时监控、报警和远程控制。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 制造与供应链系统 |
| 典型用户 | 值班员、设备工程师、工艺工程师、能源管理 |
| 核心模块 | 数据采集、画面组态、报警管理、趋势与历史、远程控制、报表 |
| 常见产品 | Ignition、WinCC、iFIX、组态王 |
| 开源项目 | FUXA、ScadaBR、OpenSCADA、ThingsBoard、Grafana |

## 这个系统解决什么问题

设备状态、温度、压力、产量散在各处，故障发现靠人巡检，历史数据留不下来。SCADA 把 PLC、传感器和仪表的数据采集上来，做画面监控、报警、趋势和历史存储。

它让值班人员在控制室就能看到现场状态，并在异常时第一时间收到报警。
