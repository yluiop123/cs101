## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 数据采集 | PLC、仪表、传感器通讯 | 设备工程师 |
| 画面组态 | 工艺流程图、设备状态 | 值班员 |
| 报警管理 | 分级、确认、推送 | 值班员 |
| 趋势与历史 | 实时曲线、历史查询 | 工艺 |
| 远程控制 | 开关、调节、操作票 | 值班员 |
| 报表 | 班报、日报、能耗 | 管理 |

## 核心功能

### 实时采集

按秒级或分钟级采集测点，支持 Modbus、OPC UA 等协议。

### 监控画面

用工艺图、设备图展示实时状态、数值和颜色报警。

### 分级报警

按严重程度分级，支持声光、短信、平台推送和确认闭环。

### 历史趋势

保存测点历史，支持多曲线对比和区间查询。

### 操作票

远程操作前填写操作票，记录操作人、时间和结果。

## 核心业务流程

### 实时监控与报警

- **触发条件**：测点越限或设备状态异常
- **参与角色**：值班员、设备工程师
- **流程步骤**：
  1. 采集数据
  2. 规则判断
  3. 生成报警
  4. 推送
  5. 现场确认
  6. 处理关闭
- **输入 / 输出**：输入测点数据，输出报警记录与处理结果
- **异常与分支**：通讯中断转通讯报警；误报可标记屏蔽并记录原因

### 历史数据查询

- **触发条件**：工艺分析或事故调查
- **参与角色**：工艺、设备、管理
- **流程步骤**：
  1. 选择测点与时间范围
  2. 查询历史库
  3. 曲线对比
  4. 导出报表
- **输入 / 输出**：输入查询条件，输出趋势图与数据表
- **异常与分支**：数据缺失检查采集链路；超长时间范围降采样

### 远程操作

- **触发条件**：需要调整设备状态或参数
- **参与角色**：值班员、值班长
- **流程步骤**：
  1. 填写操作票
  2. 审核
  3. 下发指令
  4. 现场确认
  5. 记录结果
- **输入 / 输出**：输入操作指令，输出设备状态变化与操作记录
- **异常与分支**：通讯失败重试；设备未就绪拒绝执行；紧急情况走急停

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 报警记录 | 产生/已确认/处理中/已关闭 | 确认、处理 | 关闭 |
| 操作票 | 待审核/已批准/已执行/已作废 | 审核、执行 | 操作记录 |
| 点表 | 草稿/已启用/已停用 | 启用 | 采集 |
| 班报 | 待生成/已生成 | 生成 | 归档 |

## 业务规则

- 所有远程操作必须留痕并关联操作票
- 报警必须确认并填写处理结果才能关闭
- 通讯中断要单独报警，不能静默
- 历史数据保存周期按合规要求配置
- 关键测点修改需双人复核
