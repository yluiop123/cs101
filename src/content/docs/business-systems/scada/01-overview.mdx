## 一句话定义

采集设备与产线数据，做实时监控、报警和远程控制。

## 业务背景

设备状态、温度、压力、产量散在各处，故障发现靠人巡检，历史数据留不下来。SCADA 把 PLC、传感器和仪表的数据采集上来，做画面监控、报警、趋势和历史存储。

它让值班人员在控制室就能看到现场状态，并在异常时第一时间收到报警。

## 系统边界

SCADA 管监控与数据采集，不管生产订单与工单（MES）、不管控制逻辑编程（PLC/DCS 内部逻辑）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 值班员 | 监盘、确认报警、远程操作 | 监控画面、报警、操作票 |
| 设备工程师 | 点表、通讯、设备诊断 | 设备配置、通讯状态 |
| 工艺工程师 | 趋势分析、参数优化 | 趋势、历史数据 |
| 能源管理 | 能耗监测 | 能耗看板 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| PLC/DCS | 提供现场数据与执行控制 |
| MES | 接收产量、设备状态与停机 |
| EMS | 能耗数据 |
| IT 监控/告警平台 | 统一告警推送 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 点表 | Tag List | 需要采集的测点清单，含地址、类型、量程 |
| 组态 | Configuration | 用图形化方式配置监控画面和逻辑 |
| 报警 | Alarm | 测点越限或设备异常时产生的提醒 |
| 历史库 | Historian | 按时间序列存储的测点历史数据 |
| 远程控制 | Remote Control | 通过 SCADA 下发指令操作现场设备 |
