**一句话定位**：管门店收银、商品、促销、会员和日结，让每笔交易可查。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 交易与零售系统 |
| 典型用户 | 收银员、店长、运营、财务 |
| 核心模块 | 收银、商品价格、促销、支付、会员、退货、日结 |
| 常见产品 | 海鼎 POS、思迅 POS、银豹、美团收银 |
| 开源项目 | Odoo POS、UniCenta oPOS、Floreant POS、Openbravo POS |

## 这个系统解决什么问题

门店收银慢、价格不一致、促销难执行、日结对不上，是零售门店的常见问题。POS 把商品、价格、促销、支付、会员和小票集中到收银台。

它既要保证收银效率，也要把交易数据实时回传总部，支撑库存和经营分析。
