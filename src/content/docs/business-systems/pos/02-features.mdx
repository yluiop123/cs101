## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 收银 | 扫码、改价、挂单、结账 | 收银员 |
| 商品价格 | 商品查询、价格、库存 | 收银员 |
| 促销 | 折扣、满减、买赠、券 | 运营 |
| 支付 | 现金、刷卡、扫码、混合支付 | 收银员 |
| 会员 | 识别、积分、等级 | 收银员 |
| 退货 | 原单退货、无单退货 | 收银员、店长 |
| 日结 | 班结、日结、对账 | 店长、财务 |

## 核心功能

### 快速收银

扫码、称重、改价、挂单、快捷支付，减少排队时间。

### 促销执行

总部下发折扣、满减、买赠、优惠券，收银端自动计算。

### 会员识别

手机号、会员码、人脸识别，累计积分和消费记录。

### 退货授权

无单退货、超期退货需店长授权并留痕。

### 日结对账

按支付方式汇总应收实收，差异登记。

## 核心业务流程

### 收银结账

- **触发条件**：顾客到店选购商品
- **参与角色**：收银员、顾客
- **流程步骤**：
  1. 扫码商品
  2. 识别会员
  3. 计算促销
  4. 选择支付
  5. 收款
  6. 打印小票
  7. 库存扣减
- **输入 / 输出**：输入商品与支付，输出小票、交易流水、库存变动
- **异常与分支**：支付失败重试；价格异议查价；网络中断走离线收银

### 退货

- **触发条件**：顾客要求退货
- **参与角色**：收银员、店长
- **流程步骤**：
  1. 查原单
  2. 选择退货商品
  3. 授权
  4. 退款
  5. 库存回补
- **输入 / 输出**：输入原单与退货原因，输出退款记录、库存增加
- **异常与分支**：无原单需授权；超期退货按规则处理；部分退货按比例退券

### 日结对账

- **触发条件**：门店营业结束
- **参与角色**：店长、财务
- **流程步骤**：
  1. 汇总交易
  2. 按支付方式对账
  3. 登记差异
  4. 提交日结
  5. 生成报表
- **输入 / 输出**：输入当日流水，输出日结单、差异说明
- **异常与分支**：长短款登记；支付平台延迟到账标记在途

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 销售单 | 待支付/已支付/已退货/已作废 | 收款、退货 | 日结 |
| 退货单 | 待授权/已退款/已拒绝 | 授权、退款 | 库存回补 |
| 日结单 | 待提交/已提交/有差异 | 提交 | 财务对账 |
| 交接班单 | 待交接/已交接 | 交接 | 班结 |

## 业务规则

- 改价、折扣、无单退货需要权限授权
- 支付成功才能打印小票和扣减库存
- 日结后不允许修改当日交易
- 离线交易恢复网络后必须补传
- 退货必须关联原单或授权记录
