## 一句话定义

从合同起草、审批、签署、履约到归档，管住条款风险和付款节点。

## 业务背景

合同散在邮件和共享盘里，审批靠线下签字，履约节点没人盯，续签和付款容易漏。合同系统把模板、审批、签署、履约、归档串成一条线。

它既降低法务风险，也让业务和财务知道「这份合同现在到哪一步、下一步该做什么」。

## 系统边界

合同系统管合同文本与流程，不管业务订单执行（ERP/OMS）、不管诉讼案件（案件管理）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 法务 | 模板、条款审核、风险提示 | 合同审核、模板库、风险条款 |
| 业务人员 | 发起合同、跟进履约 | 合同起草、履约记录 |
| 财务 | 付款节点、发票、结算 | 付款计划、结算 |
| 行政 | 用印、归档 | 用印、档案 |
| 管理层 | 合同台账与风险 | 台账、报表 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| OA | 合同审批与用印流程 |
| ERP/OMS | 合同转订单、发货与开票 |
| FMS | 付款计划与应收应付 |
| 电子签平台 | 在线签署与存证 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 合同台账 | Contract Register | 所有合同的编号、相对方、金额、状态汇总 |
| 履约节点 | Performance Milestone | 交付、验收、付款等关键时间点 |
| 电子签名 | Electronic Signature | 符合法律要求的在线签署方式 |
| 合同变更 | Contract Amendment | 对已签合同条款的修改 |
| 相对方 | Counterparty | 合同另一方的企业或个人 |
