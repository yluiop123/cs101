## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 模板库 | 标准条款、模板分类 | 法务 |
| 起草与审批 | 在线起草、会签、版本 | 业务、法务 |
| 电子签署 | 签署任务、存证 | 业务、相对方 |
| 履约管理 | 交付、验收、付款节点 | 业务、财务 |

## 核心功能

### 模板与条款

按合同类型维护标准模板和可选条款，减少每次从零起草。

### 版本与比对

保留每次修改版本，支持条款差异比对。

### 审批流

按金额、类型、相对方风险配置法务、财务、管理层审批。

### 电子签署

发起签署任务，跟踪签署状态，保存签署存证。

### 履约提醒

按交付、验收、付款、到期时间自动提醒责任人。

## 核心业务流程

### 合同起草到签署

- **触发条件**：业务需要与客户或供应商签约
- **参与角色**：业务、法务、财务、管理层
- **流程步骤**：
  1. 选择模板
  2. 填写要素
  3. 条款审核
  4. 审批
  5. 电子签署
  6. 归档
- **输入 / 输出**：输入合同要素与附件，输出已签合同与台账记录
- **异常与分支**：非标条款转法务；审批不通过退回修改；签署超时提醒

### 履约与付款

- **触发条件**：合同进入履约期
- **参与角色**：业务、财务
- **流程步骤**：
  1. 登记交付
  2. 验收
  3. 发起付款
  4. 财务审核
  5. 付款
  6. 更新履约状态
- **输入 / 输出**：输入验收单与发票，输出付款记录与履约进度
- **异常与分支**：验收不合格暂缓付款；付款超合同比例需审批

### 续签与终止

- **触发条件**：合同临近到期或双方决定终止
- **参与角色**：业务、法务
- **流程步骤**：
  1. 到期提醒
  2. 评估续签
  3. 起草补充协议
  4. 审批签署
  5. 更新台账
- **输入 / 输出**：输入原合同与续签条件，输出新合同或终止记录
- **异常与分支**：逾期未续签自动预警；终止需确认违约条款

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 合同 | 草稿/审批中/待签署/已生效/已终止 | 审批、签署 | 履约 |
| 补充协议 | 草稿/审批中/已签署 | 审批、签署 | 合同变更 |
| 用印申请 | 待审批/已批准/已用印 | 审批、用印 | 归档 |
| 付款计划 | 待付款/部分付款/已付清 | 付款 | 履约记录 |

## 业务规则

- 合同编号按类型和年度自动生成
- 非标条款必须法务审核
- 合同金额与付款比例超权限需升级审批
- 已生效合同修改必须走补充协议
- 合同附件与签署存证不可删除
