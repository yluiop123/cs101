**一句话定位**：把客户、线索、商机、合同和售后放进一条链路，让销售过程可跟踪、可分析。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 企业通用系统 |
| 典型用户 | 销售人员、销售主管、市场人员、客服人员、管理层 |
| 核心模块 | 客户档案、线索管理、商机管理、报价与合同、销售分析、服务记录 |
| 常见产品 | Salesforce Sales Cloud、Microsoft Dynamics 365、纷享销客、销售易 |
| 开源项目 | SuiteCRM、EspoCRM、Twenty、Dolibarr |

## 这个系统解决什么问题

客户信息散在销售个人手里，线索跟进到哪一步没人知道，成交后服务记录又找不到。CRM 把「线索→商机→报价→合同→回款→服务」串成一条客户生命周期。

它既服务销售管理，也服务客户运营：谁在跟进、下一步做什么、客户价值多少，都能在系统里看到。
