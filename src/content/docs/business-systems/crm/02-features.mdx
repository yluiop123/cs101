## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 客户档案 | 客户、联系人、关系树 | 销售、客服 |
| 线索管理 | 线索获取、分配、清洗 | 市场、销售 |
| 商机管理 | 阶段、金额、赢单率 | 销售 |
| 报价与合同 | 报价单、合同、审批 | 销售、法务 |
| 销售分析 | 漏斗、业绩、预测 | 主管、管理层 |
| 服务记录 | 咨询、投诉、回访 | 客服 |

## 核心功能

### 线索分配

按区域、行业、来源或轮询规则把线索分配给销售，并设置跟进时限。

### 商机阶段

用阶段和赢单率描述销售进展，阶段推进触发任务和审批。

### 客户 360

把客户基本信息、历史订单、服务记录、回款情况汇总到一个页面。

### 销售预测

按商机阶段和金额加权，预测本季度可能成交的收入。

### 跟进提醒

长时间未跟进的线索和商机自动提醒，避免客户流失。

## 核心业务流程

### 线索到商机

- **触发条件**：市场活动、官网表单或转介绍产生线索
- **参与角色**：市场、销售
- **流程步骤**：
  1. 线索录入
  2. 线索清洗
  3. 分配销售
  4. 首次联系
  5. 确认意向
  6. 转为商机
- **输入 / 输出**：输入线索来源与联系方式，输出商机与跟进记录
- **异常与分支**：无效线索标记关闭；重复线索合并；长期未联系回收公海

### 商机到合同

- **触发条件**：客户确认需求与预算
- **参与角色**：销售、售前、法务、财务
- **流程步骤**：
  1. 需求确认
  2. 方案与报价
  3. 商务谈判
  4. 合同审批
  5. 签约
  6. 转订单
- **输入 / 输出**：输入商机与报价，输出合同、订单与回款计划
- **异常与分支**：报价超折扣权限需上级审批；合同条款异常转法务

### 成交后服务

- **触发条件**：客户提出咨询、投诉或续约
- **参与角色**：客服、销售、技术支持
- **流程步骤**：
  1. 创建服务记录
  2. 分派处理人
  3. 处理
  4. 回访
  5. 满意度评价
- **输入 / 输出**：输入客户问题，输出处理记录与满意度
- **异常与分支**：升级为投诉工单；涉及产品缺陷转研发

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 线索 | 新建/跟进中/已转商机/已关闭 | 分配、转化 | 商机 |
| 商机 | 初步接触/需求确认/报价/谈判/赢单/输单 | 阶段推进 | 报价单或合同 |
| 报价单 | 草稿/待审批/已发送/已接受/已拒绝 | 审批、发送 | 合同 |
| 服务记录 | 待处理/处理中/已解决/已关闭 | 分派、处理 | 回访 |

## 业务规则

- 同一客户下联系人去重，按手机号或邮箱识别
- 线索超过设定天数未跟进自动回收公海
- 报价折扣超过权限必须走审批
- 赢单商机才能生成合同
- 客户敏感信息按角色脱敏展示
