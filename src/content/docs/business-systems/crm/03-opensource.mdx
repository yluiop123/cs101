## 选型建议

- 先梳理销售阶段和线索分配规则，再选型，否则只是把混乱搬到线上
- 小团队可用 EspoCRM 或 Twenty 快速起步
- 需要和 ERP、客服、营销自动化打通时，优先看开放 API 和 webhook
