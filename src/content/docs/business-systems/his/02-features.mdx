## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 患者主索引 | 患者建档、合并、查询 | 挂号、收费 |
| 挂号预约 | 号源、排班、预约 | 挂号员、患者 |
| 门诊收费 | 挂号费、检查费、药费 | 收费员 |
| 门诊医生站 | 接诊、开医嘱、看结果 | 医生 |
| 住院管理 | 入院、床位、押金、出院 | 护士、收费 |
| 药房 | 发药、退药、库存 | 药师 |
| 医保 | 结算、上传、对账 | 医保办 |

## 核心功能

### 统一患者主索引

一个患者在院内只有一个主索引，关联门诊、住院、检验、影像记录。

### 挂号与号源

按科室、医生、时段放号，支持预约、退号、加号。

### 收费与发票

按项目计价，支持医保、自费、混合支付和电子发票。

### 医嘱闭环

开立、审核、收费、执行、发药、退药全流程状态。

### 医保结算

按医保目录和政策计算报销，支持异地和特殊病种。

## 核心业务流程

### 门诊就诊

- **触发条件**：患者挂号
- **参与角色**：患者、挂号员、医生、收费员、药师
- **流程步骤**：
  1. 挂号
  2. 分诊
  3. 医生接诊
  4. 开医嘱
  5. 收费
  6. 检查/取药
  7. 离院
- **输入 / 输出**：输入患者与号源，输出就诊记录、费用、处方
- **异常与分支**：退号退费；检查未做退费；药品缺货替代

### 住院办理

- **触发条件**：医生开具住院证
- **参与角色**：患者、护士、收费、医生
- **流程步骤**：
  1. 开住院证
  2. 登记入院
  3. 交押金
  4. 分配床位
  5. 住院医嘱
  6. 出院结算
- **输入 / 输出**：输入住院证与患者信息，输出住院号、床位、费用
- **异常与分支**：无床位候床；押金不足催缴；转科转院

### 医保结算

- **触发条件**：门诊或出院结算
- **参与角色**：收费员、医保办
- **流程步骤**：
  1. 读取医保信息
  2. 目录匹配
  3. 计算报销
  4. 结算
  5. 上传医保
  6. 打印票据
- **输入 / 输出**：输入费用明细，输出医保支付与个人自付
- **异常与分支**：目录不匹配自费；医保断网挂账；上传失败重传

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 挂号单 | 已挂号/已就诊/已退号 | 挂号、退号 | 就诊 |
| 收费单 | 待收费/已收费/已退费 | 收费 | 发票 |
| 住院记录 | 待入院/在院/已出院/已结算 | 入院、出院 | 结算 |
| 医保结算单 | 待结算/已结算/已上传 | 结算、上传 | 对账 |

## 业务规则

- 患者主索引必须唯一，重复档案要合并
- 收费项目必须维护价格和医保属性
- 未收费的医嘱不能执行或发药
- 退费必须关联原收费记录
- 医保上传失败不能重复结算
