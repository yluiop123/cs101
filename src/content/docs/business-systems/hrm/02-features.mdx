## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 组织管理 | 公司、部门、岗位、编制 | HR、管理层 |
| 员工档案 | 个人信息、合同、证照 | HR |
| 招聘管理 | 需求、候选人、面试、offer | 招聘 |
| 考勤假期 | 排班、打卡、请假、加班 | HR、员工 |
| 薪酬管理 | 工资核算、社保、个税、工资条 | 薪酬 |
| 绩效管理 | 目标、评估、结果应用 | 主管、HR |

## 核心功能

### 员工全生命周期

从候选人、offer、入职、转正、调岗到离职，每一步都有记录和审批。

### 考勤规则

支持多班次、弹性工时、外勤、补卡，按规则自动算出勤结果。

### 薪酬核算

按薪酬结构、考勤、绩效、社保个税规则批量算薪，生成工资条。

### 绩效目标

目标逐级对齐，周期内打分、校准、归档。

### 员工自助

员工自己查考勤、工资条、假期余额，提交请假和证明。

## 核心业务流程

### 招聘到入职

- **触发条件**：部门提出招聘需求
- **参与角色**：用人部门、HR、候选人
- **流程步骤**：
  1. 招聘需求审批
  2. 发布职位
  3. 筛选简历
  4. 面试
  5. 发 offer
  6. 入职办理
- **输入 / 输出**：输入编制与岗位要求，输出候选人、offer、员工档案
- **异常与分支**：编制不足需特批；候选人拒 offer 重新启动；背调不通过终止

### 月度算薪

- **触发条件**：考勤周期结束
- **参与角色**：薪酬专员、财务
- **流程步骤**：
  1. 锁定考勤
  2. 异动核对
  3. 绩效与奖金导入
  4. 算薪
  5. 复核
  6. 发放
  7. 入账
- **输入 / 输出**：输入考勤、薪酬结构、绩效结果，输出工资表、工资条、财务凭证
- **异常与分支**：考勤异常需补卡；新员工按天折算；离职结算单独处理

### 入转调离

- **触发条件**：转正、调岗、离职申请
- **参与角色**：HR、主管、员工
- **流程步骤**：
  1. 发起异动
  2. 审批
  3. 生效
  4. 同步权限与资产
  5. 归档
- **输入 / 输出**：输入异动类型与生效日，输出员工状态与组织关系
- **异常与分支**：离职需交接清单；调岗涉及薪酬变更需重新审批

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 招聘需求 | 草稿/审批中/招聘中/已关闭 | 审批、发布 | 候选人 |
| offer | 待确认/已接受/已拒绝/已过期 | 发送、确认 | 入职 |
| 请假单 | 待审批/已通过/已驳回/已销假 | 审批 | 考勤结果 |
| 工资表 | 草稿/已复核/已发放 | 复核、发放 | 工资条 |

## 业务规则

- 员工编号唯一，离职后保留历史档案
- 考勤结果锁定后不能直接改，需走补卡或异常审批
- 薪酬数据按角色脱敏，主管只能看本团队汇总
- 社保公积金基数按年度调整
- 离职员工权限在生效日自动回收
