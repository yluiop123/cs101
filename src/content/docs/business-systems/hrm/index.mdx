**一句话定位**：从招聘、入职、考勤、薪酬到绩效，管理员工全生命周期。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 企业通用系统 |
| 典型用户 | HR 专员、招聘人员、薪酬专员、部门主管、员工 |
| 核心模块 | 组织管理、员工档案、招聘管理、考勤假期、薪酬管理、绩效管理 |
| 常见产品 | Workday HCM、SAP SuccessFactors、北森、钉钉智能人事 |
| 开源项目 | OrangeHRM、Odoo HR、Frappe HR、Sentrifugo |

## 这个系统解决什么问题

员工信息散在 Excel、考勤机、工资表里，入转调离靠邮件通知，薪酬核算每月重复劳动。HRM 把组织、人员、考勤、薪酬、绩效放进一套系统。

它既处理事务性工作，也支撑人才管理：编制、招聘进度、人工成本、绩效结果都能被追踪。
