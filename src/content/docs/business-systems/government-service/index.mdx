**一句话定位**：把政府服务事项搬到线上，让企业和群众少跑腿、一次办成。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 公共服务与平台系统 |
| 典型用户 | 办事群众/企业、窗口人员、审批人员、平台运营、监管 |
| 核心模块 | 事项管理、在线申报、受理审批、材料共享、进度查询、好差评、数据看板 |
| 常见产品 | 阿里政务云、腾讯政务、华为政务、太极政务 |
| 开源项目 | Flowable、Camunda、Keycloak、Apache OFBiz |

## 这个系统解决什么问题

办事要跑多个窗口、重复交材料、进度查不到，是政务服务的老问题。政务服务平台把事项、材料、流程、窗口和评价统一，支持网上办、掌上办、一次办。

它既服务群众和企业，也服务政府内部的跨部门协同和效能监督。
