## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 数据集成 | 批量、实时、文件接入 | 数据工程师 |
| 数据治理 | 标准、质量、血缘、元数据 | 数据治理 |
| 指标中心 | 指标定义、计算、口径 | 数据产品 |
| 标签画像 | 标签生产、人群圈选 | 运营、数据 |
| 数据服务 | API 发布、限流、监控 | 业务开发 |
| 业务能力中心 | 用户、商品、订单、支付 | 业务开发 |

## 核心功能

### 数据集成

支持数据库、日志、API、文件的全量与增量同步。

### 元数据与血缘

登记表、字段、任务和上下游关系，变更时能评估影响。

### 指标中心

指标定义一次，BI、报表、数据服务共用同一口径。

### 标签平台

用规则或模型生产标签，支持人群圈选和导出。

### 数据服务 API

把查询封装成 API，带鉴权、限流和监控。

## 核心业务流程

### 数据接入到指标

- **触发条件**：业务系统产生新数据或新增分析需求
- **参与角色**：数据工程师、数据产品、分析师
- **流程步骤**：
  1. 需求登记
  2. 数据接入
  3. 清洗建模
  4. 指标定义
  5. 质量校验
  6. 发布
- **输入 / 输出**：输入源数据与指标需求，输出数据集、指标与血缘
- **异常与分支**：数据质量不达标阻断发布；口径冲突走评审

### 标签生产

- **触发条件**：运营需要人群圈选
- **参与角色**：运营、数据开发
- **流程步骤**：
  1. 定义标签
  2. 配置规则或模型
  3. 跑批
  4. 质量检查
  5. 上线
  6. 圈选人群
- **输入 / 输出**：输入用户行为与属性，输出标签与人群包
- **异常与分支**：标签覆盖率低需补数据；人群量过大限制导出

### 能力复用

- **触发条件**：新业务需要用户/商品/订单能力
- **参与角色**：业务开发、中台团队
- **流程步骤**：
  1. 能力目录查找
  2. 申请接入
  3. 分配凭证
  4. 联调
  5. 上线
  6. 用量监控
- **输入 / 输出**：输入业务需求，输出 API 凭证与接入文档
- **异常与分支**：能力不满足走扩展；调用超限流需扩容

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 数据源 | 待接入/已接入/已下线 | 接入、下线 | 数据集 |
| 指标 | 草稿/评审中/已发布/已下线 | 评审、发布 | 报表/API |
| 标签 | 设计中/开发中/已上线/已下线 | 上线 | 人群 |
| API 申请 | 待审批/已通过/已拒绝 | 审批 | 凭证 |

## 业务规则

- 数据接入必须登记元数据和负责人
- 指标口径变更需评审并通知下游
- 敏感数据分级分类，按最小权限开放
- API 必须鉴权、限流、可监控
- 中台能力优先复用，避免重复建设
