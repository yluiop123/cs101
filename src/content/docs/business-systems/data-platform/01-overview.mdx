## 一句话定义

把分散在各系统的数据和服务沉淀成可复用资产，避免重复建设。

## 业务背景

系统越建越多，数据口径不一致、通用能力重复开发：每个业务都自己做用户、商品、订单、支付。中台把数据和能力沉淀下来，供前台复用。

数据中台负责采集、治理、指标、标签和服务化；业务中台把用户、商品、订单、支付等通用能力做成共享服务。

## 系统边界

中台管共享数据与能力，不管具体业务系统的交易流程。它不是万能平台，必须有稳定的业务场景和治理机制支撑。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 数据工程师 | 采集、清洗、调度、治理 | 数据集成、任务调度、质量 |
| 数据产品经理 | 指标、标签、数据服务 | 指标中心、标签平台 |
| 业务开发 | 调用共享能力 | API、SDK、能力中心 |
| 分析师 | 使用数据和指标 | 数据集、指标 |
| 管理层 | 数据资产与复用效果 | 资产地图、成本 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| 各业务系统 | 数据来源与能力消费方 |
| BI | 消费指标与数据集 |
| 数据仓库/湖 | 存储与计算底座 |
| IAM | 统一身份与权限 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 数据资产 | Data Asset | 可被登记、治理和复用的数据集合 |
| 指标中心 | Metric Center | 统一指标定义、计算和口径 |
| 标签 | Tag | 描述对象特征的属性，如高价值客户 |
| 数据服务 | Data Service | 以 API 形式对外提供数据 |
| 业务能力中心 | Business Capability Center | 用户、商品、订单等共享服务 |
