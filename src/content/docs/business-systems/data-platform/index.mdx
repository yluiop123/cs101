**一句话定位**：把分散在各系统的数据和服务沉淀成可复用资产，避免重复建设。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 企业通用系统 |
| 典型用户 | 数据工程师、数据产品经理、业务开发、分析师、管理层 |
| 核心模块 | 数据集成、数据治理、指标中心、标签画像、数据服务、业务能力中心 |
| 常见产品 | 阿里云 DataWorks、华为云 DataArts、腾讯云 TBDS、数澜科技 |
| 开源项目 | Apache DolphinScheduler、Apache SeaTunnel、DataHub、Apache Atlas、Apache Flink |

## 这个系统解决什么问题

系统越建越多，数据口径不一致、通用能力重复开发：每个业务都自己做用户、商品、订单、支付。中台把数据和能力沉淀下来，供前台复用。

数据中台负责采集、治理、指标、标签和服务化；业务中台把用户、商品、订单、支付等通用能力做成共享服务。
