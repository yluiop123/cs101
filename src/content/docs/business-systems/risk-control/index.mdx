**一句话定位**：用规则、模型和名单识别欺诈与信用风险，在交易前中后拦截。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 金融业务系统 |
| 典型用户 | 风控策略、算法工程师、审核人员、运营、合规 |
| 核心模块 | 名单管理、规则引擎、模型评分、设备指纹、决策流、案件调查、监控报表 |
| 常见产品 | 同盾科技、蚂蚁风险大脑、腾讯云天御、邦盛科技 |
| 开源项目 | Drools、Apache Flink、Open Policy Agent、Feast |

## 这个系统解决什么问题

欺诈、套现、盗刷、骗贷手段不断变化，靠人工审核跟不上。风控系统做设备指纹、名单、规则、模型评分和决策。

它要在用户体验和风险控制之间找平衡：该拦的拦住，正常交易不能误杀。
