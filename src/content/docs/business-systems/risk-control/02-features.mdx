## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 名单管理 | 黑名单、白名单、灰名单 | 风控策略 |
| 规则引擎 | 条件、阈值、命中动作 | 风控策略 |
| 模型评分 | 特征、模型、分数 | 算法 |
| 设备指纹 | 设备识别与关联 | 风控 |
| 决策流 | 编排规则与模型 | 风控策略 |
| 案件调查 | 人工复核、处置 | 审核 |
| 监控报表 | 拦截率、误杀率、趋势 | 运营 |

## 核心功能

### 多源名单

内部黑名单、外部风险名单、设备关联名单统一管理。

### 规则编排

用可视化条件配置规则，支持灰度、优先级和命中动作。

### 模型评分

实时计算特征，调用模型输出风险分。

### 决策流

按名单→规则→模型顺序决策，返回通过、复核、拒绝。

### 案件闭环

人工复核、申诉、处置结果回流优化策略。

## 核心业务流程

### 交易反欺诈

- **触发条件**：支付或转账请求到达
- **参与角色**：风控系统、支付系统
- **流程步骤**：
  1. 采集设备与行为
  2. 查名单
  3. 跑规则
  4. 模型评分
  5. 决策
  6. 放行/拦截/复核
- **输入 / 输出**：输入交易与设备信息，输出风险决策
- **异常与分支**：规则冲突按优先级；模型超时降级规则；复核队列积压告警

### 信贷审批风控

- **触发条件**：信贷申请进入审批
- **参与角色**：风控、信贷系统
- **流程步骤**：
  1. 获取征信与外部数据
  2. 计算特征
  3. 评分
  4. 规则校验
  5. 输出建议额度与风险等级
- **输入 / 输出**：输入申请人资料，输出风险分与审批建议
- **异常与分支**：数据缺失走人工；高风险拒绝；多头借贷提示

### 案件调查

- **触发条件**：交易被拦截或客户申诉
- **参与角色**：审核人员、风控策略
- **流程步骤**：
  1. 生成案件
  2. 分派
  3. 调查取证
  4. 处置
  5. 反馈策略
- **输入 / 输出**：输入拦截记录，输出案件结论与策略调整
- **异常与分支**：误杀解除并加白；确认欺诈拉黑并上报

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 风险名单 | 生效/失效 | 新增、移除 | 决策 |
| 规则 | 草稿/测试/生效/下线 | 发布 | 决策 |
| 案件 | 待处理/调查中/已处置/已申诉 | 处置 | 策略 |
| 决策记录 | 通过/复核/拒绝 | 决策 | 审计 |

## 业务规则

- 名单和规则变更必须留痕并可回滚
- 高风险决策必须可解释
- 人工复核结果要回流策略
- 误杀率超过阈值自动告警
- 敏感数据按最小权限使用
