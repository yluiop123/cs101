## 一句话定义

用规则、模型和名单识别欺诈与信用风险，在交易前中后拦截。

## 业务背景

欺诈、套现、盗刷、骗贷手段不断变化，靠人工审核跟不上。风控系统做设备指纹、名单、规则、模型评分和决策。

它要在用户体验和风险控制之间找平衡：该拦的拦住，正常交易不能误杀。

## 系统边界

风控系统管风险识别与决策，不管具体信贷流程（信贷系统）、不管账务（核心银行）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 风控策略 | 规则、阈值、策略调优 | 规则、名单、决策流 |
| 算法工程师 | 模型、特征、评估 | 模型、特征 |
| 审核人员 | 人工复核、案件处理 | 案件、审核 |
| 运营 | 拦截监控、申诉 | 监控、名单 |
| 合规 | 反洗钱、监管报送 | 报告、审计 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| 信贷系统 | 审批中的风险决策 |
| 支付清算 | 交易反欺诈 |
| 核心银行 | 账户与交易数据 |
| 数据中台 | 特征与标签 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 设备指纹 | Device Fingerprint | 识别设备唯一性，发现批量注册和盗刷 |
| 规则引擎 | Rule Engine | 用条件组合配置风险规则 |
| 评分卡 | Scorecard | 预测违约或欺诈概率的模型 |
| 决策流 | Decision Flow | 按顺序执行名单、规则、模型的决策过程 |
| 误杀率 | False Positive Rate | 正常交易被错误拦截的比例 |
