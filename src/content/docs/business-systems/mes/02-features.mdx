## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 工单管理 | 工单下达、拆分、关闭 | 计划、车间 |
| 排产派工 | 工序排程、人员设备分配 | 计划、班组长 |
| 生产执行 | 开工、报工、报检、暂停 | 操作工 |
| 物料管理 | 领料、配送、退料、消耗 | 仓库、车间 |
| 质量管理 | 首检、巡检、终检、不良处理 | 质量 |
| 设备管理 | 点检、维修、停机 | 设备 |
| 追溯看板 | 批次追溯、生产看板 | 管理、质量 |

## 核心功能

### 工单执行

按工艺路线生成工序任务，操作工扫码开工、报工、报检。

### 实时进度

按工单、工序、设备统计完成数量、良率和在制品。

### 批次追溯

记录每批产品用的原料批次、设备、参数和操作人。

### 质量拦截

首检未通过不能批量生产，不良品强制走返修或报废。

### 设备停机

记录停机原因和时长，统计 OEE 与瓶颈工序。

## 核心业务流程

### 工单下达与执行

- **触发条件**：ERP 下达生产订单或计划补产
- **参与角色**：计划、车间主任、班组长、操作工
- **流程步骤**：
  1. 接收生产订单
  2. 生成工单
  3. 排产派工
  4. 领料
  5. 开工
  6. 报工
  7. 完工入库
- **输入 / 输出**：输入生产订单与 BOM，输出工单进度、领料记录、完工入库
- **异常与分支**：缺料停线；设备故障转维修；质量异常转返修

### 质量检验与追溯

- **触发条件**：首件、巡检或完工报检
- **参与角色**：操作工、质量人员
- **流程步骤**：
  1. 发起报检
  2. 采样检验
  3. 判定
  4. 放行或隔离
  5. 记录追溯信息
- **输入 / 输出**：输入检验项目与结果，输出检验单、放行或隔离指令
- **异常与分支**：不合格隔离并触发返修/报废；复检仍不合格升级处理

### 物料配送

- **触发条件**：工单开工前或线边库存低于安全量
- **参与角色**：车间、仓库
- **流程步骤**：
  1. 生成配送需求
  2. 仓库拣料
  3. 配送上线
  4. 扫码接收
  5. 消耗登记
- **输入 / 输出**：输入工单物料需求，输出配送单与线边库存
- **异常与分支**：错料退回；紧急补料走绿色通道

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 工单 | 已下达/待开工/生产中/已完工/已关闭 | 开工、报工 | 完工入库 |
| 报工单 | 待审核/已确认 | 审核 | 工单进度 |
| 检验单 | 待检/合格/不合格/已复检 | 判定 | 放行或隔离 |
| 维修单 | 待维修/维修中/已修复 | 维修 | 设备状态 |

## 业务规则

- 工单必须关联生产订单和 BOM
- 首检未通过不允许批量生产
- 不良品必须走返修、报废或让步接收
- 关键工序必须扫码记录操作人和设备
- 工单关闭前必须完成报工和物料结算
