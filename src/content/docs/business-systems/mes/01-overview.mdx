## 一句话定义

把生产订单变成工单、工序、报工和追溯，管住车间每一天的执行。

## 业务背景

ERP 下达生产订单后，车间靠纸质工单和 Excel 排产，进度、良率、在制品不透明，出了问题也难追溯到具体批次。MES 承接计划，管理工单、工序、设备、质量和物料。

它让管理层看到「今天该做什么、做到哪、为什么没完成」，也让质量部门能顺着批次反查原料、设备和操作人。

## 系统边界

MES 管车间执行，不管企业经营计划与财务（ERP）、不管设备底层控制与数据采集（SCADA/PLC）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 生产计划 | 工单下达、排产、交期 | 工单、排产、看板 |
| 车间主任 | 派工、进度、异常处理 | 工单、报工、异常 |
| 班组长 | 任务分派、首件确认 | 派工、首检 |
| 操作工 | 扫码开工、报工、报检 | 工单执行、报工 |
| 质量人员 | 检验、判定、追溯 | 检验单、追溯 |
| 设备人员 | 点检、维修、停机记录 | 设备台账、维修单 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| ERP | 接收生产订单，回传完工与领料 |
| SCADA/PLC | 采集设备状态与工艺参数 |
| WMS | 物料配送与成品入库 |
| QMS/LIMS | 检验结果与质量判定 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 工单 | Work Order | 车间执行生产的最小任务单元 |
| 工序 | Operation | 工单按工艺路线拆分的加工步骤 |
| 报工 | Production Reporting | 操作工上报完成数量、工时和不良 |
| 在制品 | WIP | 已投产但尚未完工的产品 |
| 批次追溯 | Lot Traceability | 按批次反查原料、设备、人员和检验记录 |
