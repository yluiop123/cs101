## 一句话定义

收集日志、关联分析、检测告警和响应安全事件。

## 业务背景

安全设备多、日志分散，攻击发现靠人盯，事件响应缺流程。SIEM 把日志采集、归一化、关联规则、告警和响应集中起来。

它让安全团队从「看设备」变成「看事件」，并满足合规审计要求。

## 系统边界

SIEM 管日志分析与安全事件，不管终端防护（EDR）、不管身份权限（IAM）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| SOC 分析师 | 监控、告警研判 | 告警、事件 |
| 安全工程师 | 规则、日志接入、调优 | 规则、数据源 |
| 应急响应 | 事件调查、处置 | 事件、取证 |
| 合规 | 审计、报告 | 报表 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| EDR | 终端告警与响应 |
| 防火墙/WAF | 网络与 Web 日志 |
| IAM | 登录与权限事件 |
| 威胁情报 | IOC 与情报匹配 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 日志归一化 | Normalization | 把不同格式日志转成统一字段 |
| 关联规则 | Correlation Rule | 把多个事件组合成安全告警 |
| IOC | Indicator of Compromise | 恶意 IP、域名、文件哈希等指标 |
| 事件 | Incident | 需要响应处置的安全事件 |
| SOAR | Security Orchestration, Automation and Response | 安全编排与自动化响应 |
