## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 日志采集 | Agent、Syslog、API | 安全工程师 |
| 解析归一 | 字段映射、富化 | 安全工程师 |
| 关联规则 | 规则、阈值、序列 | 分析师 |
| 告警 | 分级、去重、分派 | SOC |
| 事件调查 | 时间线、取证、处置 | 应急 |
| 报表合规 | 等保、审计报表 | 合规 |

## 核心功能

### 多源日志接入

采集网络、主机、应用、云平台日志。

### 关联分析

按规则、阈值、时间窗口识别攻击行为。

### 告警降噪

去重、聚合、白名单和优先级。

### 事件调查

关联原始日志、资产和情报，还原攻击链。

### 合规报表

按等保和审计要求生成报告。

## 核心业务流程

### 日志接入

- **触发条件**：新增设备或系统
- **参与角色**：安全工程师
- **流程步骤**：
  1. 配置采集
  2. 解析字段
  3. 验证数据
  4. 上线
  5. 监控延迟
- **输入 / 输出**：输入日志源，输出标准化事件
- **异常与分支**：解析失败告警；日志量超限限流；采集中断补传

### 告警检测

- **触发条件**：规则命中
- **参与角色**：SOC 分析师
- **流程步骤**：
  1. 规则匹配
  2. 生成告警
  3. 去重聚合
  4. 研判
  5. 升级事件或关闭
- **输入 / 输出**：输入事件流，输出告警与研判结论
- **异常与分支**：误报加白；规则冲突调优先级；告警风暴抑制

### 事件响应

- **触发条件**：告警升级为安全事件
- **参与角色**：应急响应、安全工程师
- **流程步骤**：
  1. 创建事件
  2. 调查取证
  3. 遏制
  4. 根除
  5. 恢复
  6. 复盘
- **输入 / 输出**：输入告警与日志，输出事件报告与处置记录
- **异常与分支**：重大事件上报；取证数据保全；跨团队协同

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 日志源 | 待接入/已接入/异常 | 接入 | 事件 |
| 告警 | 新建/研判中/已升级/已关闭 | 研判 | 事件 |
| 事件 | 待处理/处理中/已遏制/已关闭 | 处置 | 报告 |
| 规则 | 草稿/测试/启用/停用 | 启用 | 告警 |

## 业务规则

- 日志保存周期满足合规要求
- 告警必须研判并记录结论
- 重大事件必须上报和复盘
- 规则变更要测试后上线
- 取证数据要保证完整性
