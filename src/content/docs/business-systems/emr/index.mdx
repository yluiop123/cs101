**一句话定位**：管病历文书、医嘱、护理记录和签名，让临床过程可追溯。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 医疗健康系统 |
| 典型用户 | 医生、护士、病案室、质控、患者 |
| 核心模块 | 门诊病历、住院病历、医嘱、护理记录、模板、签名、质控 |
| 常见产品 | 嘉和美康、海泰医疗、东软 EMR、卫宁 EMR |
| 开源项目 | OpenEMR、OpenMRS、Bahmni、HospitalRun |

## 这个系统解决什么问题

纸质病历难检索、难共享，医生重复书写，质控靠抽查。EMR 把门诊/住院病历、医嘱、护理、检查报告和电子签名集中管理。

它既服务临床书写，也服务病案质控、科研和医保审核。
