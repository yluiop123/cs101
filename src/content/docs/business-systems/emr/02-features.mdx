## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 门诊病历 | 主诉、现病史、诊断、处方 | 医生 |
| 住院病历 | 入院记录、病程、手术、出院小结 | 医生 |
| 医嘱 | 长期/临时医嘱、执行 | 医生、护士 |
| 护理记录 | 生命体征、护理措施 | 护士 |
| 模板 | 专科模板、短语、结构化字段 | 医生 |
| 签名 | 电子签名、时限 | 医生 |
| 质控 | 规则、评分、整改 | 质控 |

## 核心功能

### 结构化书写

按专科模板和字段录入，兼顾书写效率和科研统计。

### 医嘱闭环

开立、审核、执行、停止、核对全程留痕。

### 电子签名

医生签名后病历不可随意修改，修改留痕。

### 时限质控

入院记录、病程、手术记录按规范设置完成时限。

### 病案首页

自动汇总诊断、手术、费用，支持医保结算清单。

## 核心业务流程

### 门诊书写

- **触发条件**：患者就诊
- **参与角色**：医生
- **流程步骤**：
  1. 调阅患者信息
  2. 书写主诉现病史
  3. 诊断
  4. 开处方/检查
  5. 签名
  6. 归档
- **输入 / 输出**：输入问诊与检查信息，输出门诊病历与处方
- **异常与分支**：模板不适用自定义；诊断编码错误质控拦截

### 住院病程

- **触发条件**：患者入院
- **参与角色**：医生、护士
- **流程步骤**：
  1. 入院记录
  2. 首次病程
  3. 日常病程
  4. 手术记录
  5. 出院小结
  6. 签名归档
- **输入 / 输出**：输入住院诊疗信息，输出住院病历与病案首页
- **异常与分支**：超时未写质控提醒；修改需留痕；危急值记录

### 病历质控

- **触发条件**：病历提交或归档
- **参与角色**：质控、医生
- **流程步骤**：
  1. 规则扫描
  2. 评分
  3. 问题清单
  4. 医生整改
  5. 复核
  6. 归档
- **输入 / 输出**：输入病历内容，输出质控评分与整改项
- **异常与分支**：甲级病历标准不达标退回；争议病历人工复核

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 门诊病历 | 草稿/已签名/已归档 | 签名 | 归档 |
| 住院病历 | 书写中/待质控/已归档 | 提交、质控 | 病案 |
| 医嘱 | 已开立/已审核/执行中/已停止 | 审核、执行 | 护理 |
| 病案首页 | 草稿/已提交/已归档 | 提交 | 医保 |

## 业务规则

- 病历签名后修改必须留痕并说明理由
- 入院记录、首次病程等有完成时限
- 医嘱必须经审核才能执行
- 病案首页诊断和手术编码要符合规范
- 患者隐私数据按角色授权访问
