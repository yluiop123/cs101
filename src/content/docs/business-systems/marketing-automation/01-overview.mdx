## 一句话定义

用人群、旅程和触达，把营销活动从一次性投放变成持续运营。

## 业务背景

营销靠人工群发，用户旅程断点没人管，活动效果难归因。营销自动化做人群分层、自动化旅程、多渠道触达和效果分析。

它让「什么时候、对谁、发什么」由规则自动执行，而不是靠运营手工排期。

## 系统边界

营销自动化管营销旅程与触达，不管会员权益（会员系统）、不管广告投放（广告平台）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 市场 | 活动、内容、旅程 | 活动、旅程 |
| 运营 | 人群、触达、转化 | 人群、消息 |
| 数据分析 | 归因、漏斗、实验 | 报表 |
| 销售 | 线索跟进 | 线索评分 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| 会员系统 | 会员与权益 |
| CRM | 线索与商机 |
| 广告平台 | 投放与回传 |
| 数据中台 | 标签与人群 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 人群 | Segment | 按条件筛选出的用户集合 |
| 旅程 | Journey | 按触发条件和时间编排的营销流程 |
| 触达 | Engagement | 短信、邮件、推送、企微等触达方式 |
| 线索评分 | Lead Scoring | 按行为和属性给线索打分 |
| 归因 | Attribution | 把转化归因到具体渠道或活动 |
