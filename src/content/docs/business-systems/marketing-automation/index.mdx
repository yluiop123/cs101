**一句话定位**：用人群、旅程和触达，把营销活动从一次性投放变成持续运营。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 公共服务与平台系统 |
| 典型用户 | 市场、运营、数据分析、销售 |
| 核心模块 | 人群管理、旅程编排、多渠道触达、内容管理、线索评分、效果分析 |
| 常见产品 | HubSpot、Marketo、致趣百川、销售易营销云 |
| 开源项目 | Mautic、Apache Unomi、Listmonk、Odoo Marketing |

## 这个系统解决什么问题

营销靠人工群发，用户旅程断点没人管，活动效果难归因。营销自动化做人群分层、自动化旅程、多渠道触达和效果分析。

它让「什么时候、对谁、发什么」由规则自动执行，而不是靠运营手工排期。
