## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 人群管理 | 标签、规则、人群包 | 运营 |
| 旅程编排 | 触发、等待、分支、动作 | 市场 |
| 多渠道触达 | 短信、邮件、推送、企微 | 运营 |
| 内容管理 | 模板、素材、个性化 | 市场 |

## 核心功能

### 人群圈选

按属性、行为、标签组合圈人，实时或离线更新。

### 自动化旅程

用触发、等待、条件分支和动作编排用户旅程。

### 多渠道触达

短信、邮件、App 推送、企微统一编排。

### 线索评分

按行为和属性评分，高分线索转销售。

### 效果归因

跟踪触达到转化的全链路，评估活动 ROI。

## 核心业务流程

### 新客培育

- **触发条件**：用户注册或留资
- **参与角色**：市场、运营
- **流程步骤**：
  1. 进入人群
  2. 触发旅程
  3. 发送欢迎内容
  4. 等待
  5. 根据行为分支
  6. 转化或转销售
- **输入 / 输出**：输入用户与行为，输出触达记录与转化
- **异常与分支**：退订停止触达；无响应走召回；频控限制

### 流失召回

- **触发条件**：用户长时间未活跃
- **参与角色**：运营
- **流程步骤**：
  1. 识别流失
  2. 圈选人群
  3. 设计权益
  4. 多渠道触达
  5. 转化跟踪
- **输入 / 输出**：输入流失规则，输出召回活动与效果
- **异常与分支**：触达频控；权益成本超限审批；负反馈用户排除

### 活动投放

- **触发条件**：营销活动上线
- **参与角色**：市场、数据
- **流程步骤**：
  1. 配置活动
  2. 选人群
  3. 排期
  4. 触达
  5. 监控
  6. 归因分析
- **输入 / 输出**：输入活动方案，输出曝光、点击、转化
- **异常与分支**：素材审核不通过；发送失败重试；预算耗尽停止

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 人群 | 草稿/计算中/已生效/已失效 | 计算 | 旅程 |
| 旅程 | 草稿/运行中/已暂停/已结束 | 上线 | 触达 |
| 活动 | 草稿/待审核/进行中/已结束 | 审核、上线 | 归因 |
| 触达任务 | 待发送/发送中/已完成/失败 | 发送 | 效果 |

## 业务规则

- 触达必须遵守频控和退订规则
- 人群条件变更要重新计算
- 活动素材必须审核
- 归因窗口和口径要统一
- 用户敏感数据按授权使用
