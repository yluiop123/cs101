## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 项目立项 | 申请、评审、章程、优先级 | PMO、管理层 |
| 计划与进度 | WBS、里程碑、甘特图 | 项目经理 |
| 资源管理 | 资源池、排期、工时 | 资源经理 |
| 成本预算 | 预算、实际成本、偏差 | 财务、项目经理 |
| 风险与问题 | 登记、评估、应对、跟踪 | 项目经理 |
| 组合分析 | 投资、优先级、健康度 | 管理层、PMO |

## 核心功能

### 项目台账

所有项目按类型、状态、负责人、预算汇总，支持多维度筛选。

### WBS 与甘特图

把项目拆成任务和里程碑，展示依赖关系和关键路径。

### 资源排期

查看人员在多个项目上的投入，识别超负荷和空档。

### 预算与成本

按项目归集人力、采购、外包成本，对比预算看偏差。

### 组合健康度

用进度、成本、风险、收益综合评分，辅助优先级调整。

## 核心业务流程

### 项目立项

- **触发条件**：业务部门提出项目需求
- **参与角色**：申请人、PMO、管理层、财务
- **流程步骤**：
  1. 项目申请
  2. 可行性评估
  3. 预算评审
  4. 立项审批
  5. 任命项目经理
  6. 项目启动
- **输入 / 输出**：输入目标、范围、预算、资源需求，输出项目章程与项目编号
- **异常与分支**：预算不足退回；跨部门资源冲突需管理层协调

### 计划与执行

- **触发条件**：项目启动
- **参与角色**：项目经理、团队成员、PMO
- **流程步骤**：
  1. 拆解 WBS
  2. 排期与资源分配
  3. 执行任务
  4. 周报与进度更新
  5. 风险跟踪
  6. 阶段评审
- **输入 / 输出**：输入项目章程，输出计划、进度、风险清单
- **异常与分支**：关键路径延期触发预警；需求变更走变更审批

### 结项与复盘

- **触发条件**：项目交付完成
- **参与角色**：项目经理、PMO、财务
- **流程步骤**：
  1. 提交验收
  2. 成本结算
  3. 资料归档
  4. 复盘
  5. 项目关闭
- **输入 / 输出**：输入交付物与成本，输出验收报告、复盘记录
- **异常与分支**：验收不通过整改；预算超支需专项说明

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 项目申请 | 草稿/评审中/已立项/已驳回 | 评审、审批 | 项目 |
| 项目计划 | 草稿/已审批/执行中/已关闭 | 审批、更新 | 任务与里程碑 |
| 变更单 | 待评估/待审批/已批准/已拒绝 | 评估、审批 | 计划更新 |
| 验收单 | 待验收/已验收/不通过 | 验收 | 结项 |

## 业务规则

- 项目必须有唯一编号和负责人
- 预算超阈值需重新审批
- 关键里程碑延期必须登记原因
- 资源排期冲突时由资源经理协调
- 项目关闭前必须完成成本结算和资料归档
