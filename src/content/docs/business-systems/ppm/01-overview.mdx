## 一句话定义

用项目、阶段、资源、预算和风险，把一堆并行的项目管成一个可控的组合。

## 业务背景

多个项目同时推进时，资源冲突、预算超支、进度延期往往到最后才暴露。PPM 把立项、计划、资源、成本、风险统一管理，并从组合视角做优先级和投资决策。

它不只回答「这个项目做到哪了」，还回答「这些项目值不值得做、资源该投给谁」。

## 系统边界

PPM 管项目组合与项目过程，不管具体任务协作（OA/任务工具）、不管研发代码与流水线（DevOps/ALM）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| PMO | 制度、模板、项目监控 | 项目台账、组合看板、评审 |
| 项目经理 | 计划、进度、风险、变更 | 项目计划、任务、风险、周报 |
| 资源经理 | 人员排期与冲突协调 | 资源池、排期、工时 |
| 财务 | 预算、成本、结算 | 预算、实际成本、结算 |
| 管理层 | 投资决策与优先级 | 组合分析、仪表盘 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| OA | 立项、变更、验收审批 |
| FMS/ERP | 项目预算、成本归集、开票 |
| HRM | 人员与工时 |
| DevOps/ALM | 研发任务与交付物 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 项目组合 | Portfolio | 按战略目标管理的一组项目 |
| 项目章程 | Project Charter | 明确目标、范围、预算和负责人的立项文件 |
| WBS | Work Breakdown Structure | 把项目拆成可管理的工作包 |
| 里程碑 | Milestone | 项目中的关键节点 |
| 资源负荷 | Resource Utilization | 人员在不同项目上的投入比例 |
