**一句话定位**：用项目、阶段、资源、预算和风险，把一堆并行的项目管成一个可控的组合。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 企业通用系统 |
| 典型用户 | PMO、项目经理、资源经理、财务、管理层 |
| 核心模块 | 项目立项、计划与进度、资源管理、成本预算、风险与问题、组合分析 |
| 常见产品 | Microsoft Project、Jira Align、禅道、飞书项目 |
| 开源项目 | OpenProject、ProjectLibre、Redmine、Odoo Project |

## 这个系统解决什么问题

多个项目同时推进时，资源冲突、预算超支、进度延期往往到最后才暴露。PPM 把立项、计划、资源、成本、风险统一管理，并从组合视角做优先级和投资决策。

它不只回答「这个项目做到哪了」，还回答「这些项目值不值得做、资源该投给谁」。
