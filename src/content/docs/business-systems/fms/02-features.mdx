## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 总账 | 凭证、账簿、期末结账 | 会计 |
| 应收应付 | 往来账、账龄、核销 | 会计、业务 |
| 资金管理 | 账户、收付款、银行对账 | 出纳 |
| 费用报销 | 报销、借款、发票校验 | 员工、财务 |
| 预算管理 | 编制、控制、执行分析 | 财务、部门 |
| 税务与报表 | 发票、申报、财务报表 | 财务 |

## 核心功能

### 凭证处理

支持手工制单、业务单据自动生成、批量导入，借贷平衡校验。

### 往来核销

收款与应收、付款与应付自动或手工核销，输出账龄分析。

### 预算控制

报销和付款提交时校验部门、项目、科目预算余额。

### 银企直联

直连银行查询余额和流水，发起支付并回单。

### 报表中心

资产负债表、利润表、现金流量表和管理报表。

## 核心业务流程

### 费用报销

- **触发条件**：员工发生因公支出
- **参与角色**：员工、主管、财务
- **流程步骤**：
  1. 提交报销单
  2. 主管审批
  3. 财务审核
  4. 出纳付款
  5. 生成凭证
- **输入 / 输出**：输入发票与报销明细，输出付款单、凭证
- **异常与分支**：发票不合规退回；超预算需追加审批；借款未清先冲借款

### 月末结账

- **触发条件**：会计期间结束
- **参与角色**：会计、财务主管
- **流程步骤**：
  1. 业务单据入账
  2. 计提折旧与摊销
  3. 往来对账
  4. 试算平衡
  5. 结账
  6. 出报表
- **输入 / 输出**：输入本期凭证，输出账簿、报表、结账状态
- **异常与分支**：试算不平需查错；跨期单据走调整凭证

### 收款核销

- **触发条件**：银行到账
- **参与角色**：出纳、会计
- **流程步骤**：
  1. 导入流水
  2. 匹配客户
  3. 核销应收
  4. 生成凭证
- **输入 / 输出**：输入银行流水，输出核销记录与应收余额
- **异常与分支**：无法匹配走暂收；部分收款按金额拆分核销

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 记账凭证 | 草稿/已审核/已记账/已作废 | 审核、记账 | 账簿 |
| 报销单 | 草稿/审批中/待付款/已付款 | 审批、付款 | 凭证 |
| 付款单 | 待审批/已审批/已支付/已失败 | 审批、支付 | 银行回单 |
| 预算单 | 草稿/已下达/执行中/已关闭 | 下达 | 预算控制 |

## 业务规则

- 凭证必须借贷平衡才能保存
- 已记账凭证修改需红冲后重做
- 报销单必须关联合规发票
- 付款前校验预算和审批权限
- 结账后本期不允许新增凭证
