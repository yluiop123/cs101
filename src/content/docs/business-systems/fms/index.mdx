**一句话定位**：管好账、钱、税、报表，让企业每一笔收支都有据可查。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 企业通用系统 |
| 典型用户 | 会计、出纳、财务主管、业务部门、管理层 |
| 核心模块 | 总账、应收应付、资金管理、费用报销、预算管理、税务与报表 |
| 常见产品 | SAP FI/CO、用友 NC / YonBIP 财务、金蝶云星空财务、畅捷通好会计 |
| 开源项目 | ERPNext Accounting、Odoo Accounting、GnuCash、Apache Fineract |

## 这个系统解决什么问题

企业每天发生大量收付款、报销、开票、纳税事项，靠手工记账容易错漏，月底对账和出报表非常痛苦。FMS 把凭证、账簿、报表、资金、税务串起来。

它既要满足会计规范，也要服务经营分析：钱花在哪、哪个部门超预算、现金流是否健康。
