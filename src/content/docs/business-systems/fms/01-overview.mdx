## 一句话定义

管好账、钱、税、报表，让企业每一笔收支都有据可查。

## 业务背景

企业每天发生大量收付款、报销、开票、纳税事项，靠手工记账容易错漏，月底对账和出报表非常痛苦。FMS 把凭证、账簿、报表、资金、税务串起来。

它既要满足会计规范，也要服务经营分析：钱花在哪、哪个部门超预算、现金流是否健康。

## 系统边界

FMS 管会计核算、资金、预算、税务与报表，不管业务单据本身（采购/销售在 ERP）、不管银行核心账务（银行系统）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 会计 | 制单、审核、记账、结账 | 凭证、账簿、报表 |
| 出纳 | 收付款、银行对账 | 资金、银行日记账 |
| 财务主管 | 预算、审核、分析 | 预算、报表、审批 |
| 业务部门 | 报销、借款、预算查询 | 报销单、借款单 |
| 管理层 | 经营分析 | 管理报表、仪表盘 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| ERP | 业务单据生成凭证 |
| OA | 报销、借款、付款审批 |
| 银行/银企直联 | 账户余额、流水、支付 |
| 税务平台 | 发票、申报、税负分析 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 会计凭证 | Voucher | 记录一笔经济业务的会计分录 |
| 权责发生制 | Accrual Basis | 按业务发生期间确认收入费用 |
| 预算控制 | Budget Control | 支出前校验预算余额 |
| 银企直联 | Bank-Enterprise Direct Connection | 系统直连银行查询与支付 |
| 合并报表 | Consolidated Statements | 多法人主体合并后的财务报表 |
