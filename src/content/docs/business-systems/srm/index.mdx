**一句话定位**：管供应商准入、询报价、采购协同、绩效和对账。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 制造与供应链系统 |
| 典型用户 | 采购员、供应商、质量、财务、采购经理 |
| 核心模块 | 供应商准入、询报价、采购协同、来料质量、绩效、对账 |
| 常见产品 | SAP Ariba、Coupa、甄云 SRM、企企通 SRM |
| 开源项目 | Odoo Purchase、ERPNext Buying、Apache OFBiz、Dolibarr |

## 这个系统解决什么问题

供应商信息分散，询价靠邮件，交期和质量靠催，对账经常扯皮。SRM 把供应商全生命周期和采购协同管起来。

它让采购从「找供应商」变成「经营供应商」，也让供应商能在线接单、交货和对账。
