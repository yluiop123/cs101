## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 供应商准入 | 注册、资质、评审、分级 | 采购、质量 |
| 询报价 | RFQ、比价、授标 | 采购 |
| 采购协同 | 订单确认、交期、发货 | 采购、供应商 |
| 来料质量 | 检验、不合格处理 | 质量 |
| 绩效 | 评分、排名、改进 | 采购 |
| 对账 | 对账单、发票、付款 | 财务、供应商 |

## 核心功能

### 供应商门户

供应商在线注册、报价、确认订单、上传发货和发票信息。

### 询比价

发起 RFQ，多家报价，按价格、交期、资质综合比价。

### 订单协同

采购订单在线确认，交期变更和发货通知实时同步。

### 绩效评分

按质量、交期、价格、服务自动或手工评分，分级管理。

### 在线对账

采购方和供应商核对收货、退货、发票和付款。

## 核心业务流程

### 供应商准入

- **触发条件**：采购需要引入新供应商
- **参与角色**：采购、质量、财务、供应商
- **流程步骤**：
  1. 供应商注册
  2. 资质审核
  3. 现场评审
  4. 样品验证
  5. 准入审批
  6. 加入合格供方
- **输入 / 输出**：输入资质与评审结果，输出供应商档案与等级
- **异常与分支**：资质不全退回；评审不通过列入观察；关键供应商需高层审批

### 询比价

- **触发条件**：采购需求明确但供应商未定
- **参与角色**：采购、供应商、审批人
- **流程步骤**：
  1. 创建 RFQ
  2. 邀请供应商
  3. 报价
  4. 比价
  5. 授标
  6. 转采购订单
- **输入 / 输出**：输入需求与报价，输出比价表与授标结果
- **异常与分支**：报价不足三家需说明；超预算重新询价

### 采购协同与对账

- **触发条件**：采购订单下达
- **参与角色**：采购、供应商、仓库、财务
- **流程步骤**：
  1. 订单确认
  2. 排产/备货
  3. 发货
  4. 收货
  5. 对账
  6. 开票
  7. 付款
- **输入 / 输出**：输入订单与收货，输出对账单、发票、付款
- **异常与分支**：交期延误预警；数量差异挂起；发票不符退回

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 供应商档案 | 待审核/合格/观察/黑名单 | 审核、评级 | 采购 |
| RFQ | 草稿/报价中/比价中/已授标/已关闭 | 授标 | 采购订单 |
| 采购订单 | 待确认/已确认/部分交货/已完成 | 确认、收货 | 对账 |
| 对账单 | 待对账/有差异/已确认/已付款 | 对账 | 付款 |

## 业务规则

- 未准入供应商不能下单
- 关键物料必须有多家合格供方
- 报价超预算或单一来源需审批
- 来料不合格影响供应商绩效
- 对账确认后才能开票付款
