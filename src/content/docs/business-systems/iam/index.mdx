**一句话定位**：统一身份、认证、授权和审计，让正确的人访问正确的资源。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 公共服务与平台系统 |
| 典型用户 | 员工、IT 管理员、安全、审计、外部用户 |
| 核心模块 | 身份目录、单点登录、多因素认证、授权、权限申请、审计 |
| 常见产品 | Okta、Microsoft Entra ID、阿里云 IDaaS、竹云 |
| 开源项目 | Keycloak、Authentik、Ory、Apache Syncope、Casdoor |

## 这个系统解决什么问题

员工在多系统有多个账号，离职权限回收不及时，权限泛滥，审计拿不出证据。IAM 做统一身份、单点登录、授权、审批和审计。

它既提升员工体验，也降低账号泄露和越权风险。
