## 一句话定义

统一身份、认证、授权和审计，让正确的人访问正确的资源。

## 业务背景

员工在多系统有多个账号，离职权限回收不及时，权限泛滥，审计拿不出证据。IAM 做统一身份、单点登录、授权、审批和审计。

它既提升员工体验，也降低账号泄露和越权风险。

## 系统边界

IAM 管身份与访问，不管业务权限细节（各业务系统）、不管终端安全（EDR）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 员工 | 登录、申请权限 | 单点登录、权限申请 |
| IT 管理员 | 账号、应用、策略 | 账号、应用、策略 |
| 安全 | 风险评估、审计 | 审计、报表 |
| 审计 | 权限合规检查 | 权限报表 |
| 外部用户 | 合作伙伴/客户登录 | 外部身份 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| HRM | 入转调离事件 |
| 各业务系统 | 应用接入与权限 |
| SIEM | 登录与权限事件 |
| MFA/短信 | 多因素认证 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 单点登录 | SSO | 一次登录访问多个应用 |
| 多因素认证 | MFA | 密码之外的第二种认证因素 |
| RBAC | Role-Based Access Control | 基于角色的访问控制 |
| 最小权限 | Least Privilege | 只授予完成工作所需的最小权限 |
| 权限回收 | Deprovisioning | 员工离职或转岗时收回权限 |
