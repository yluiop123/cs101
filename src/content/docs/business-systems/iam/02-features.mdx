## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 身份目录 | 用户、组织、账号 | IT |
| 单点登录 | OIDC、SAML、CAS | 员工 |
| 多因素认证 | 短信、OTP、生物识别 | 安全 |
| 授权 | 角色、策略、数据范围 | 管理员 |
| 权限申请 | 申请、审批、有效期 | 员工、主管 |
| 审计 | 登录日志、权限变更 | 审计 |

## 核心功能

### 统一身份

一个账号访问所有接入应用，减少多套密码。

### 单点登录

支持 OIDC、SAML、CAS 等标准协议。

### 多因素认证

高风险登录触发短信、OTP 或生物识别。

### 权限申请审批

按应用和角色申请，主管/应用负责人审批。

### 权限审计

查看谁有什么权限、何时授予、是否过期。

## 核心业务流程

### 入职开通

- **触发条件**：HR 系统新增员工
- **参与角色**：HR、IT、主管
- **流程步骤**：
  1. 同步员工
  2. 创建账号
  3. 分配基础角色
  4. 开通应用
  5. 通知员工
- **输入 / 输出**：输入员工与岗位，输出账号与初始权限
- **异常与分支**：岗位未定先给基础权限；敏感应用单独审批

### 离职回收

- **触发条件**：HR 系统离职生效
- **参与角色**：HR、IT、安全
- **流程步骤**：
  1. 接收离职事件
  2. 禁用账号
  3. 回收权限
  4. 移交数据
  5. 审计记录
- **输入 / 输出**：输入离职员工，输出账号禁用与权限回收
- **异常与分支**：离职未交接暂缓；外包账号到期自动回收

### 权限申请

- **触发条件**：员工需要访问新应用
- **参与角色**：员工、主管、应用负责人
- **流程步骤**：
  1. 选择应用与角色
  2. 填写理由
  3. 主管审批
  4. 应用负责人审批
  5. 授权
  6. 到期回收
- **输入 / 输出**：输入申请，输出授权记录与有效期
- **异常与分支**：高风险权限加签安全；超期自动回收；拒绝通知

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 账号 | 正常/锁定/禁用/注销 | 创建、禁用 | 权限 |
| 权限申请 | 待审批/已批准/已拒绝/已过期 | 审批 | 授权 |
| 角色 | 启用/停用 | 配置 | 授权 |
| 审计日志 | 不可篡改 | 记录 | 审计 |

## 业务规则

- 一人一账号，禁止共享账号
- 离职账号必须当天禁用
- 高风险权限需要额外审批和定期复核
- 权限必须有有效期
- 所有登录和授权变更留审计日志
