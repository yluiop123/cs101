## 一句话定义

管仓库里的收货、上架、拣货、复核、发货和盘点。

## 业务背景

库存账实不符、找货慢、拣货出错、发货漏单，是仓库最常见的痛点。WMS 用库位、批次、波次和扫码把仓库作业标准化。

它让每一件货「在哪、有多少、什么时候进出」都可查，也让仓库产能和人员绩效可衡量。

## 系统边界

WMS 管仓库作业，不管库存财务核算（ERP）、不管运输调度（TMS）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 仓管员 | 收货、上架、拣货、盘点 | 收货、上架、拣货、盘点 |
| 收货员 | 到货验收、异常登记 | 收货单、异常 |
| 拣货员 | 按波次拣货、扫码复核 | 拣货任务、复核 |
| 发货员 | 装车、交接、发货确认 | 发货单 |
| 仓库主管 | 库容、产能、绩效 | 看板、报表 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| ERP | 库存账与采购/销售订单 |
| TMS | 发货交接与运输 |
| OMS | 订单下发与库存占用 |
| MES | 线边配送与成品入库 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 库位 | Location | 仓库中存放商品的具体位置编码 |
| 波次 | Wave | 把多个订单合并成一批拣货任务 |
| 批次 | Lot | 同一生产或采购批次的商品 |
| 先进先出 | FIFO | 先入库的批次先出库 |
| 盘点 | Cycle Count | 核对系统库存与实物库存 |
