## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 收货 | 到货登记、验收、异常 | 收货员 |
| 上架 | 推荐库位、扫码上架 | 仓管员 |
| 库存 | 库位、批次、冻结、移库 | 仓管员 |
| 拣货 | 波次、路径、扫码复核 | 拣货员 |
| 发货 | 打包、装车、交接 | 发货员 |
| 盘点 | 动盘、循环盘、差异处理 | 仓管员 |
| 报表 | 库容、周转、绩效 | 主管 |

## 核心功能

### 库位管理

按区、巷、架、层、位编码，支持混放和指定库位。

### 批次与效期

按批次、效期、序列号管理，支持先进先出和临期预警。

### 波次拣货

按订单结构、承运商、区域合并波次，优化拣货路径。

### 扫码作业

收货、上架、拣货、复核全流程扫码，减少人为错误。

### 库存冻结

质检、锁定、召回等场景冻结库存，避免误发。

## 核心业务流程

### 收货上架

- **触发条件**：供应商到货或成品完工入库
- **参与角色**：收货员、仓管员、质检
- **流程步骤**：
  1. 到货登记
  2. 验收
  3. 质检
  4. 推荐库位
  5. 扫码上架
  6. 库存增加
- **输入 / 输出**：输入到货单与实物，输出入库单、库位库存
- **异常与分支**：数量短少登记差异；质检不合格转退货或待检区

### 订单拣货发货

- **触发条件**：OMS/ERP 下发发货订单
- **参与角色**：拣货员、复核员、发货员
- **流程步骤**：
  1. 生成波次
  2. 分配拣货任务
  3. 拣货
  4. 复核
  5. 打包
  6. 装车交接
  7. 发货确认
- **输入 / 输出**：输入发货订单，输出拣货单、发货单、库存扣减
- **异常与分支**：缺货拆单；拣错复核拦截；装车差异登记

### 盘点

- **触发条件**：周期盘点或差异预警
- **参与角色**：仓管员、主管
- **流程步骤**：
  1. 生成盘点任务
  2. 冻结库位
  3. 实盘
  4. 差异复核
  5. 调整库存
  6. 解冻
- **输入 / 输出**：输入盘点范围，输出盘点单与差异调整
- **异常与分支**：差异超阈值复盘；责任差异走审批

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 收货单 | 待收货/部分收货/已完成/异常 | 验收 | 上架 |
| 上架单 | 待上架/已完成 | 扫码上架 | 库存 |
| 拣货单 | 待拣货/拣货中/已完成/异常 | 拣货、复核 | 发货 |
| 盘点单 | 待盘点/盘点中/待复核/已完成 | 实盘、复核 | 库存调整 |

## 业务规则

- 所有出入库必须扫码，禁止手工改库存
- 批次商品按先进先出或效期优先出库
- 冻结库存不能参与分配
- 盘点期间库位冻结，避免边盘边动
- 库存差异必须走审批才能调整
