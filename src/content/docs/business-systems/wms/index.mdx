**一句话定位**：管仓库里的收货、上架、拣货、复核、发货和盘点。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 制造与供应链系统 |
| 典型用户 | 仓管员、收货员、拣货员、发货员、仓库主管 |
| 核心模块 | 收货、上架、库存、拣货、发货、盘点、报表 |
| 常见产品 | SAP EWM、Manhattan WMS、富勒 WMS、唯智 WMS |
| 开源项目 | OpenBoxes、Odoo Inventory、ERPNext Stock、Apache OFBiz |

## 这个系统解决什么问题

库存账实不符、找货慢、拣货出错、发货漏单，是仓库最常见的痛点。WMS 用库位、批次、波次和扫码把仓库作业标准化。

它让每一件货「在哪、有多少、什么时候进出」都可查，也让仓库产能和人员绩效可衡量。
