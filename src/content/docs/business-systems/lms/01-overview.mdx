## 一句话定义

管课程、学习、考试和证书，让培训可组织、可追踪。

## 业务背景

培训靠线下通知和 Excel 统计，课程资源分散，学习进度和效果难追踪。LMS 把课程、班级、学习、考试、证书和报表集中起来。

它既服务员工培训，也服务客户教育和合规学习。

## 系统边界

LMS 管学习过程与培训管理，不管人事档案（HRM）、不管直播/会议（直播平台）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 学员 | 选课、学习、考试、查证书 | 课程、考试、证书 |
| 讲师 | 建课、授课、答疑 | 课程、直播、作业 |
| 培训管理员 | 计划、班级、报名、统计 | 培训计划、班级 |
| 主管 | 团队学习进度 | 团队报表 |
| 管理层 | 培训效果与合规 | 仪表盘 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| HRM | 员工与组织 |
| 直播平台 | 线上授课 |
| 考试/题库 | 测评 |
| 内容平台 | 课程资源 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 课程 | Course | 一组学习内容与活动 |
| 班级 | Class | 按时间组织的学员集合 |
| 学习路径 | Learning Path | 按顺序完成的课程组合 |
| SCORM | Sharable Content Object Reference Model | 课程内容与 LMS 的交互标准 |
| 证书 | Certificate | 完成学习或考试后的凭证 |
