## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 课程管理 | 课程、章节、资源 | 讲师、管理员 |
| 班级培训 | 计划、报名、签到 | 管理员 |
| 在线学习 | 视频、文档、进度 | 学员 |
| 考试 | 题库、试卷、判分 | 讲师 |
| 证书 | 模板、发放、查询 | 管理员 |
| 报表 | 学习进度、完成率、成绩 | 主管 |

## 核心功能

### 课程与学习路径

课程可组合成学习路径，按顺序解锁。

### 班级管理

按计划开班，支持报名、审批、签到和名额。

### 在线考试

题库组卷、限时考试、自动判分和防作弊。

### 证书发放

完成条件满足后自动发证，支持查询和验真。

### 学习报表

按部门、课程、学员统计进度和完成率。

## 核心业务流程

### 课程发布到学习

- **触发条件**：讲师或管理员创建课程
- **参与角色**：讲师、管理员、学员
- **流程步骤**：
  1. 创建课程
  2. 上传内容
  3. 设置学习规则
  4. 发布
  5. 学员报名
  6. 学习
  7. 完成
- **输入 / 输出**：输入课程内容，输出课程、学习记录
- **异常与分支**：内容审核不通过退回；学员退课；学习超时提醒

### 考试与证书

- **触发条件**：课程学习完成或合规要求
- **参与角色**：学员、讲师、管理员
- **流程步骤**：
  1. 组卷
  2. 考试
  3. 判分
  4. 合格
  5. 发证
  6. 归档
- **输入 / 输出**：输入题库与答卷，输出成绩与证书
- **异常与分支**：不合格补考；作弊取消成绩；证书信息错误重发

### 培训计划

- **触发条件**：年度培训或合规要求
- **参与角色**：管理员、主管、学员
- **流程步骤**：
  1. 制定计划
  2. 分配学员
  3. 通知
  4. 学习
  5. 考核
  6. 统计
- **输入 / 输出**：输入培训目标与对象，输出计划、完成率
- **异常与分支**：未完成催办；计划变更通知；缺席补训

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 课程 | 草稿/待审核/已发布/已下线 | 发布 | 学习 |
| 培训班 | 待开班/进行中/已结班 | 开班、结班 | 证书 |
| 考试 | 待开始/进行中/已结束 | 考试 | 成绩 |
| 证书 | 待发放/已发放/已撤销 | 发放 | 查询 |

## 业务规则

- 课程内容审核后才能发布
- 考试必须满足完成条件才能参加
- 证书编号唯一并可验真
- 学习记录保留用于合规审计
- 退课按规则处理已产生费用
