**一句话定位**：管课程、学习、考试和证书，让培训可组织、可追踪。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 公共服务与平台系统 |
| 典型用户 | 学员、讲师、培训管理员、主管、管理层 |
| 核心模块 | 课程管理、班级培训、在线学习、考试、证书、报表 |
| 常见产品 | 云学堂、平安知鸟、腾讯乐享、Cornerstone |
| 开源项目 | Moodle、Open edX、Canvas LMS、Chamilo |

## 这个系统解决什么问题

培训靠线下通知和 Excel 统计，课程资源分散，学习进度和效果难追踪。LMS 把课程、班级、学习、考试、证书和报表集中起来。

它既服务员工培训，也服务客户教育和合规学习。
