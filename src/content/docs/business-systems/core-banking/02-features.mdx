## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 客户信息 | 个人/对公客户、证件、关系 | 柜员、客户经理 |
| 账户管理 | 开户、销户、冻结、状态 | 柜员、运营 |
| 存款 | 活期、定期、计息、支取 | 柜员 |
| 贷款 | 放款、还款、展期、核销 | 信贷、运营 |
| 支付结算 | 转账、汇款、手续费 | 柜员、清算 |
| 总账 | 科目、凭证、日终 | 会计 |

## 核心功能

### 账户生命周期

开户、激活、冻结、挂失、销户全流程管理。

### 产品参数化

利率、期限、计息方式、手续费按产品配置。

### 交易记账

每笔交易生成借贷分录，保证账务平衡。

### 日终批处理

计息、计提、清算、总账过账、报表生成。

### 冲正与差错

错误交易冲正、差错登记和人工调整。

## 核心业务流程

### 开户

- **触发条件**：客户到柜面或线上申请开户
- **参与角色**：客户、柜员、运营
- **流程步骤**：
  1. 身份核验
  2. 客户信息录入
  3. 选择产品
  4. 开户
  5. 激活
  6. 发放凭证
- **输入 / 输出**：输入客户身份与产品，输出客户号、账号
- **异常与分支**：身份核验不通过拒绝；重复开户合并；高风险客户加强尽调

### 存取款与转账

- **触发条件**：客户发起存取款或转账
- **参与角色**：客户、柜员、清算
- **流程步骤**：
  1. 交易录入
  2. 校验余额与限额
  3. 记账
  4. 打印凭证
  5. 清算
- **输入 / 输出**：输入交易金额与账户，输出交易流水与余额
- **异常与分支**：余额不足拒绝；超限额授权；跨行转账走清算

### 日终批处理

- **触发条件**：营业日结束
- **参与角色**：运营、会计、清算
- **流程步骤**：
  1. 交易入账
  2. 计息计提
  3. 清算对账
  4. 总账过账
  5. 报表生成
  6. 日切
- **输入 / 输出**：输入当日交易，输出利息、总账、报表
- **异常与分支**：对账不平挂账；批处理失败回滚重跑

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 开户申请 | 待审核/已开户/已拒绝 | 审核 | 账户 |
| 交易流水 | 已记账/已冲正 | 记账、冲正 | 总账 |
| 贷款账户 | 正常/逾期/呆账/已结清 | 放款、还款 | 账务 |
| 日终报表 | 待生成/已生成 | 生成 | 报送 |

## 业务规则

- 所有交易必须借贷平衡
- 账户状态异常时禁止交易
- 大额交易触发反洗钱报告
- 冲正必须关联原交易
- 日切后当日交易不能修改
