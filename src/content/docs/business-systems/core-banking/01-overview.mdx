## 一句话定义

管存款、贷款、客户账户和总账，是银行所有业务的后台账务核心。

## 业务背景

银行每天发生海量存取款、转账、贷款还款，必须有稳定的账户和账务核心。核心银行系统负责客户、账户、产品、交易记账和总账。

它不直接面对客户，而是为柜面、手机银行、信贷、支付等渠道提供统一的账务能力。

## 系统边界

核心银行管账务与客户账户，不管渠道（手机银行/柜面）、不管支付清算（清算系统）、不管信贷审批（信贷系统）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 柜员 | 开户、存取款、转账 | 柜面交易 |
| 客户经理 | 客户与账户查询 | 客户视图 |
| 运营 | 账户冻结、冲正、对账 | 运营交易 |
| 清算人员 | 日终清算与对账 | 清算、总账 |
| 会计 | 总账与报表 | 总账、报表 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| 支付清算 | 支付指令与清算结果 |
| 信贷系统 | 放款、还款与额度 |
| 渠道系统 | 手机银行、网银、柜面 |
| 监管报送 | 账户与交易数据 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 活期/定期 | Demand/Time Deposit | 按支取方式划分的存款产品 |
| 账户冻结 | Account Freeze | 限制账户资金进出的状态 |
| 冲正 | Reversal | 对错误交易进行反向记账 |
| 日终批处理 | End-of-Day Batch | 每日营业结束后的计息、清算和总账处理 |
| 总账 | General Ledger | 银行全部科目的汇总账簿 |
