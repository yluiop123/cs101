**一句话定位**：管存款、贷款、客户账户和总账，是银行所有业务的后台账务核心。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 金融业务系统 |
| 典型用户 | 柜员、客户经理、运营、清算人员、会计 |
| 核心模块 | 客户信息、账户管理、存款、贷款、支付结算、总账 |
| 常见产品 | Temenos T24、FIS Core Banking、长亮科技、宇信科技 |
| 开源项目 | Apache Fineract、Mifos X、Apache OFBiz、Ledger |

## 这个系统解决什么问题

银行每天发生海量存取款、转账、贷款还款，必须有稳定的账户和账务核心。核心银行系统负责客户、账户、产品、交易记账和总账。

它不直接面对客户，而是为柜面、手机银行、信贷、支付等渠道提供统一的账务能力。
