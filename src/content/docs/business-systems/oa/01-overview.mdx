## 一句话定义

把审批、公文、会议、任务和知识文档放进一个入口，让组织协同有记录。

## 业务背景

请假、报销、用印、采购申请靠微信和邮件流转，审批到哪一步不清楚，文件版本满天飞。OA 把日常审批和协同事务集中到一套系统。

它也是企业流程的入口：很多业务系统（ERP、FMS、HRM）的审批会从 OA 发起或回到 OA 待办。

## 系统边界

OA 管协同流程与办公事务，不管专业业务核算（FMS/ERP）、不管项目管理细节（PPM）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 全体员工 | 请假、报销、用印、查待办 | 待办、申请、通讯录 |
| 部门主管 | 审批、任务分派 | 审批、任务、团队日程 |
| 行政 | 公文、会议、资产、用印 | 公文、会议、行政事务 |
| HR | 入转调离审批、公告 | 审批、公告 |
| 管理层 | 看板、督办 | 仪表盘、督办 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| HRM | 请假、加班、入转调离数据 |
| FMS | 报销、付款审批与凭证 |
| ERP | 采购、合同审批 |
| 企业微信/钉钉 | 消息通知与移动审批 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 工作流 | Workflow | 按条件和角色流转的审批流程 |
| 公文 | Official Document | 企业正式发文、收文、签报 |
| 督办 | Supervision | 对重点事项跟踪进度和结果 |
| 知识库 | Knowledge Base | 制度、模板、经验文档的集中管理 |
| 待办 | To-do | 当前用户需要处理的任务和审批 |
