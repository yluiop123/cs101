## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 流程审批 | 请假、报销、用印、采购等流程 | 全体员工 |
| 公文管理 | 发文、收文、签报、归档 | 行政、管理层 |
| 会议管理 | 会议室、会议通知、纪要 | 行政、全员 |
| 任务与督办 | 任务分派、进度、提醒 | 主管、执行人 |
| 知识文档 | 制度、模板、目录权限 | 全员 |
| 通讯录 | 组织架构、人员信息 | 全员 |

## 核心功能

### 可视化流程

用表单、条件、审批节点配置流程，支持会签、或签、转办、加签。

### 统一待办

各业务系统的审批集中到 OA 待办，避免多系统来回切换。

### 公文流转

按公文类型走拟稿、核稿、签发、分发、归档。

### 知识库

按部门、角色控制文档可见范围，支持版本和检索。

### 移动审批

在手机端处理待办、查看附件、手写签名。

## 核心业务流程

### 请假审批

- **触发条件**：员工提交请假申请
- **参与角色**：员工、主管、HR
- **流程步骤**：
  1. 填写请假单
  2. 主管审批
  3. HR 备案
  4. 同步考勤
- **输入 / 输出**：输入请假类型与时间，输出审批结果与考勤记录
- **异常与分支**：假期余额不足驳回；连续请假超阈值加签上级

### 公文发文

- **触发条件**：部门需要正式发文
- **参与角色**：拟稿人、核稿人、签发人、行政
- **流程步骤**：
  1. 拟稿
  2. 部门核稿
  3. 会签
  4. 领导签发
  5. 编号分发
  6. 归档
- **输入 / 输出**：输入正文与附件，输出正式公文与归档记录
- **异常与分支**：会签意见不一致退回修改；紧急公文走特急通道

### 用印申请

- **触发条件**：合同、证明等需要盖章
- **参与角色**：申请人、主管、法务、行政
- **流程步骤**：
  1. 提交用印申请
  2. 业务审批
  3. 法务审核
  4. 行政盖章
  5. 登记归档
- **输入 / 输出**：输入文件与用印类型，输出盖章记录
- **异常与分支**：合同未审完不盖章；外带用印需登记归还

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 请假单 | 草稿/审批中/已通过/已驳回 | 审批 | 考勤 |
| 报销单 | 草稿/审批中/待付款/已付款 | 审批、付款 | 凭证 |
| 发文单 | 拟稿/核稿/会签/已签发/已归档 | 签发 | 公文 |
| 用印单 | 待审批/已批准/已用印/已归还 | 审批、用印 | 用印登记 |

## 业务规则

- 审批人按组织架构和岗位自动匹配，可配置代理人
- 流程中的金额、假期等字段参与条件分支
- 已办结流程不能修改，需发起变更或作废
- 公文编号按年度和类型自动生成
- 敏感文档按密级控制下载和转发
