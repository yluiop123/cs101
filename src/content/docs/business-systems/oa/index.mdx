**一句话定位**：把审批、公文、会议、任务和知识文档放进一个入口，让组织协同有记录。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 企业通用系统 |
| 典型用户 | 全体员工、部门主管、行政、HR、管理层 |
| 核心模块 | 流程审批、公文管理、会议管理、任务与督办、知识文档、通讯录 |
| 常见产品 | 钉钉、企业微信、飞书、泛微 e-cology |
| 开源项目 | Flowable、Activiti、Dolibarr、Odoo |

## 这个系统解决什么问题

请假、报销、用印、采购申请靠微信和邮件流转，审批到哪一步不清楚，文件版本满天飞。OA 把日常审批和协同事务集中到一套系统。

它也是企业流程的入口：很多业务系统（ERP、FMS、HRM）的审批会从 OA 发起或回到 OA 待办。
