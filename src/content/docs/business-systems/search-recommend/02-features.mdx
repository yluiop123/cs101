## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 搜索召回 | 倒排、向量、类目 | 算法 |
| 搜索排序 | 相关性、点击率、转化率 | 算法 |
| 推荐召回 | 协同、内容、热门、向量 | 算法 |
| 推荐排序 | CTR/CVR 模型 | 算法 |
| 运营配置 | 词库、同义词、黑名单、人工干预 | 运营 |
| 效果分析 | 点击、转化、GMV、AB 实验 | 数据 |

## 核心功能

### 多路召回

关键词、类目、向量、协同过滤多路召回候选商品。

### 个性化排序

结合用户画像、行为和商品特征预测点击与转化。

### 搜索理解

分词、同义词、纠错、意图识别，提升搜得到率。

### 运营干预

置顶、屏蔽、加权、活动商品池。

### AB 实验

按流量分组验证算法和策略效果。

## 核心业务流程

### 搜索请求

- **触发条件**：用户输入关键词
- **参与角色**：用户、搜索服务
- **流程步骤**：
  1. 查询理解
  2. 多路召回
  3. 粗排
  4. 精排
  5. 重排/打散
  6. 返回结果
  7. 记录行为
- **输入 / 输出**：输入关键词与用户上下文，输出排序后的商品列表
- **异常与分支**：无结果给推荐兜底；敏感词过滤；超时降级热门

### 首页推荐

- **触发条件**：用户进入首页或详情页
- **参与角色**：用户、推荐服务
- **流程步骤**：
  1. 获取用户画像
  2. 多路召回
  3. 排序
  4. 多样性打散
  5. 曝光
  6. 反馈
- **输入 / 输出**：输入用户与场景，输出推荐列表
- **异常与分支**：新用户走热门/内容召回；重复曝光降权

### 运营干预

- **触发条件**：活动或业务需要调整结果
- **参与角色**：运营、算法
- **流程步骤**：
  1. 配置词库/商品池
  2. 设置权重或屏蔽
  3. 灰度
  4. 观察效果
  5. 全量或回滚
- **输入 / 输出**：输入干预规则，输出搜索结果变化
- **异常与分支**：干预过度导致相关性下降时回滚

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 搜索词库 | 草稿/已发布 | 发布 | 搜索 |
| 干预规则 | 待审核/生效中/已下线 | 审核、上线 | 结果 |
| 推荐场景 | 配置中/已上线/已下线 | 上线 | 曝光 |
| 实验 | 运行中/已结束/已结论 | 结束 | 策略 |

## 业务规则

- 召回和排序必须可解释、可回滚
- 敏感词和违规商品不能出现在结果中
- 实验流量不能重叠
- 推荐结果要控制多样性和重复曝光
- 效果指标以转化和 GMV 为主，不能只看点击
