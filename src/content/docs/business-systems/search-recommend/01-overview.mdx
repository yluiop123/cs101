## 一句话定义

让用户更快找到商品，也让商品找到更可能买的人。

## 业务背景

商品多、目录深，用户搜不到、逛不到；首页和详情页没有个性化，转化率上不去。搜索与推荐系统做召回、排序、展示和效果评估。

它把「人找货」和「货找人」结合起来，是电商和内容平台的核心增长系统。

## 系统边界

搜索推荐管检索、排序和推荐服务，不管商品主数据（PIM）、不管交易履约（OMS）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 算法工程师 | 召回、排序、特征、评估 | 模型、特征、AB 实验 |
| 搜索运营 | 词库、同义词、干预 | 搜索配置、干预 |
| 商品运营 | 商品标签、上下架 | 商品池 |
| 数据分析 | 效果分析、漏斗 | 报表、实验 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| PIM | 商品与属性 |
| OMS/POS | 行为与交易数据 |
| 数据中台 | 特征与标签 |
| AB 实验平台 | 效果验证 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 召回 | Recall | 从全量商品中快速筛选候选集 |
| 排序 | Ranking | 对候选集按相关性或转化概率排序 |
| 粗排/精排 | Coarse/Fine Ranking | 两阶段排序，兼顾效率和效果 |
| 向量检索 | Vector Search | 用 Embedding 相似度找商品 |
| 冷启动 | Cold Start | 新用户或新商品缺少行为数据时的推荐 |
