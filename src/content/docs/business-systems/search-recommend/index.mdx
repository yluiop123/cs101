**一句话定位**：让用户更快找到商品，也让商品找到更可能买的人。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 交易与零售系统 |
| 典型用户 | 算法工程师、搜索运营、商品运营、数据分析 |
| 核心模块 | 搜索召回、搜索排序、推荐召回、推荐排序、运营配置、效果分析 |
| 常见产品 | 阿里云 OpenSearch、腾讯云搜索、百度智能推荐、神策推荐 |
| 开源项目 | Elasticsearch、OpenSearch、Vespa、Milvus、Qdrant |

## 这个系统解决什么问题

商品多、目录深，用户搜不到、逛不到；首页和详情页没有个性化，转化率上不去。搜索与推荐系统做召回、排序、展示和效果评估。

它把「人找货」和「货找人」结合起来，是电商和内容平台的核心增长系统。
