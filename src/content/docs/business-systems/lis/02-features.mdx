## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 检验申请 | 项目、组合、申请单 | 医生 |
| 标本管理 | 采样、条码、接收、拒收 | 护士、技师 |
| 仪器接口 | 双向通讯、结果采集 | 技师 |
| 结果处理 | 录入、计算、审核 | 技师 |
| 报告 | 报告生成、发布、打印 | 审核 |
| 危急值 | 识别、通知、记录 | 技师、临床 |
| 质控 | 室内质控、失控处理 | 技师 |

## 核心功能

### 条码闭环

从采样到上机全程扫码，避免标本错配。

### 仪器双向通讯

自动下载测试项目、上传结果，减少手工录入。

### 结果审核

按规则自动审核，异常结果人工复核。

### 危急值通知

识别危急值，电话/系统通知临床并记录。

### 室内质控

质控品结果监控，失控时阻断报告。

## 核心业务流程

### 检验申请到报告

- **触发条件**：医生开具检验申请
- **参与角色**：医生、护士、技师、审核
- **流程步骤**：
  1. 开申请
  2. 收费
  3. 采样
  4. 条码
  5. 送检
  6. 接收
  7. 上机
  8. 结果
  9. 审核
  10. 报告
- **输入 / 输出**：输入申请与标本，输出检验结果与报告
- **异常与分支**：标本不合格拒收；结果异常复检；仪器故障转手工

### 标本流转

- **触发条件**：护士采样
- **参与角色**：护士、运送、技师
- **流程步骤**：
  1. 打印条码
  2. 采样
  3. 扫码绑定
  4. 送检
  5. 接收确认
  6. 上机
- **输入 / 输出**：输入患者与项目，输出标本状态
- **异常与分支**：条码错误重打；标本量不足补采；超时标本标记

### 危急值

- **触发条件**：结果触发危急值规则
- **参与角色**：技师、临床医生
- **流程步骤**：
  1. 识别
  2. 复核
  3. 通知临床
  4. 记录
  5. 临床处理
- **输入 / 输出**：输入危急值结果，输出通知记录与处理反馈
- **异常与分支**：联系不上升级；重复通知留痕

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 检验申请 | 待收费/待采样/已采样/已报告 | 采样、报告 | 报告 |
| 标本 | 待接收/已接收/已上机/已归档/拒收 | 接收、上机 | 结果 |
| 检验报告 | 待审核/已审核/已发布 | 审核 | 临床 |
| 危急值记录 | 待通知/已通知/已处理 | 通知 | 处理 |

## 业务规则

- 标本必须条码唯一并绑定患者
- 不合格标本必须拒收并记录原因
- 危急值必须通知临床并留痕
- 质控失控时相关项目报告暂停
- 报告审核后才能发布
