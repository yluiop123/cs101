## 一句话定义

管检验申请、标本、仪器、结果和报告，让检验全流程可追踪。

## 业务背景

检验申请靠纸质，标本容易错，仪器结果手工录入，报告发放慢。LIS 把申请、采样、条码、仪器、结果审核和报告串起来。

它让检验科能批量处理标本，也让临床及时看到结果和危急值。

## 系统边界

LIS 管检验流程与结果，不管病历文书（EMR）、不管影像（PACS）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 医生 | 开检验申请、看结果 | 申请、报告 |
| 护士 | 采样、条码打印、标本送检 | 采样、标本 |
| 检验技师 | 接收标本、上机、结果录入 | 标本、仪器、结果 |
| 审核人员 | 结果审核、危急值 | 审核、报告 |
| 患者 | 查询报告 | 报告查询 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| HIS | 患者、收费、申请 |
| EMR | 结果回写与调阅 |
| 仪器 | 生化、免疫、血球等 |
| 区域检验平台 | 外送与互认 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 标本 | Specimen | 血液、尿液等检验样本 |
| 条码 | Barcode | 标本唯一标识，关联患者与检验项目 |
| 仪器接口 | Instrument Interface | LIS 与检验仪器的双向通讯 |
| 危急值 | Critical Value | 提示生命危险的检验结果，需立即通知 |
| 质控 | Quality Control | 检验过程的室内质控与室间质评 |
