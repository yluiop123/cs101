**一句话定位**：管检验申请、标本、仪器、结果和报告，让检验全流程可追踪。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 医疗健康系统 |
| 典型用户 | 医生、护士、检验技师、审核人员、患者 |
| 核心模块 | 检验申请、标本管理、仪器接口、结果处理、报告、危急值、质控 |
| 常见产品 | 杏和 LIS、瑞美 LIS、东软 LIS、卫宁 LIS |
| 开源项目 | OpenELIS、OpenMRS Lab、Bahmni、OpenEMR |

## 这个系统解决什么问题

检验申请靠纸质，标本容易错，仪器结果手工录入，报告发放慢。LIS 把申请、采样、条码、仪器、结果审核和报告串起来。

它让检验科能批量处理标本，也让临床及时看到结果和危急值。
