## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 库存模型 | SKU、仓、渠道、批次 | 库存运营 |
| 渠道分配 | 渠道可售比例与规则 | 电商运营 |
| 占用释放 | 下单占用、取消释放 | 系统 |
| 调拨 | 调拨申请、执行、在途 | 仓库 |
| 同步 | 渠道库存推送与对账 | 库存运营 |
| 预警 | 低库存、超卖、呆滞 | 运营 |

## 核心功能

### 统一库存池

把多仓、多店、多平台的库存汇总成一个可计算的总池。

### 渠道分配

按渠道优先级、比例或安全库存分配可售数量。

### 占用与释放

下单锁库存，取消或超时自动释放，避免超卖。

### 调拨在途

调拨发出后计入在途，签收后转入目标仓。

### 库存预警

低库存、超卖、呆滞、效期预警。

## 核心业务流程

### 库存同步

- **触发条件**：入库、出库、调拨或盘点后库存变化
- **参与角色**：系统、库存运营
- **流程步骤**：
  1. 接收库存变动
  2. 重新计算可售
  3. 按渠道规则分配
  4. 推送渠道
  5. 对账
- **输入 / 输出**：输入库存变动，输出各渠道可售库存
- **异常与分支**：推送失败重试；渠道库存不一致告警；大促期间限流

### 下单占用

- **触发条件**：OMS/POS 创建订单
- **参与角色**：系统
- **流程步骤**：
  1. 校验可售
  2. 占用库存
  3. 返回结果
  4. 出库后扣减
  5. 取消后释放
- **输入 / 输出**：输入订单商品与数量，输出占用结果
- **异常与分支**：库存不足拒绝；支付超时释放；拆单分别占用

### 调拨

- **触发条件**：仓间或仓店库存不平衡
- **参与角色**：库存运营、仓库
- **流程步骤**：
  1. 创建调拨单
  2. 审批
  3. 调出仓出库
  4. 在途
  5. 调入仓签收
  6. 库存转移
- **输入 / 输出**：输入调拨需求，输出调拨单、在途库存
- **异常与分支**：在途丢失走理赔；签收差异登记

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 库存记录 | 可用/占用/冻结/在途 | 占用、释放、调拨 | 库存变动 |
| 调拨单 | 待审批/待出库/在途/已签收/异常 | 审批、签收 | 库存转移 |
| 渠道库存 | 同步中/已同步/异常 | 同步 | 渠道 |
| 盘点差异单 | 待处理/已调整 | 审批 | 库存调整 |

## 业务规则

- 可售库存不能为负
- 渠道可售之和不能超过总可售
- 大促前锁定库存分配规则
- 调拨在途计入总库存但不计入可售
- 库存调整必须留痕
