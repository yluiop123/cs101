**一句话定位**：统一管理多渠道库存，做占用、释放、调拨和同步。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 交易与零售系统 |
| 典型用户 | 库存运营、电商运营、仓库、财务 |
| 核心模块 | 库存模型、渠道分配、占用释放、调拨、同步、预警 |
| 常见产品 | 阿里库存中心、京东库存中心、旺店通、聚水潭 |
| 开源项目 | Apache OFBiz、Odoo Inventory、ERPNext Stock、Saleor |

## 这个系统解决什么问题

电商、门店、仓库各有一套库存，超卖和积压同时发生；大促前不知道能卖多少。库存中心把可售库存统一计算，按渠道分配和同步。

它让「同一个商品在多个渠道卖」不再互相打架，也让补货和调拨有依据。
