**一句话定位**：管产品从需求、设计、BOM、变更到退市的全生命周期数据。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 制造与供应链系统 |
| 典型用户 | 研发工程师、工艺工程师、质量工程师、采购、项目经理 |
| 核心模块 | 产品结构、图文档、BOM 管理、变更管理、项目管理、合规管理 |
| 常见产品 | Teamcenter、Windchill、ENOVIA、用友 PLM |
| 开源项目 | OpenPLM、Odoo PLM、Apache OFBiz、FreeCAD |

## 这个系统解决什么问题

图纸、BOM、工艺文件版本混乱，设计变更传不到生产和采购，导致错料、返工和交期延误。PLM 把产品数据、流程和变更管起来。

它让研发、工艺、采购、质量围绕同一份产品定义协作，并保留完整的变更历史。
