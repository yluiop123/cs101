## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 产品结构 | 产品、零部件、版本 | 研发 |
| 图文档 | 图纸、模型、文档、权限 | 研发 |
| BOM 管理 | 设计 BOM、制造 BOM、替代料 | 研发、工艺 |
| 变更管理 | ECN、影响分析、审批 | 研发、质量 |
| 项目管理 | 新品开发计划与里程碑 | 项目经理 |
| 合规管理 | 法规、物质、证书 | 质量 |

## 核心功能

### 统一产品数据

图纸、模型、BOM、工艺文件围绕产品结构组织，版本可追溯。

### BOM 转换

从设计 BOM 生成制造 BOM，支持替代料和用量调整。

### 变更闭环

变更申请、影响分析、审批、执行、通知生产和采购。

### 权限与签审

按角色控制查看、下载、修改，关键文件走电子签审。

### 合规追踪

记录物料成分、证书和法规符合性。

## 核心业务流程

### 新品开发

- **触发条件**：市场或客户提出新产品需求
- **参与角色**：项目经理、研发、工艺、质量
- **流程步骤**：
  1. 立项
  2. 概念设计
  3. 详细设计
  4. 样机验证
  5. 工艺开发
  6. 试产
  7. 量产发布
- **输入 / 输出**：输入需求与设计输入，输出产品结构、BOM、工艺文件
- **异常与分支**：评审不通过退回设计；试产问题走变更

### 设计变更

- **触发条件**：设计缺陷、降本或供应替代
- **参与角色**：研发、工艺、采购、质量、生产
- **流程步骤**：
  1. 提出 ECN
  2. 影响分析
  3. 审批
  4. 更新图纸与 BOM
  5. 通知生产采购
  6. 切换版本
- **输入 / 输出**：输入变更原因与方案，输出新版本与切换计划
- **异常与分支**：在制品和库存需消耗旧版本；紧急变更走特批

### BOM 发布

- **触发条件**：设计定型或变更完成
- **参与角色**：研发、工艺、ERP 管理员
- **流程步骤**：
  1. BOM 审核
  2. 生成制造 BOM
  3. 发布到 ERP
  4. 核对物料与用量
- **输入 / 输出**：输入设计 BOM，输出制造 BOM 与 ERP 物料数据
- **异常与分支**：物料编码缺失先补主数据；BOM 不一致回退

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 产品 | 概念/设计中/已发布/已退市 | 发布、退市 | BOM |
| 图纸 | 草稿/审核中/已发布/已作废 | 审核、发布 | 版本 |
| ECN | 草稿/影响分析/审批中/已执行/已关闭 | 审批、执行 | 版本切换 |
| BOM | 草稿/已审核/已发布/已失效 | 发布 | ERP |

## 业务规则

- 产品、物料、图纸必须有唯一编码和版本
- 已发布版本不能直接修改，只能新建版本
- 变更必须做影响分析并通知相关方
- BOM 发布前必须完成物料主数据校验
- 关键文件下载和打印要留痕
