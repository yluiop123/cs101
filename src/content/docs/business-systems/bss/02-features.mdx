## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 客户管理 | 客户、账户、联系方式 | 营业员、客服 |
| 产品配置 | 套餐、资费、促销 | 产品经理 |
| 订单 | 订购、变更、退订 | 营业员 |
| 计费 | 采集、批价、出账 | 计费 |
| 账务 | 账单、缴费、调账 | 财务 |
| 客服 | 查询、投诉、工单 | 客服 |

## 核心功能

### 产品与套餐

组合语音、流量、宽带、增值业务，配置资费和促销。

### 订购关系

管理客户与产品的开通、变更、暂停、退订。

### 计费出账

按使用量和套餐规则批价，生成周期账单。

### 缴费与调账

支持多渠道缴费、代扣、退款和人工调账。

### 收入稽核

比对开通、计费、收款，发现漏收和错收。

## 核心业务流程

### 开户订购

- **触发条件**：客户办理新套餐
- **参与角色**：客户、营业员、OSS
- **流程步骤**：
  1. 实名认证
  2. 选择套餐
  3. 创建订单
  4. 支付
  5. 开通
  6. 通知
- **输入 / 输出**：输入客户与套餐，输出订单、账户、开通指令
- **异常与分支**：实名不通过拒绝；资源不足排队；支付失败取消

### 计费出账

- **触发条件**：计费周期结束
- **参与角色**：计费、财务
- **流程步骤**：
  1. 采集用量
  2. 批价
  3. 优惠计算
  4. 出账
  5. 稽核
  6. 发布账单
- **输入 / 输出**：输入用量与套餐，输出账单与收入
- **异常与分支**：异常用量核查；批价失败重跑；争议账单调账

### 变更退订

- **触发条件**：客户变更套餐或退订
- **参与角色**：客户、营业员、客服
- **流程步骤**：
  1. 申请
  2. 校验合约
  3. 计算费用
  4. 生效
  5. 通知
  6. 同步 OSS
- **输入 / 输出**：输入变更请求，输出新订购关系与费用
- **异常与分支**：合约未到期收违约金；靓号协议限制；退订后资源回收

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 客户 | 正常/欠费/停机/销户 | 开户、停机 | 账户 |
| 订单 | 待支付/已支付/开通中/已完成/已取消 | 支付、开通 | 订购 |
| 账单 | 待出账/已出账/已缴费/争议 | 出账、缴费 | 账务 |
| 工单 | 待处理/处理中/已关闭 | 处理 | 客服 |

## 业务规则

- 实名认证通过才能开户
- 套餐变更按合约和生效规则处理
- 账单争议未解决不能重复扣款
- 所有调账必须审批留痕
- 收入稽核差异必须闭环
