## 一句话定义

把业务数据变成报表、看板和自助分析，让决策有数可依。

## 业务背景

数据散在 ERP、CRM、OA 等系统里，业务要一张报表只能找 IT 写 SQL，口径还经常对不上。BI 把数据接入、指标建模、报表、看板和自助分析集中起来。

它让业务人员能自己拖拽分析，也让管理层在同一套口径下看经营结果。

## 系统边界

BI 管分析与展示，不管业务交易（ERP/CRM）、不管数据同步与治理（数据中台/ETL）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 数据分析师 | 建模、指标、报表开发 | 数据集、报表、看板 |
| 业务人员 | 自助查询、订阅报表 | 自助分析、看板 |
| 管理层 | 经营驾驶舱 | 仪表盘、移动端 |
| IT/数据团队 | 数据接入、权限、运维 | 数据源、调度、权限 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| 数据中台/数仓 | 提供清洗后的数据与指标 |
| ERP/CRM/OMS | 业务数据来源 |
| OA/消息平台 | 报表订阅与告警推送 |
| 权限系统 | 行列级数据权限 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 指标 | Metric | 可被业务统一定义和复用的度量，如 GMV、毛利率 |
| 数据集 | Dataset | 面向分析组织好的宽表或模型 |
| 维度 | Dimension | 分析的角度，如时间、地区、渠道 |
| 下钻 | Drill-down | 从汇总数据逐层查看明细 |
| 数据权限 | Data Permission | 控制用户能看到哪些行、哪些列 |
