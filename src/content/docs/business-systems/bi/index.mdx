**一句话定位**：把业务数据变成报表、看板和自助分析，让决策有数可依。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 企业通用系统 |
| 典型用户 | 数据分析师、业务人员、管理层、IT/数据团队 |
| 核心模块 | 数据接入、指标建模、报表、看板、自助分析、权限与审计 |
| 常见产品 | Tableau、Power BI、FineBI、观远数据 |
| 开源项目 | Apache Superset、Metabase、Redash、Grafana、Lightdash |

## 这个系统解决什么问题

数据散在 ERP、CRM、OA 等系统里，业务要一张报表只能找 IT 写 SQL，口径还经常对不上。BI 把数据接入、指标建模、报表、看板和自助分析集中起来。

它让业务人员能自己拖拽分析，也让管理层在同一套口径下看经营结果。
