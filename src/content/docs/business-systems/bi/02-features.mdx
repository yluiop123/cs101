## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 数据接入 | 数据库、API、文件、埋点 | IT/数据 |
| 指标建模 | 指标定义、口径、血缘 | 分析师 |
| 报表 | 明细表、汇总表、订阅 | 业务、分析师 |
| 看板 | 可视化大屏、驾驶舱 | 管理层 |
| 自助分析 | 拖拽查询、图表 | 业务人员 |
| 权限与审计 | 行列权限、访问日志 | IT |

## 核心功能

### 多源接入

连接关系库、数仓、Excel、API 和埋点数据。

### 指标中心

统一指标口径、计算逻辑和负责人，避免同名不同义。

### 可视化看板

用折线、柱状、地图、漏斗等组件拼装看板，支持筛选联动。

### 自助分析

业务人员拖拽维度和指标，即时生成图表。

### 订阅与告警

按日/周推送报表，指标异常触发告警。

## 核心业务流程

### 报表需求到上线

- **触发条件**：业务提出报表需求
- **参与角色**：业务、分析师、数据工程师
- **流程步骤**：
  1. 需求确认
  2. 指标口径评审
  3. 数据接入与建模
  4. 报表开发
  5. 验收
  6. 发布与订阅
- **输入 / 输出**：输入业务问题，输出指标定义、数据集和报表
- **异常与分支**：口径不一致先对齐；数据缺失补采集；性能不达标优化模型

### 自助分析

- **触发条件**：业务人员临时想看某个维度
- **参与角色**：业务人员
- **流程步骤**：
  1. 选择数据集
  2. 拖拽维度与指标
  3. 筛选
  4. 保存图表
  5. 分享
- **输入 / 输出**：输入分析条件，输出图表与结论
- **异常与分支**：权限不足提示申请；数据量过大走预聚合

### 指标口径变更

- **触发条件**：业务规则调整
- **参与角色**：指标负责人、分析师、业务
- **流程步骤**：
  1. 提出变更
  2. 影响评估
  3. 评审
  4. 更新指标
  5. 通知订阅者
- **输入 / 输出**：输入新口径，输出指标版本与影响范围
- **异常与分支**：历史报表需重算；下游模型同步更新

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 指标定义 | 草稿/评审中/已发布/已下线 | 评审、发布 | 数据集 |
| 报表 | 开发中/待验收/已发布/已下线 | 验收、发布 | 订阅 |
| 看板 | 草稿/已发布 | 发布 | 分享 |
| 数据权限申请 | 待审批/已通过/已拒绝 | 审批 | 权限生效 |

## 业务规则

- 一个指标只能有一个负责人和一份口径
- 报表发布前必须经过业务验收
- 敏感字段按角色脱敏
- 所有查询记录访问日志
- 指标变更必须通知下游订阅者
