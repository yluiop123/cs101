## 一句话定义

用可视化配置和少量代码快速搭建表单、流程和业务应用。

## 业务背景

业务变化快，传统开发排期长，大量长尾应用（登记、审批、报表、台账）没人手做。低代码用拖拽表单、流程、页面和权限快速交付。

它让业务人员或公民开发者自己搭简单应用，专业开发聚焦核心系统。

## 系统边界

低代码适合表单流程类应用和部门级工具，不适合高并发交易核心、复杂算法和深度定制。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 业务人员 | 搭建简单表单和台账 | 表单、流程、报表 |
| 公民开发者 | 配置部门应用 | 页面、数据、权限 |
| 专业开发 | 扩展组件、集成 API | 自定义代码、连接器 |
| IT 管理 | 应用审核、权限、资源 | 应用目录、审计 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| OA | 流程审批与待办 |
| 数据中台 | 数据源与 API |
| IAM | 统一登录与权限 |
| 消息平台 | 通知与提醒 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 公民开发 | Citizen Developer | 非专业开发人员用低代码搭建应用 |
| 表单引擎 | Form Engine | 拖拽生成录入表单 |
| 流程引擎 | Workflow Engine | 配置审批与自动化流程 |
| 连接器 | Connector | 连接外部系统和 API 的适配层 |
| 应用发布 | App Publishing | 把配置好的应用部署给用户使用 |
