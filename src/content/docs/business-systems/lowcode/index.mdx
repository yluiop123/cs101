**一句话定位**：用可视化配置和少量代码快速搭建表单、流程和业务应用。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 企业通用系统 |
| 典型用户 | 业务人员、公民开发者、专业开发、IT 管理 |
| 核心模块 | 表单设计、流程设计、页面设计、数据模型、权限、集成 |
| 常见产品 | Mendix、OutSystems、钉钉宜搭、简道云 |
| 开源项目 | Appsmith、ToolJet、Budibase、NocoDB、Baserow |

## 这个系统解决什么问题

业务变化快，传统开发排期长，大量长尾应用（登记、审批、报表、台账）没人手做。低代码用拖拽表单、流程、页面和权限快速交付。

它让业务人员或公民开发者自己搭简单应用，专业开发聚焦核心系统。
