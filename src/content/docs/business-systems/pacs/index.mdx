**一句话定位**：管医学影像的采集、存储、调阅和报告，让影像在院内共享。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 医疗健康系统 |
| 典型用户 | 放射科医生、临床医生、技师、患者、远程会诊 |
| 核心模块 | 检查登记、影像采集、归档存储、阅片、报告、会诊、打印 |
| 常见产品 | 联影 PACS、东软 PACS、锐珂 PACS、西门子 PACS |
| 开源项目 | Orthanc、dcm4che、Weasis、OHIF Viewer |

## 这个系统解决什么问题

影像胶片难保存、难调阅，患者换院要重拍，临床医生看不到历史影像。PACS 把 CT、MR、DR、超声等影像归档，支持临床调阅和报告。

它是放射科和临床之间的影像枢纽，也是远程会诊的基础。
