## 一句话定义

管医学影像的采集、存储、调阅和报告，让影像在院内共享。

## 业务背景

影像胶片难保存、难调阅，患者换院要重拍，临床医生看不到历史影像。PACS 把 CT、MR、DR、超声等影像归档，支持临床调阅和报告。

它是放射科和临床之间的影像枢纽，也是远程会诊的基础。

## 系统边界

PACS 管影像存储与调阅，不管病历文书（EMR）、不管检验（LIS）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 放射科医生 | 阅片、写报告、审核 | 阅片、报告 |
| 临床医生 | 调阅影像与报告 | 影像调阅 |
| 技师 | 检查、采集、传图 | 检查、采集 |
| 患者 | 获取影像与报告 | 患者服务 |
| 远程会诊 | 共享影像 | 会诊 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| HIS | 检查申请与收费 |
| EMR | 报告回写 |
| 影像设备 | CT/MR/DR/US |
| 区域影像平台 | 互认与共享 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| DICOM | Digital Imaging and Communications in Medicine | 医学影像标准格式与通讯协议 |
| 影像归档 | Archive | 把影像长期存储并可检索 |
| 阅片 | Reading | 医生在专业显示器上查看影像 |
| 报告 | Radiology Report | 影像检查的结论与建议 |
| 远程会诊 | Teleconsultation | 跨院专家共享影像会诊 |
