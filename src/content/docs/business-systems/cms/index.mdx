**一句话定位**：管内容的创建、审核、发布、版本和多端分发。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 公共服务与平台系统 |
| 典型用户 | 编辑、审核、运营、开发、管理员 |
| 核心模块 | 内容模型、编辑器、审核发布、版本、栏目专题、多端 API、检索 |
| 常见产品 | Contentful、Adobe Experience Manager、Sitecore、内容管理系统厂商 |
| 开源项目 | Strapi、Directus、Payload、WordPress、Ghost |

## 这个系统解决什么问题

内容散在多个平台，发布流程不规范，改版和回滚困难，多端展示不一致。CMS 把内容模型、编辑、审核、发布、版本和分发统一起来。

它让编辑专注内容，让开发通过模板和 API 控制展示。
