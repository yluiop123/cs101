## 一句话定义

管内容的创建、审核、发布、版本和多端分发。

## 业务背景

内容散在多个平台，发布流程不规范，改版和回滚困难，多端展示不一致。CMS 把内容模型、编辑、审核、发布、版本和分发统一起来。

它让编辑专注内容，让开发通过模板和 API 控制展示。

## 系统边界

CMS 管内容生产与发布，不管数字资产存储（DAM）、不管营销自动化（MA）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 编辑 | 创建、编辑、提交审核 | 内容编辑 |
| 审核 | 审核、退回、发布 | 审核队列 |
| 运营 | 栏目、专题、推荐位 | 栏目、运营配置 |
| 开发 | 模板、API、集成 | 模板、API |
| 管理员 | 模型、权限、版本 | 模型、权限 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| DAM | 图片、视频等资产 |
| 搜索 | 站内搜索 |
| 营销自动化 | 内容触达 |
| CDN/前端 | 多端发布 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 内容模型 | Content Model | 定义内容类型和字段 |
| 工作流 | Workflow | 草稿、审核、发布的状态流转 |
| 版本 | Revision | 内容每次修改的快照 |
| 栏目 | Category | 内容的分类与导航结构 |
| 多端分发 | Multi-channel Delivery | 网站、App、小程序共用内容 |
