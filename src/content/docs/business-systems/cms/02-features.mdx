## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 内容模型 | 类型、字段、关系 | 管理员 |
| 编辑器 | 富文本、Markdown、组件 | 编辑 |
| 审核发布 | 工作流、定时发布 | 审核 |
| 版本 | 历史、对比、回滚 | 编辑、管理员 |
| 栏目专题 | 分类、推荐位、专题 | 运营 |
| 多端 API | REST/GraphQL 输出 | 开发 |
| 检索 | 全文检索、标签 | 全员 |

## 核心功能

### 结构化内容

用内容模型定义字段，内容与展示分离。

### 审核工作流

草稿、待审、已发布、已下线，支持定时发布。

### 版本回滚

保留每次修改，可对比和回滚。

### 多端分发

同一份内容通过 API 输出到网站、App、小程序。

### 栏目与推荐

栏目树、专题、推荐位配置。

## 核心业务流程

### 内容创作到发布

- **触发条件**：编辑需要发布新内容
- **参与角色**：编辑、审核、运营
- **流程步骤**：
  1. 创建内容
  2. 填写字段
  3. 上传素材
  4. 提交审核
  5. 审核
  6. 发布
  7. 分发
- **输入 / 输出**：输入内容与素材，输出已发布内容
- **异常与分支**：审核不通过退回；定时发布取消；敏感词拦截

### 内容更新与回滚

- **触发条件**：内容需要修改或出错
- **参与角色**：编辑、审核
- **流程步骤**：
  1. 创建新版本
  2. 修改
  3. 审核
  4. 发布
  5. 必要时回滚
- **输入 / 输出**：输入修改内容，输出新版本
- **异常与分支**：紧急下线；回滚到指定版本；缓存刷新

### 多端分发

- **触发条件**：内容发布或栏目调整
- **参与角色**：开发、运营
- **流程步骤**：
  1. 内容发布
  2. API 输出
  3. CDN 刷新
  4. 端上展示
  5. 埋点回收
- **输入 / 输出**：输入内容与栏目，输出各端页面
- **异常与分支**：端上缓存不一致强制刷新；API 限流

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 内容 | 草稿/待审核/已发布/已下线 | 审核、发布 | 分发 |
| 版本 | 历史/当前 | 回滚 | 内容 |
| 栏目 | 启用/停用 | 配置 | 导航 |
| 发布任务 | 待执行/已完成/已取消 | 执行 | 上线 |

## 业务规则

- 内容发布必须经过审核
- 已发布内容修改要生成新版本
- 敏感词和违规内容自动拦截
- 栏目调整要同步导航和缓存
- 内容删除采用软删除并保留审计
