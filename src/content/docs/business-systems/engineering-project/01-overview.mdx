## 一句话定义

管工程项目的进度、成本、合同、质量和安全，让施工现场可控。

## 业务背景

工程项目周期长、参与方多，进度靠报表、成本靠事后算、质量和安全靠巡检，问题往往滞后才发现。工程项目管理系统把立项、进度、合同、成本、质量、安全串起来。

它让业主、施工、监理在同一套数据上协作，减少扯皮和信息差。

## 系统边界

系统管项目管理过程，不管设计建模（BIM）、不管现场设备监控（智慧工地）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 项目经理 | 计划、进度、协调 | 进度、任务、周报 |
| 施工员 | 施工日志、进度上报 | 施工记录 |
| 预算/成本 | 预算、签证、结算 | 成本、合同 |
| 质量/安全 | 检查、整改、验收 | 检查单、整改单 |
| 监理 | 旁站、验收、指令 | 监理记录 |
| 业主 | 投资、进度、质量监督 | 看板、报表 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| BIM | 设计模型与工程量 |
| 财务/ERP | 付款、成本归集 |
| 采购/物资 | 材料采购与进场 |
| 智慧工地 | 现场设备与人员监控 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| WBS | Work Breakdown Structure | 把工程拆成可管理的工作包 |
| 签证 | Site Instruction | 现场变更的书面确认 |
| 进度款 | Progress Payment | 按工程进度支付的款项 |
| 旁站 | Supervision | 监理对关键工序的现场监督 |
| 竣工验收 | Completion Acceptance | 工程完成后的正式验收 |
