**一句话定位**：管工程项目的进度、成本、合同、质量和安全，让施工现场可控。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 公共服务与平台系统 |
| 典型用户 | 项目经理、施工员、预算/成本、质量/安全、监理、业主 |
| 核心模块 | 立项、进度、合同、成本、物资、质量、安全 |
| 常见产品 | 广联达、鲁班软件、用友工程、金蝶工程 |
| 开源项目 | OpenProject、ProjectLibre、Redmine、Odoo Project |

## 这个系统解决什么问题

工程项目周期长、参与方多，进度靠报表、成本靠事后算、质量和安全靠巡检，问题往往滞后才发现。工程项目管理系统把立项、进度、合同、成本、质量、安全串起来。

它让业主、施工、监理在同一套数据上协作，减少扯皮和信息差。
