## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 立项 | 项目、标段、参建方 | 业主、项目经理 |
| 进度 | WBS、计划、实际进度 | 项目经理 |
| 合同 | 合同、变更、签证 | 合同/成本 |
| 成本 | 预算、实际、结算 | 预算/财务 |
| 物资 | 计划、采购、进场 | 物资 |
| 质量 | 检查、整改、验收 | 质量 |
| 安全 | 检查、隐患、教育 | 安全 |

## 核心功能

### 进度计划

按 WBS 编制计划，跟踪实际进度和偏差。

### 合同与签证

合同台账、变更签证、付款节点。

### 成本控制

预算、实际成本、进度款和结算对比。

### 质量安全

检查单、隐患整改、复查闭环。

### 多方协同

业主、施工、监理按权限共享数据和流程。

## 核心业务流程

### 项目立项

- **触发条件**：业主启动新项目
- **参与角色**：业主、项目经理、财务
- **流程步骤**：
  1. 项目建议
  2. 可行性研究
  3. 预算审批
  4. 立项
  5. 组建项目部
- **输入 / 输出**：输入项目目标与投资，输出立项批复与项目编号
- **异常与分支**：投资超限重新审批；条件不成熟暂缓

### 进度与成本

- **触发条件**：项目开工
- **参与角色**：项目经理、施工员、预算、财务
- **流程步骤**：
  1. 编制计划
  2. 施工上报
  3. 进度确认
  4. 成本归集
  5. 进度款申请
  6. 支付
- **输入 / 输出**：输入施工进度与成本，输出进度报表、付款申请
- **异常与分支**：进度滞后预警；成本超预算审批；签证未确认暂不付款

### 质量安全检查

- **触发条件**：日常巡检或关键工序
- **参与角色**：质量/安全、施工员、监理
- **流程步骤**：
  1. 检查
  2. 发现问题
  3. 下发整改
  4. 整改
  5. 复查
  6. 关闭
- **输入 / 输出**：输入检查结果，输出整改单与复查记录
- **异常与分支**：重大隐患停工；整改超期升级；复查不合格再整改

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 项目 | 立项/在建/停工/竣工/结算 | 立项、竣工 | 结算 |
| 进度计划 | 草稿/已审批/执行中/已调整 | 审批 | 进度上报 |
| 签证单 | 待审批/已批准/已结算 | 审批 | 成本 |
| 整改单 | 待整改/整改中/待复查/已关闭 | 整改、复查 | 关闭 |

## 业务规则

- 未立项项目不能发生成本
- 签证和变更必须书面确认
- 进度款支付不能超过合同比例
- 重大安全隐患必须停工整改
- 竣工资料齐全才能验收
