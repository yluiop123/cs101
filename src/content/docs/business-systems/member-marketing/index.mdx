**一句话定位**：管会员等级、积分、优惠券和活动，让老客持续复购。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 交易与零售系统 |
| 典型用户 | 会员运营、市场、门店、客服 |
| 核心模块 | 会员档案、等级权益、积分、优惠券、活动、触达、分析 |
| 常见产品 | 有赞、微盟、驿氪、数云 |
| 开源项目 | Open Loyalty、Odoo Loyalty、Apache OFBiz、ERPNext CRM |

## 这个系统解决什么问题

会员数据散在各渠道，积分和优惠券规则不统一，活动效果难评估。会员系统把身份、等级、权益、积分、券和活动统一起来。

它让运营能针对不同人群做差异化权益，而不是所有客户发同一张券。
