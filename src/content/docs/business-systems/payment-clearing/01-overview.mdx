## 一句话定义

管支付指令、渠道对接、清分结算和对账，让钱准确到账。

## 业务背景

支付方式越来越多（网银、快捷、扫码、代付），渠道接口各异，对账复杂，差错难追。支付清算系统统一支付指令、渠道路由、清分结算和对账。

它既要保证支付成功率，也要保证每一笔钱都能对上账。

## 系统边界

支付清算管支付指令与清算，不管银行核心账务（核心银行）、不管商户订单（OMS）。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 支付运营 | 渠道、限额、成功率 | 支付订单、渠道配置 |
| 开发 | 接口、路由、回调 | 网关、路由 |
| 财务 | 对账、结算、差错 | 对账单、结算单 |
| 风控 | 交易拦截 | 风险规则 |
| 商户 | 收款、退款、对账 | 商户后台 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| 核心银行 | 账户扣款与入账 |
| OMS | 订单与退款 |
| 渠道方 | 微信、支付宝、银联、银行 |
| 风控 | 交易风险决策 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 支付网关 | Payment Gateway | 统一对接各支付渠道的入口 |
| 渠道路由 | Channel Routing | 按成功率、费率、限额选择通道 |
| 清分 | Clearing | 计算各方的应收应付 |
| 结算 | Settlement | 按周期把资金划给商户或合作方 |
| 对账 | Reconciliation | 支付流水与渠道、账务的核对 |
