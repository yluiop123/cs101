**一句话定位**：管支付指令、渠道对接、清分结算和对账，让钱准确到账。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 金融业务系统 |
| 典型用户 | 支付运营、开发、财务、风控、商户 |
| 核心模块 | 支付网关、渠道路由、收单、代付、清分结算、对账、退款 |
| 常见产品 | 银联商务、Ping++、汇付天下、连连支付 |
| 开源项目 | Mojaloop、Apache Fineract、Hyperledger Fabric、Apache OFBiz |

## 这个系统解决什么问题

支付方式越来越多（网银、快捷、扫码、代付），渠道接口各异，对账复杂，差错难追。支付清算系统统一支付指令、渠道路由、清分结算和对账。

它既要保证支付成功率，也要保证每一笔钱都能对上账。
