## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 支付网关 | 统一下单、回调、签名 | 开发 |
| 渠道路由 | 通道选择、降级、限额 | 支付运营 |
| 收单 | 扫码、快捷、网银 | 商户 |
| 代付 | 批量付款、提现 | 商户、财务 |
| 清分结算 | 分账、计费、结算 | 财务 |
| 对账 | 渠道对账、差错处理 | 财务 |
| 退款 | 原路退款、部分退款 | 客服、财务 |

## 核心功能

### 统一支付接口

商户只对接一套 API，内部适配不同渠道。

### 智能路由

按成功率、费率、限额、地域选择最优通道。

### 分账结算

支持平台分账、服务商结算和手续费计算。

### 自动对账

每日拉取渠道账单，与本地流水自动匹配。

### 退款管理

原路退款、部分退款、退款失败重试。

## 核心业务流程

### 支付

- **触发条件**：商户或用户发起支付
- **参与角色**：商户、支付网关、渠道
- **流程步骤**：
  1. 创建支付单
  2. 风控校验
  3. 路由选通道
  4. 调用渠道
  5. 用户支付
  6. 回调
  7. 记账
  8. 通知商户
- **输入 / 输出**：输入订单与金额，输出支付结果与流水
- **异常与分支**：渠道超时查单；支付失败换通道；重复回调幂等处理

### 退款

- **触发条件**：订单取消或售后
- **参与角色**：商户、支付网关、渠道
- **流程步骤**：
  1. 创建退款单
  2. 校验可退金额
  3. 调用渠道退款
  4. 回调
  5. 记账
  6. 通知
- **输入 / 输出**：输入原支付单与退款金额，输出退款结果
- **异常与分支**：渠道退款失败重试；部分退款累计不能超原额

### 对账与结算

- **触发条件**：每日渠道账单生成
- **参与角色**：财务、支付运营
- **流程步骤**：
  1. 下载账单
  2. 导入本地流水
  3. 自动匹配
  4. 差错处理
  5. 生成结算单
  6. 划款
- **输入 / 输出**：输入渠道账单与本地流水，输出对账结果、结算单
- **异常与分支**：长短款挂账；跨日交易调整；差错人工核销

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 支付单 | 待支付/支付中/成功/失败/已关闭 | 支付、回调 | 记账 |
| 退款单 | 待退款/退款中/成功/失败 | 退款 | 记账 |
| 对账单 | 待对账/已对平/有差错 | 对账 | 结算 |
| 结算单 | 待结算/已结算/已划款 | 结算 | 财务 |

## 业务规则

- 支付回调必须幂等
- 退款金额不能超过原支付金额
- 渠道限额和费率变更需审批
- 对账差错必须登记并核销
- 敏感支付信息加密存储
