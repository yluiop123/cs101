**一句话定位**：把财务、采购、库存、生产、销售等企业核心资源放进一套系统统一管理。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 企业通用系统 |
| 典型用户 | 财务人员、采购人员、库存管理员、生产计划员、销售/商务 |
| 核心模块 | 财务核算、采购管理、库存管理、生产管理、销售管理、主数据 |
| 常见产品 | SAP S/4HANA、Oracle Fusion ERP、用友 U8 / YonBIP、金蝶云星空 |
| 开源项目 | Odoo、ERPNext、Apache OFBiz、Tryton |

## 这个系统解决什么问题

企业规模一大，财务、采购、库存、销售各用一套表格或小系统，数据对不上：财务不知道库存，销售不知道交期，采购不知道预算。ERP 用统一的主数据和单据流把「钱、物、账」串起来。

它通常围绕采购到付款、销售到收款、生产到入库三条主线，把业务动作实时转成财务凭证，让管理者看到经营结果。
