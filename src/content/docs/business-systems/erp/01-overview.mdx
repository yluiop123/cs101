## 一句话定义

把财务、采购、库存、生产、销售等企业核心资源放进一套系统统一管理。

## 业务背景

企业规模一大，财务、采购、库存、销售各用一套表格或小系统，数据对不上：财务不知道库存，销售不知道交期，采购不知道预算。ERP 用统一的主数据和单据流把「钱、物、账」串起来。

它通常围绕采购到付款、销售到收款、生产到入库三条主线，把业务动作实时转成财务凭证，让管理者看到经营结果。

## 系统边界

ERP 管企业内部资源与交易记账，不管车间设备控制（MES/SCADA）、不管客户线索培育（CRM）、不管仓储作业细节（WMS）。它可以和这些系统集成，但不替代它们。

## 典型用户与角色

| 角色 | 职责 | 常用功能 |
| --- | --- | --- |
| 财务人员 | 核算、应收应付、总账、报表 | 凭证、应收应付、总账、财务报表 |
| 采购人员 | 供应商、采购订单、到货对账 | 采购申请、采购订单、收货、对账 |
| 库存管理员 | 出入库、盘点、库存台账 | 入库、出库、调拨、盘点 |
| 生产计划员 | 生产订单、物料需求 | 生产订单、MRP、领料 |
| 销售/商务 | 销售订单、发货、开票 | 销售订单、发货、应收 |

## 与相邻系统的关系

| 系统 | 关系 |
| --- | --- |
| CRM | 提供客户与商机，成交后转销售订单 |
| WMS | 执行仓库出入库作业，回传库存变动 |
| MES | 执行生产工单，回传完工与领料 |
| 税务/发票平台 | 发票开具、认证与纳税申报对接 |

## 关键术语

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 主数据 | Master Data | 物料、客户、供应商、组织等跨模块共享的基础数据 |
| 物料需求计划 | MRP | 根据订单、库存、BOM 计算采购与生产需求 |
| 物料清单 | BOM | 描述产品由哪些物料组成的结构 |
| 三单匹配 | Three-way Match | 采购订单、收货单、发票三者核对后付款 |
| 总账 | General Ledger | 所有会计凭证汇总的账簿 |
