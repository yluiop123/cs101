## 功能地图

| 模块 | 作用 | 主要使用角色 |
| --- | --- | --- |
| 财务核算 | 总账、应收应付、固定资产、报表 | 财务 |
| 采购管理 | 采购申请、订单、收货、对账 | 采购、仓库 |
| 库存管理 | 出入库、调拨、盘点、库存台账 | 仓库、计划 |
| 生产管理 | 生产订单、MRP、领料、完工 | 计划、车间 |
| 销售管理 | 销售订单、发货、开票、应收 | 销售、财务 |
| 主数据 | 物料、客户、供应商、组织 | 各业务部门 |

## 核心功能

### 统一主数据

物料、客户、供应商、组织、币种、税率在一处维护，各模块引用同一份编码，避免一物多码。

### 单据流转

采购申请→订单→收货→发票→付款，销售订单→发货→开票→收款，每一步都有单据和状态。

### 实时记账

业务单据审核后自动生成会计凭证，财务账与业务账保持一致。

### MRP 运算

根据销售订单、库存、BOM、在途采购计算缺料，生成采购建议和生产建议。

### 权限与审批

按组织、角色、金额、单据类型配置审批流和数据权限。

## 核心业务流程

### 采购到付款

- **触发条件**：库存低于安全库存，或 MRP 产生采购建议
- **参与角色**：采购、仓库、财务
- **流程步骤**：
  1. 采购申请
  2. 审批
  3. 采购订单
  4. 供应商发货
  5. 收货入库
  6. 发票校验
  7. 付款
- **输入 / 输出**：输入需求与供应商报价，输出入库单、应付账款、付款单
- **异常与分支**：数量短少或质量不合格走退货；发票与订单不一致走三单差异处理

### 销售到收款

- **触发条件**：客户下单
- **参与角色**：销售、仓库、财务
- **流程步骤**：
  1. 销售订单
  2. 信用检查
  3. 发货
  4. 出库
  5. 开票
  6. 收款
  7. 核销
- **输入 / 输出**：输入客户订单，输出发货单、发票、应收账款
- **异常与分支**：信用不足冻结订单；缺货拆单；退货走红字发票

### 生产到入库

- **触发条件**：销售订单或库存补充计划
- **参与角色**：计划、车间、仓库
- **流程步骤**：
  1. 生产订单
  2. 领料
  3. 加工
  4. 报工
  5. 完工入库
- **输入 / 输出**：输入生产订单与 BOM，输出领料单、完工入库单、成本
- **异常与分支**：缺料停线、报废补料、超领退料

## 单据与状态

| 单据 | 状态 | 触发动作 | 下一步 |
| --- | --- | --- | --- |
| 采购订单 | 草稿/已审批/部分收货/已完成/已关闭 | 审批、收货 | 收货单 |
| 销售订单 | 草稿/已确认/部分发货/已完成/已取消 | 确认、发货 | 发货单 |
| 生产订单 | 已下达/生产中/已完工/已关闭 | 下达、报工 | 完工入库 |
| 付款单 | 待审批/已审批/已支付 | 审批、支付 | 应付核销 |

## 业务规则

- 物料、客户、供应商必须先建主数据才能开单
- 采购订单价格不能高于框架协议价，超出需审批
- 销售订单确认前做信用额度检查
- 库存出库按先进先出或指定批次
- 已审核单据不能直接删除，只能冲销或红冲
