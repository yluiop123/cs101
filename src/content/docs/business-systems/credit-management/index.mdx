**一句话定位**：管贷款申请、授信、审批、放款、还款和贷后，让信贷业务可风控。

## 系统档案

| 项目 | 内容 |
| --- | --- |
| 所属分类 | 金融业务系统 |
| 典型用户 | 客户经理、审批人、风控、贷后、财务 |
| 核心模块 | 申请进件、评分授信、审批、合同放款、还款、贷后 |
| 常见产品 | 宇信信贷、长亮信贷、神州信息、蚂蚁信贷 |
| 开源项目 | Apache Fineract、Mifos X、Odoo、Apache OFBiz |

## 这个系统解决什么问题

信贷流程长、材料多、审批链复杂，贷后跟踪难，逾期催收靠人盯。信贷系统把申请、评分、授信、合同、放款、还款和贷后串起来。

它让每一笔贷款从进件到结清都有记录，也让风险指标能实时监控。
