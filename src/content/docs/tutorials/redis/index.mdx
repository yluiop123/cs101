Redis（REmote DIctionary Server）是一个内存中的键值数据库：单线程串行执行命令、一次网络往返可以批量下发、数据结构开箱即用。它最常见的身份是**缓存**，但它的边界远不止于此——计数器、排行榜、分布式锁、消息队列、限流器都靠同一套原语实现。本教程从安装与五大类型讲起，一路推进到持久化、事务、发布订阅与集群，最后用一个商品详情缓存把「缓存三兄弟」落地。

## 你将学到

- 判断一个需求该不该上 Redis，以及上线前必须确认的那几个默认值

- 大 key 与热 key 的发现治理、六种淘汰策略与一次内存估算
- RDB 与 AOF 的取舍、混合持久化，以及一次真正的数据恢复演练
- `WATCH` 乐观锁、Lua 原子脚本与 Stream 消费者组：限流、扣库存、延迟队列
- 主从复制、哨兵故障转移与 Cluster 分槽，以及缓存三兄弟的完整对策

## 环境要求

```bash
redis-server --version    # 本教程基于 Redis 7.x，命令在 6.2+ 均可用
redis-cli                 # 客户端随服务端一起安装
docker                    # 可选：第 1 章用 Docker 起一个实例
```
