Go（Golang）由 Google 设计：语法极简、编译极快、原生并发（goroutine/channel），是云原生时代的官方语言（Docker/Kubernetes/etcd 均用它编写）。本教程从语法讲到并发模式，尾部以 Gin + GORM 完成 Web 后端实战。

## 你将学到

- Go 工具链与模块管理（go mod）
- 切片与 map 的内部机制、函数与错误处理哲学
- 结构体、方法、接口与组合（面向对象 Go 姿态）
- goroutine/channel 并发模型与 sync 包
- net/http → Gin → GORM 的 Web 后端全链路
- JWT 鉴权、交叉编译与 Docker 部署
