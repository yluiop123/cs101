JavaScript 是网页的"灵魂"，负责页面的交互逻辑，也是唯一能在浏览器中原生运行的编程语言（如今也大量运行在服务端）。本教程从变量与数据类型讲起，覆盖函数、对象、DOM、事件、异步编程与模块化，最终独立完成一个完整的待办清单应用。

## 你将学到

- 现代 JavaScript 完整语法（ES6+ 风格优先）
- 函数、闭包、原型与 class 的核心机制
- DOM 查询与操作、事件模型与事件委托
- localStorage 存储与浏览器交互
- Promise / async-await 异步编程与 fetch 请求
- ES Module 模块化，综合实战：待办清单应用
