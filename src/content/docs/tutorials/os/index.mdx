操作系统是那个把所有硬件变成「可复用、可仲裁、可计量」抽象的中间层。本教程不讲历史也不写玩具内核：全程以 Linux 为事实参照，每章都用 `strace`、`/proc`、`perf` 这类工具把结论落在你能亲手复现的观测上。两条主线贯穿始终 —— **虚拟化**（一份资源虚拟成多份）与**并发**（多执行流如何互不干扰地共存）。

## 前置教程

- [Linux 教程](../linux/)：会用 shell、权限、进程与 systemd，看得懂 `/proc` 与常见命令的输出
- [C 语言教程](../c/)：`fork`/`open`/`read`/`mmap` 这些接口都是 C 层 API，指针与结构体是读代码的最低门槛

## 你将学到

- 一次系统调用如何跨过用户态与内核态，以及它的真实代价
- 进程地址空间、PCB、`fork`/`exec`/`wait` 与写时复制；线程到底共享了什么
- 调度算法的取舍：FCFS/RR/MLFQ 的失效点，以及 CFS 用虚拟运行时间做的账本
- 虚拟内存全链路：分页、TLB、多级页表、缺页、swap、OOM 与内存超配
- 文件系统的一致性与性能：VFS、inode、fd 三层结构、页缓存与 `fsync` 的边界
- 用 `/proc`、`strace`、`perf` 把「慢」拆成排队、缺页、切换或换页四类可验证的原因
