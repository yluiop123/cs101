Git 是目前世界上最流行的**分布式版本控制系统**，是每个开发者的必备技能。它能记录代码的每一次改动、支持多人协作、随时回退到任意历史版本。

本教程从「为什么需要版本控制」讲起，覆盖 Git 的核心三区模型、分支管理、远程协作（GitHub），直到 rebase 等进阶技巧与真实事故恢复演练。

## 你将学到

- 理解工作区、暂存区、仓库三区模型与 commit 的本质
- 熟练使用 add / commit / branch / merge 等日常命令
- 配置远程仓库，完成 push / pull 协作与 Pull Request 流程
- 掌握 rebase、stash、cherry-pick 与事故恢复（reset / revert）
