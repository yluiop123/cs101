Angular 是 Google 开发的企业级前端框架，"大而全"是其特点：路由、HTTP、表单、依赖注入、测试全部内置，配合 TypeScript 形成强约束的工程体系。它广泛存在于大型企业系统与外企项目中。本教程定位为入门，RxJS 等深水区点到为止，采用现代写法（standalone 组件 + signals + 新控制流）。

## 你将学到

- Angular 的组件化模型与模板语法（新控制流 @if/@for）
- 依赖注入（DI）的设计思想与用法
- 服务、signal 与 RxJS 的协作分工
- 内置路由、响应式表单与 HttpClient
- Angular Material 组件库与测试基础
